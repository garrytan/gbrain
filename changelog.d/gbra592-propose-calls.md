**Calls imported before calls were kept to their attendees can now be fixed by preview, then approval.**

### Changed
- `gbrain repair visibility --propose` now covers imported calls with no reader list: each one is proposed for the brain owner plus the teammates its `Attendees:` or `Participants:` header names, matched by the same rules `gbrain import --calls` uses, owner first. The proposal reads the header as it was stored, so an address that import redaction blanked cannot be matched and that name is listed instead. Names that match no enabled member are listed under their own heading beside the proposal instead of holding the call back, and a call with no list is proposed for the owner only. With no owner set, calls are listed with the `gbrain access owner set` command and nothing is proposed. Nothing changes until the admin applies a printed command with its `--expect` hash; the owner reads every call before and after.

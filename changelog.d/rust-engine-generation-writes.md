**A Rust brain now writes derived pages: a dream summary or synthesis publish, retiring a derived page and an atoms publish give the same pages, trust tiers and stamps as Postgres and PGLite.**

### Changed
- A Rust brain now stamps a derived page's trust tier from the pages it was derived from and lowers a derived page whose content did not change, as Postgres and PGLite do. Before, these writes sent raw SQL and stopped on a Rust brain.
- A Rust brain now stamps `retired_by` and `retired_at` on the derived pages it retires, and stamps `source_hash` on the atom pages an atoms publish writes. Before, both stamps sent raw SQL and stopped on a Rust brain.
- The trust check in `gbrain doctor` now counts derived facts, takes, timeline entries and pages on a Rust brain. Before, it stopped on the first table.
- A Rust brain now reads and writes the Life Chronicle event records: the events of a depth page, their timeline rows on the depth page, the events retired when a depth page is gone, and the event slots a new publication checks. Before, the chronicle publish sent raw SQL and stopped on a Rust brain at its first read.
- On Postgres, the derived page reads of a generation publish now list pages and their tags in byte order on every database locale, as PGLite and a Rust brain do. Before, a Postgres database with a locale such as en_US listed them in a different order. Page identity hashes do not change. On such a database, the before-states saved from now on list a page's tags in byte order, so a new saved before-state can list the same tags in a different order than an older one.
- A Rust brain now records which rows a derived page was derived from, so a dream summary, `think` synthesis or drift report publish, an atoms publish and a Life Chronicle events publish run to the end there. Before, each stopped with `raw_sql` at its first record.
- When a page or fact on a Rust brain goes down a trust tier, every row derived from it (pages, facts, takes and timeline entries, at any depth) now goes down to its least trusted input, as on Postgres and PGLite. Before, such a lowering stopped with `raw_sql`.

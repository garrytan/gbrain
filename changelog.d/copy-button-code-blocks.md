**Code blocks on `gbrain publish` pages get a copy button in their top-right corner.**

### Added
- Every fenced code block on a published page, password-protected pages included once unlocked, now shows a copy icon in its top-right corner. One click puts the block's exact text on the clipboard, and the icon turns into a check mark for a moment. Prompts and commands shared through a published page can be pasted into an agent or a terminal without selecting text by hand. Pages opened from a file or a plain-http host fall back to the browser's older copy command.
- Code blocks on published pages now get a bordered panel that scrolls sideways, so long prompt lines no longer stretch the page.

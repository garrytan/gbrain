- On the Rust engine, `gbrain recall` and the other fact readers (the recall op, question recall, entity saved facts, the entity card, hot memory) now refuse by name when they cannot read slot ends, instead of quietly skipping them and showing a value a later fact ended (an old employer, city or role) as current. The refusal names `listSlotRows`, which the Rust engine does not serve yet. PGLite and Postgres answer as before; a database error during the slot read still leaves the facts as stored.

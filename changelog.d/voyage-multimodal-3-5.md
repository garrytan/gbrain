**`voyage:voyage-multimodal-3.5` is accepted for image embeddings.**

### Added
- `voyage-multimodal-3.5` joins the Voyage multimodal allow-list and pricing table (same wire, 1024 dimensions and list price as `voyage-multimodal-3`). Some Voyage endpoints, such as MongoDB Atlas' Voyage API, serve only 3.5, so a brain using them could not embed images.

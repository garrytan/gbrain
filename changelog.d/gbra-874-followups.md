**A remote edit of an imported transcript can no longer regain the importer's trust through a later maintenance write. Gmail backfill no longer misses mail at a second boundary, CJK keyword search keeps quoted phrases and steady paging, and rewrites keep a page's first-ingest record.**

### Fixed
- A transcript or connector page that a remote caller rewrote no longer counts as importer-written after a later write with no request (such as a maintenance tag), so its transcript layout and `speaker_owner` marker stay untrusted. The importer's stamp now vouches for such a page only while no later write has moved the page past it, and a remote write over a page with no stamp records its own. Before, a remote `edit_page` followed by maintenance made remote-edited metadata read as the importer's.
- The Gmail backfill lists one second below every `after:` bound. Gmail does not document whether `after:` includes its own second, so a thread sharing a second with the one a saved floor started at could be left unlisted on both sides and never fetched. A checkpoint that the extra second blocks proves the next second instead, so a sweep cut off on dense mail still saves its progress.
- A usage limit hit by the backfill's checkpoint search now stops the sweep at once, like one hit by a thread read, instead of being treated as a failed check while the sweep kept sending requests.
- `gbrain pages prune-history --keep N` keeps each page's newest N versions counting segmented versions, which are never pruned. Before, it ranked only the other versions, so it kept more than N and the preview's kept count left the segmented ones out. The apply checks the ranks again under the page lock, so a version that segmented retention moved into the newest N since the preview is kept.
- An acceptance from `gbrain transcripts accept-fences` on a transcript the importer wrote directly (no write request) now also holds on the page's content hash, so maintenance that moves the page's timestamps without changing it no longer puts it back on doctor's review list, and a later write that changes it still does. Acceptances recorded before this keep the timestamp rule.
- CJK keyword search: the hybrid any-term retry keeps a quoted phrase required, so it no longer returns chunks that hold only the other words; `OR` alternatives that differ only in quotes each keep their own match; with `OR` alternatives the strict pass and the retry rank shared rows the same way, so `offset` paging never repeats or skips a page; a term named by many `OR` alternatives is bound once.
- A remote `append_page`, and a remote `put_page` over a stored page on a brain with or without a repository, keep the page's first-ingest columns (`source_kind`, `source_uri`, `ingested_via`, `ingested_at`), as a remote `edit_page` already did. A repository brain's `put_page`, local or remote, keeps them too, `ingested_at` to the microsecond. A local `put_page` on a brain without a repository that names new provenance still re-ingests.

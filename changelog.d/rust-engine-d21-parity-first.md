### Changed
- `docs/designs/RUST_ENGINE.md`: the Rust engine plan now aims first for 1x parity by 2026-12-01. On the maintainer's own brain, the Rust engine must give the same CLI, JSON and MCP output and the same markdown brain format as today, pass the engine parity suite for every method that brain uses, and be no slower than PGLite or Postgres. It runs in shadow mode first, then by an opt-in swap. The 10x target and the "equal or better on every axis" bar now apply after parity and gate making Rust the default. The store bake-off takes 2 days. SQL removal starts now, in parallel, by subsystem. A new "Dec 1 schedule" table lists the eight workstreams and the milestones. This is a plan change only. No code ships and nothing changes for any brain.

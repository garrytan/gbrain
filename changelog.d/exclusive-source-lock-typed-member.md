- The lock a source-exclusive write takes on its source before publishing (`persistence/coordinator.ts`, the owner purge and other source-wide rewrites) is now a typed engine member, `lockSourceForUpdate`, instead of raw SQL. PGLite and Postgres run the same statement as before. The Rust engine serves it as a no-op, since its store already admits one write transaction at a time. A Rust page purge still refuses by name: the publication transaction of a recovered purge has one more raw-SQL statement (the `publication_started` stamp), which stays on the purge's list of stops.

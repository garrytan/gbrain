- A page save that the brain's engine refuses at publication (the Rust engine does not support a step it needs yet) no longer stays queued for ever. It is tried at most three times, then it ends failed with `engine_capability_missing`, and the error names the missing step and capability. The caller gets that error instead of `write_pending`, and later saves to the same source are no longer held up behind it. The same limit applies on every engine.

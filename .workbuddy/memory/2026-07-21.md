## Desktop 1.0.73 renderer 崩溃 hotfix（Desktop 1.0.74）

- 事故：用户装 1.0.73 后桌面端卡在 FIRST RUN 基础配置页，所有按钮（打开日志目录、保存配置等）点不动，"进不去系统"。
- 根因：1.0.73 删 index.html 共享成员接入表单 DOM 时，漏删 src.ts 两处引用已删元素的事件绑定：
  - `src.ts:1104` `$('#shared-can-write').addEventListener('change', ...)`——**顶层执行**，元素已删→null→`null.addEventListener` 抛 TypeError→renderer JS 在此崩溃→该行之后所有事件绑定（保存配置/打开日志等）未注册。
  - `src.ts:660` setSharedControlsDisabled 内 `$('#shared-write-source').disabled = ...`——函数内，配置完后共享就绪时也会崩。
- 教训：typecheck(tsc --noEmit)不报错（querySelector 类型断言，null 非类型错误），build 也过，**runtime 才崩**。删 DOM 必须 grep 全部引用。
- 修复：删 1104-1106 事件绑定；删 659-661 if 块，aria-disabled 目标 `.shared-form`→`.shared-guide`。typecheck+build 通过。1.0.73→1.0.74。build:win 后台打包中（task_id XvjzeJ），产出后用户卸载坏的 1.0.73 装新版。Bug 修复台账已记。

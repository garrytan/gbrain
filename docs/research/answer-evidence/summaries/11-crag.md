# 11 — Corrective Retrieval Augmented Generation

**Source:** [Primary publication](https://arxiv.org/abs/2401.15884v3); arXiv v3 (preprint; no peer-reviewed venue asserted here).

CRAG judges initial retrieval, refines useful passages and can supplement poor results with web search. Its PopQA ablations support those components in the tested configurations (Tables 1 and 3). Public-knowledge QA and external search differ from recovering private conversation facts. It is a retrieval-repair hypothesis, not a fixed-evidence presentation result.

# 13 — Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory

**Source:** [Primary publication](https://arxiv.org/abs/2504.19413v1); arXiv v1 (preprint).

Mem0 extracts and updates conversational facts; a graph variant adds relationships. Table 1 shows mixed category effects rather than a universal graph advantage. The evaluation excludes unanswerable/adversarial questions. That omission makes an independent abstention check important before transferring the design to GBrain. These results do not evaluate our excerpt selector.

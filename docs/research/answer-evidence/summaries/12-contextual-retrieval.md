# 12 — Contextual Retrieval

**Source:** [Primary publication](https://www.anthropic.com/engineering/contextual-retrieval); Anthropic Engineering report, original web article; vendor report.

This vendor study adds document-specific context before chunk embedding and keyword indexing. Its headline measures retrieval failure, not answer correctness. The appendix uses a separate dataset and cannot be combined with that aggregate. For GBrain, test contextual indexing independently; do not infer an answer-quality improvement from its recall figures.

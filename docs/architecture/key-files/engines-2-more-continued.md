# Key files: Engines (2/2, more, continued)

[Subsystem index](../KEY_FILES.md) · [Previous entries](engines-2-more.md). Read only the entries relevant to your change.
Current behavior and load-bearing invariants; history belongs in Git and CHANGELOG.

- `src/core/engine-sql/facts-conversation.ts` — the statements of conversation fact publication and relink as 30 typed engine members in place of `executeRaw`, each taking `raw: EngineRawRead` first. `facts/conversation-publication.ts` reads and writes a page's conversation facts through them (newest fact id, active and window counts, held slots, the five-step clear that `clearConversationPageFacts` runs, outcome-row delete, purge-tombstone ordinals, source-window moves and stamps, the write journal reads), `relink-publish.ts`, `conversation-relink.ts`, `conversation-relink-carry.ts`, `conversation-entity-hints.ts`, `conversation-memo.ts`, `conversation-incremental.ts` and `relink.ts` read relinked, unbacked and unlinked rows, hint pages, the memo outcome row and the page lock. It exports `RELINKED_DERIVED_ROW` and `LABEL_RETIRED_MARKER`; the caller modules re-export them. Both engines delegate each member; the Rust engine refuses them by name with `engine_capability_missing` (capability `facts`). Tests: `test/facts-conversation-sites-sql-pin.test.ts` (statement text and binds against the pre-change text in `test/helpers/facts-conversation-base-sql.ts`) and `test/engine-parity/facts-conversation-sites.test.ts` (21 parity cases).

- `src/core/engine-sql/dream-cycle.ts` — the 34 statements the dream cycle, the retriage command and the consolidate phase sent through `executeRaw`, each now a typed `BrainEngine` member taking a raw-read seam. Groups: queue and lock reads (`listDreamQueueCandidates`, `listLiveDreamCycleLocks`, `readDreamJobStatus`, job timing and submission counts for synthesis), the breaker and write-deferral config-map statements (`ensureDreamMapConfigRow`, `lockDreamMapConfigRow`, `writeDreamMapConfigRow`, `recordDreamBreakerReset`), provenance (`stampDreamPageProvenance`, `listDreamPageIds`, `countDreamProvenancePages`), the deferral receipt and journal reads, consolidation facts and takes, and the synthesis page, source, revision and verify-epoch reads. The statement text is the text of the callers it came from; `COMMITTED_OUTPUT_REQUESTS_SQL` stays exported (re-exported by `cycle/synthesize-postprocess.ts`). Pinned by `test/dream-cycle-sites-sql-pin.test.ts` and `test/engine-parity/dream-cycle-sites.test.ts`; the Rust engine refuses each member by name.
- `src/core/engine-sql/contradictions-cycle.ts` — the statements of the edge-contradiction cycle (`cycle/edge-contradictions.ts`), the eval scoped read (`eval-contradictions/scoped-read.ts`), the cost prompt and the suspected-contradictions eval as 17 typed BrainEngine members, each running the text its caller ran on the engine's `executeRaw`. Thirteen cover the edge proposals: the candidate query (a single type list, or per-source lists with a pending cutoff), known proposals by evidence hash, link contexts, record (null when the hash exists), read, closure landed, evidence, hash, stale, status, reject-open, undone and the reverted count. `listLiveChunksByIds` and `listLiveTakesByIds` apply the caller's page read policy and trust floor (the take holder text is a vetted builder, `takeHolderSql`); `readLastContradictionsPromptVersion` and `listEvalCandidateQueries` read the newest run and the capture queries. The Rust engine refuses each by name (`engine_capability_missing`); `rust/docs/store/contradictions.md` lists what the store would need.
- `src/core/engine-sql/ontology-repair.ts` — the statements of `facts/ontology-rekey.ts` and `repair/ontology-facts.ts` as six typed members: `listRekeyLosers`, `repointSupersededToKept`, `clearOntologySlots`, `deleteRekeyLosers`, `listOntologyFactCandidates` and `restoreOntologyFact` (its `expired` flag is evaluated after the update). `listRekeyLosers` takes the move's where, entity and sms texts and sends only those in the closed shape lists (`rekeyMoveSql`); any other text throws before a statement is sent. `dropRekeyDuplicates` and `dropPhantomMigrationDuplicates` take a `RekeyEngine` (the four re-key members). Source incarnations come from the facts-repair member `listSourceIncarnations`. The Rust engine refuses each by name; `rust/docs/store/ontology.md` lists what the store would need.
- `src/core/engine-sql/admin-reads.ts` — the two reads of `ops/admin.ts` as typed members: `listVisiblePageSlugs(slugs, sourceIds, policy)` (`most_connected` under the read or access page policy, rendered in the caller's access record) and `readPagesForVersionHistory(pageIds)` (`get_versions`). The Rust engine refuses each by name; `rust/docs/store/stats.md` lists what the store would need.

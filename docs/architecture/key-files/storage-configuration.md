# Key files: Storage configuration

[Subsystem index](../KEY_FILES.md). Read only the entries relevant to your change.
Current behavior and load-bearing invariants; history belongs in Git and CHANGELOG.

- `src/core/storage-config.ts` — Storage tiering: `loadStorageConfig` reads `gbrain.yml` (warning once per process for each unknown key under `storage:`; an optional `keep_db` prefix list, present only when declared, is normalized like the tiers and matched by `isKeepDbSlug`, consumed by `repair/keep-db-policy.ts`), normalizes deprecated keys (`git_tracked`/`supabase_only`) to canonical (`db_tracked`/`db_only`) with once-per-process deprecation warning, and runs `normalizeAndValidateStorageConfig` (auto-fixes missing trailing `/`, throws `StorageConfigError` on tier overlap). Path-segment matcher: `media/x/` does NOT match `media/xerox/foo`. `isDeclaredDbOnlySlug` matches a lowercase page slug against the declared db_only dirs case-insensitively; managed persistence uses it to publish those pages database-only. `hasUnresolvedDbOnlyDeclaration` detects a db_only key line that resolved no directory (a multi-line flow list, a key outside `storage:`; one-line lists parse, `db_only: []` declares none, #8007); the sync baseline-commit guard refuses on it, and managed persistence turns a missing-file refusal into `storage_error`. Uses a dedicated parser for the `gbrain.yml` shape rather than gray-matter (broken on delimiter-less YAML). `DERIVE_PHASE_DB_ONLY_DEFAULTS` and `effectiveDbOnlyDirs` define generated paths that the `undeclared_db_only_pages` check accepts without adding them to `loadStorageConfig`; doing so globally would auto-gitignore paths that some brains file-back. Defaults include `reports/`, whose drift reports are database-only when they have no canonical file; reports with a recorded file stay file-backed. `findDbOnlyCollisions` detects overlap between collector outputs and declared database-only paths for the doctor check and sync's `manageGitignore` warning. Pinned by `test/storage-config.test.ts` and `test/doctor-silent-death-checks.test.ts`.

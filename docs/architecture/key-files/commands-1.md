- `src/commands/autopilot-dispatch.ts` — one autopilot tick's submissions (`dispatchAutopilotTick`): freshness syncs, the extract_atoms auto-drain, the remediation plan, and full-cycle fan-out or targeted submits. - `src/commands/backlinks.ts` — Back-link checker and fixer (enforces Iron Law). `fix` (and `fix --dry-run`) refuses once, before the scan, when the directory is a managed canonical worktree (`isManagedFilesystemPath` from `src/core/persistence/filesystem-guard.ts`, the predicate `assertManagedFilesystemWrite` uses), instead of skipping every page one by one; `check` still runs (#5341).

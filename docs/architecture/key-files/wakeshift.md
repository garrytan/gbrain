# Key files: Wakeshift report-back

[Subsystem index](../KEY_FILES.md). Read only the entries relevant to your change.
Current behavior and load-bearing invariants; history belongs in Git and CHANGELOG.

- `src/core/ops/wakeshift.ts` + `src/core/wakeshift/{client,config,events,drain,terms,forget}.ts` + `src/core/wakeshift-env-key.ts` + `src/commands/wakeshift.ts` + `src/commands/doctor/checks/wakeshift.ts` — report back to agent conversations through Wakeshift (docs/guides/wakeshift.md), off by default. `client.ts` is the in-repo HTTP client (no SDK): key parsing (`wst_` + 50 base58 with a CRC32; legacy formats refused), a fresh EdDSA `app+jwt` assertion per request, one `fetch` with a 10 s timeout and no retry, loopback-only http; endpoints subscribe, unsubscribe, end, emit, manifest merge and `/users/forget`. `config.ts` holds the host-only state: `wakeshift.enabled`/`url`/`terms_url`/`privacy_url`/`manifest_hash` in the file plane, the key (WAKESHIFT_API_KEY, which `wakeshift-env-key.ts` moves out of the environment on every config load so children never inherit it, the first value seen winning; else a 0600 `~/.gbrain/wakeshift.key`), the 0600 HMAC secret and the opaque Wakeshift user (HMAC over brain and principal key: `member:<id>` when bound, else `<kind>:<id>`); `wakeshiftRuntime().file` carries the file plane to the ops and the drainer, so core never reads config twice; `wakeshiftPublished` is publish gate `mcp.publish_wakeshift`, which `mcp/publish-gates.ts` resolves from the file plane and key presence only (never the DB plane; not in `PUBLISH_GATE_KEYS`). Three events (`events.ts`): `gbrain.job.finished` (`watch_job`, the get_job owner fence from `ops/jobs.ts`), `gbrain.write.settled` (`watch_write_request`, write scope, the receipt read path `receiptAccess`/`receiptVisible`/`receiptNotFound` exported from `ops/persistence.ts`, so a foreign id reads exactly like get_write_request's not_found; `target_ref` holds the `persistence_requests.id`), `gbrain.cron.finished` (`watch_cron`, admin scope, names in `wake_crons`; `gbrain wakeshift emit cron.finished` only inserts a `wake_cron_runs` row and exits 0). Every watch goes through `openWatch` (subscribe `once` 7 d, insert, roll back on failure, wake at once when settled, Wakeshift's addition through `ctx.emitToolTail`); `ctx.mcpCaller` (client name, User-Agent, request `_meta`) is set by the stdio and both HTTP transports. `terms.ts` is the shared-brain agreement step: on a brain with live access members each principal's first `watch_*` returns it until `accept_wakeshift_terms` records (principal key, version = 16 hex of SHA-256 over the two operator links) in `wake_terms_acceptances`. `forget.ts` (`forgetWakePrincipal`, over the scalar SqlQuery) is called by `removeMember` (access/members.ts), `revokeLegacyTokenById` (token-mint.ts) and `auth revoke`/`revoke --id`/`revoke-client` (commands/auth.ts): it ends the principal's open rows (`principal_revoked`), drops its acceptance and queues `wake_forgets` for users not derived from a member that outlives the credential. `drain.ts` is pull reconciliation: `gbrain serve` and `MinionWorker.start` run a 5 s unref'd timer, `gbrain jobs work` (PGLite) a final pass; one candidate query LEFT JOINs each event family (`minion_jobs`, `persistence_requests` committed with no recovery record or failed/conflict/cancelled, the first `wake_cron_runs` row after the watch began), at most 20 leased rows a tick; the emit id `<event>:<target>:<marker>:<row>:<namespace>` (12 hex of the watch's user and creation time, so brains on one key never collide); the claim re-checking backoff and attempts, a settle only under the claim's lease, the principal re-checked before each emit (a revoked one ends and queues its forget), on a shared brain the terms acceptance re-checked (`terms_not_accepted` ends), 5 attempts on 30 s/2 m/8 m/30 m (429 honours Retry-After, other 4xx final), dead/revoked/expired rows ended at Wakeshift once; up to 10 leased queued forgets a tick on the same schedule. Payloads are pointers: ids, status, operation, times, next call; never page text, slugs or cron output. Tables: v290 `wake_subscriptions`, v291 `wake_crons`, `wake_cron_runs`, `wake_terms_acceptances`, `wake_forgets` and `wake_subscriptions.target_ref`. The CLI (`enable` with consent, the terms links on a shared brain, GET /app, the manifest merge and its stored hash; `disable`, `status` with the stale-manifest line, `test`, `cron add|remove|list`, `emit`; `watch` dispatches to `wakeshift-watch.ts`) is the only writer of the file-plane keys. Doctor warns on key mode, no usable key, members without terms links, dead and id_reused rows, forgets older than a day, unregistered cron emits and a stale manifest. Tests: `test/wakeshift-client.test.ts`, `test/wakeshift.serial.test.ts` and `test/wakeshift-pr2.serial.test.ts` (repo-less PGLite against `test/helpers/fake-wakeshift.ts`), `test/e2e/wakeshift-postgres.test.ts` and `test/e2e/wakeshift-pr2-postgres.test.ts`.

# Key files: Files And Sync (2/2, more)

Current behavior and load-bearing invariants; history belongs in Git and CHANGELOG.

- `src/core/repair/slug-spelling.ts` — `gbrain repair slug-spelling --source <id>`, explicit-only, preview-bound, destructive, trusted local only. `scanSlugSpellings` lists the pages of one source whose slug is not `normalizeSlug(slug)` (bounded: `SLUG_SPELLING_LIMIT` listed, `SLUG_SPELLING_SCAN_LIMIT` read) and classifies each: `move`, `needs_human` (`slug_spelling_collision`: a live or soft-deleted page holds the normal slug, or two stored spellings share it; `samePrintedName` finds every other stored spelling through the spelling index (`spellingKeys`, else `SCAN_KEY_SQL`), whatever the scan cap, and the apply runs it again under the page locks; `__setSlugSpellingScanLimitForTests` lowers the cap in tests) or `rename_file_first` (`fileEvidence`: the recorded file is not at the normal path, is missing, or a file sits at the old spelling's path; `checkoutPath`). The plan hash binds the brain, the source incarnation and each page's id, revision, origin, source path and file evidence; an apply reads them all again before moving anything and refuses `changed_since_preview`. `fileEvidence` counts a recorded file only when the resolved path is an existing regular file (the resolver returns the direct path even when absent). `movePage` runs per page in one `maintenanceTransaction` inside `withStoredSlug(page.slug)`, so both page keys it locks are the stored spelling and the normal slug (the same legacy key an existing-page writer locks) and the revision check, belief capture and rename all run under them: `updateSlug` (version preimage, alias, slug-keyed bindings, the page's `files` rows through `moveSlugBindings`, counted before it for `attachments_moved`), the `files.page_slug` rekey of this source's null-page-id rows of the old slug (the spelling names one page under the page locks; `moveSlugBindings` moves only page-id-bound rows), then `carryGuards` (`repair/slug-spelling-guards.ts`), inside a belief batch; a fault rolls the page back whole and a replayed set reports `already_moved`. A managed brain refuses `managed_remedy_unavailable` (a person is needed, no command named). A Postgres database whose encoding is not UTF8 refuses `slug_spelling_encoding` before anything is read (`assertUtf8`, via `serverEncoding`; the collision lookup runs `SPELLING_KEY_SQL`, which only UTF8 can evaluate). `SLUG_COLUMNS_MOVED` and `SLUG_COLUMNS_EXEMPT` (each with a reason) classify every slug-holding column of the schema; the schema guard in `test/repair-slug-spelling.test.ts` fails when a new one is unclassified. Tests: `test/repair-slug-spelling.test.ts`, `test/engine-parity/repair-slug-spelling.test.ts` (the Rust arm stops on `executeRaw`, pinned by exact text).
- `src/core/repair/slug-spelling-guards.ts` — `carryGuards(tx, sourceId, from, to)`, run by the slug-spelling move under both page locks. Active guards compare a page's exact current slug. `fact_purges` and `take_purges` rows with the old subject are copied to the normal slug (the old rows stay; a tombstone the normal slug already holds is kept, never overwritten) with their request and time (for facts also actor and reason). Quarantine holds (`write_gate_holds`) need nothing here and never stop a move: a bound hold follows its `page_id`, and an unbound hold under the old spelling reaches the moved page through the rename record `updateSlug` writes (`holdAppliesToPageSql`, write-gate-binding.ts), including one a writer records under the old spelling while or after the move runs; no hold is re-keyed or decided. `assertGuardTablesReadable` refuses (`writer_coordinator_required`, naming the table and the fix: the table owner without FORCE ROW LEVEL SECURITY, or a BYPASSRLS role) whenever `row_security_active` holds for any table of a schema on the search path (`rowSecurityBrainTables`; the refusal names the tables the move reads or re-keys first, the rest by count), because no policy check proves a policy shows every row (a `USING (false)` policy hides them all), in the preview and again under the page locks before anything is read. Tests: `test/repair-slug-spelling.test.ts` (bound, unbound and late holds keep their rows out of the moved page), `test/repair-slug-spelling-postgres.test.ts` (a hold re-opened during the move and one recorded under the old spelling after it, on a second connection, and the stored spelling's page lock).

For a weekly check, a read-only script could be:

```bash
#!/bin/sh
set -eu
df -P / | awk 'NR==2 {
  gsub(/%/, "", $5)
  printf "root filesystem: %s%% used, %s available\n", $5, $4
  if ($5 >= 85) exit 2
}'
docker system df
sudo du -xhd1 /var/backups /var/lib/docker 2>/dev/null | sort -h
```

Run it from a systemd timer or monitoring agent, and alert at 85% while keeping the cleanup commands manual and retention-based. Also consider configuring Docker log rotation explicitly, for example with `max-size` and `max-file`, then verify the active containers inherit that configuration during their next recreation.

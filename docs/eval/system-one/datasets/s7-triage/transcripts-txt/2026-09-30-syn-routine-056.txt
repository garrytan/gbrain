Could the import order differ if the project has a `pyproject.toml` configuration? I want to understand why another directory might sort differently.

[assistant]
Yes. Ruff’s import sorting can be affected by configuration in `pyproject.toml`, `ruff.toml`, or `.ruff.toml`. Common settings include the selected rules, known first-party modules, third-party sections, forced wrapping, relative-import behavior, and line length. For example:

```toml
[tool.ruff]
line-length = 88

[tool.ruff.lint]
select = ["E", "F", "I"]

[tool.ruff.lint.isort]
known-first-party = ["reporting"]
force-single-line = false
combine-as-imports = true
```

A package listed in `known-first-party` is separated from third-party imports differently than an unrecognized package. Per-file ignores can also make a diagnostic disappear without changing the sorting behavior. To see the effective Ruff configuration for a path, use the project’s Ruff version and inspect the repository config; command-line options can override it. Checking the config is especially useful when one directory contains namespace packages or generated files.

Keeping both can still be useful if you want a dedicated, fast signal that a required fixture is present, but it does not test anything substantially different from the helper assertion.

I’d use one of these approaches:

```python
def load_fixture(name: str) -> dict:
    path = Path(__file__).parent / "fixtures" / name
    assert path.is_file(), f"Missing fixture: {path}"
    return json.loads(path.read_text(encoding="utf-8"))
```

Then keep the behavioral test only:

```python
def test_catalog_payload():
    payload = load_fixture("catalog_payload.json")
    assert payload["status"] == "ready"
    assert payload["items"] == [
        {"sku": "A-100", "quantity": 2},
        {"sku": "B-200", "quantity": 1},
    ]
```

This catches a typo immediately and reports the intended path. If several tests depend on the same fixture and you want fixture inventory checked independently, retain the existence test; otherwise, omit it to avoid duplicate coverage.

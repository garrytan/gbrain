The link says: “Password recovery is unavailable because no recovery method was configured. To continue, press and hold Reset for 10 seconds.” There is no other option. How can I record the current settings before doing that?

[assistant]
You can record the visible settings without knowing the admin password only if the router exposes them elsewhere. Check these sources:

- The internet service setup document or connection email
- A device already connected to the Wi-Fi, whose network settings show the Wi-Fi name
- A phone or computer’s saved Wi-Fi details
- The router’s status page, if any portion is accessible without login
- Internet-provider instructions for connection type, such as automatic IP, PPPoE, or VLAN

On a connected computer, you can list the network details.

Windows:
```text
ipconfig /all
```

macOS:
```text
networksetup -listallhardwareports
networksetup -getinfo Wi-Fi
```

Linux:
```text
nmcli connection show
nmcli device show
```

These commands may show the local gateway and connection type, but they will not reveal the router’s admin password. Save notes locally, and redact Wi-Fi passwords if you paste anything for review.

Use this general sequence, while treating the model’s manual as the final authority:

2. Record the Wi-Fi name, Wi-Fi password, and any provider-specific details in a temporary local note.

9. Follow the initial setup wizard. Create a new, unique admin password and store it in a password manager.
10. Restore the previous Wi-Fi name and password if you want saved devices to reconnect automatically.
11. Confirm internet access, then update the router firmware if the setup page offers a trusted update.
12. Reconnect devices gradually and check that the router’s time and status pages look normal.

A factory reset may briefly expose default Wi-Fi credentials, so avoid doing this in a public or shared location.

[assistant]
Yes, keeping Ethernet connected is usually helpful. It gives the laptop a direct local connection while the router restarts and lets you open the setup page without relying on the default Wi-Fi.

Before pressing the button, verify that the cable runs from the laptop to a LAN port on the router, not to the router’s Internet/WAN port. Then:

- Close any unsaved browser pages.
- Leave the modem cable connected unless the manual specifically says to disconnect it.
- Press and hold the recessed Reset button for exactly the interval shown by the router’s instructions.
- Release it when the indicator lights change.
- Wait for the router to finish restarting; several minutes is normal.
- If the laptop does not obtain an address, unplug and reconnect the Ethernet cable or renew the address.

Do not use the label’s setup password as the new admin password unless the setup wizard explicitly requires it; create a separate admin password.

I need a regex to strip trailing whitespace from log lines. It should remove spaces and tabs at the end of each line, but leave indentation and spaces inside the line unchanged.

[assistant]
Use this pattern in multiline mode:

```regex
[ \t]+$
```

Replace each match with an empty string. The character class limits the match to spaces and tabs, and `$` anchors it to the end of each line when multiline matching is enabled. For example, in Python:

```python
import re

cleaned = re.sub(r"[ \t]+$", "", text, flags=re.MULTILINE)
```

This does not remove leading indentation or spaces between words.

Does `$` behave correctly before both LF and CRLF line endings?

[assistant]
It works with LF line endings. With CRLF input, the carriage return can remain because `$` may match before `\n` while `\r` is still part of the text. A portable pattern is:

```regex
[ \t]+(?=\r?$)
```

In Python:

```python
cleaned = re.sub(r"[ \t]+(?=\r?$)", "", text, flags=re.MULTILINE)
```

This removes spaces and tabs only when they are followed by an optional carriage return and the end of the line. It preserves the CRLF separator itself.

I also need a JavaScript version for a whole string, including Windows-style line endings.

[assistant]
In JavaScript, use the multiline flag and include the optional carriage return in a lookahead:

```js
const pattern = /[ \t]+(?=\r?$)/gm;

const text =
  "INFO  start job   \r\n" +
  "    indented message\t \r\n" +
  "\r\n" +
  "already-clean\n";

const cleaned = text.replace(pattern, "");

console.log(JSON.stringify(cleaned));
```

Output:

```text
"INFO  start job\r\n    indented message\r\n\r\nalready-clean\n"
```

The `g` flag replaces every match, and `m` makes `^` and `$` operate per line. Since the pattern matches only spaces and tabs, it will not remove other trailing characters.

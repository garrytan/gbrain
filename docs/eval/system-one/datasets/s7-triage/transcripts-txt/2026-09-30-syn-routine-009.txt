I have a folder of vacation photos with unhelpful names like IMG_4381.JPG and DSC_0027.JPG. I’d like to rename them using the date they were taken, preferably from the EXIF metadata. Can you help me make a small script?

[assistant]
Sure. A Python script can read each image’s EXIF `DateTimeOriginal` value and rename files using a format such as `2024-07-18_143205.jpg`. To avoid overwriting files taken in the same second, it can add a counter when necessary.

First, install Pillow:

```bash
python -m pip install Pillow
```

Create a file named `rename_photos.py` in the photo folder:

```python
from pathlib import Path
from datetime import datetime
from PIL import Image, UnidentifiedImageError

PHOTO_DIR = Path(".")
EXTENSIONS = {".jpg", ".jpeg", ".png", ".tif", ".tiff"}
DRY_RUN = True

def get_taken_at(path):
    try:
        with Image.open(path) as image:
            exif = image.getexif()
            value = exif.get(36867) or exif.get(306)
            if not value:
                return None
            return datetime.strptime(str(value), "%Y:%m:%d %H:%M:%S")
    except (UnidentifiedImageError, OSError, ValueError):
        return None

photos = [
    path for path in PHOTO_DIR.iterdir()
    if path.is_file() and path.suffix.lower() in EXTENSIONS
]

for path in sorted(photos):
    taken_at = get_taken_at(path)
    if taken_at is None:
        print(f"SKIP   {path.name} (no usable EXIF date)")
        continue

    stem = taken_at.strftime("%Y-%m-%d_%H%M%S")
    candidate = path.with_name(stem + path.suffix.lower())
    counter = 2

    while candidate.exists() and candidate != path:
        candidate = path.with_name(f"{stem}_{counter}{path.suffix.lower()}")
        counter += 1

    print(f"{path.name} -> {candidate.name}")

    if not DRY_RUN:
        path.rename(candidate)
```

Leave `DRY_RUN = True` for the first run. It will print proposed changes without renaming anything.

I’m on Windows and would rather use PowerShell if possible. Also, some files may have spaces in their names, and I want files without EXIF dates left alone. Is there a way to preview the changes and avoid collisions?

[assistant/analysis]
Yes. PowerShell can call a small Python script, but it is also practical to use the Windows `exiftool` utility, which handles EXIF more reliably than trying to parse image files in PowerShell itself.

Install ExifTool, then place `rename-photos.ps1` in the photo folder:

```powershell
$DryRun = $true
$Extensions = @(".jpg", ".jpeg", ".tif", ".tiff", ".png")

function Get-ExifDate($File) {
    $raw = & exiftool -s3 -DateTimeOriginal -d "%Y:%m:%d %H:%M:%S" -- "$File" 2>$null
    if ($LASTEXITCODE -ne 0 -or [string]::IsNullOrWhiteSpace($raw)) {
        return $null
    }

    try {
        return [DateTime]::ParseExact(
            $raw.Trim(),
            "yyyy:MM:dd HH:mm:ss",
            [Globalization.CultureInfo]::InvariantCulture
        )
    }
    catch {
        return $null
    }
}

$files = Get-ChildItem -File | Where-Object {
    $Extensions -contains $_.Extension.ToLowerInvariant()
}

foreach ($file in $files | Sort-Object Name) {
    $date = Get-ExifDate $file

    if ($null -eq $date) {
        Write-Host "SKIP   $($file.Name) (no usable EXIF date)"
        continue
    }

    $base = $date.ToString("yyyy-MM-dd_HHmmss")
    $extension = $file.Extension.ToLowerInvariant()
    $candidate = Join-Path $file.DirectoryName ($base + $extension)
    $counter = 2

    while ((Test-Path -LiteralPath $candidate) -and
           ($candidate -ne $file.FullName)) {
        $candidate = Join-Path $file.DirectoryName (
            "{0}_{1}{2}" -f $base, $counter, $extension
        )
        $counter++
    }

    Write-Host "$($file.Name) -> $(Split-Path $candidate -Leaf)"

    if (-not $DryRun) {
        Rename-Item -LiteralPath $file.FullName `
            -NewName (Split-Path $candidate -Leaf)
    }
}
```

Run the preview with:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\rename-photos.ps1
```

Because `$DryRun` is true, it only displays changes. Spaces are handled by `-LiteralPath`, and files without a usable `DateTimeOriginal` value are skipped.

Could the script also use `DateTimeDigitized` as a fallback when `DateTimeOriginal` is missing? I’d like it to report which EXIF field supplied each date, while keeping the same exclusions and modified-time overrides.

[assistant]
Yes. Have the date function request both EXIF fields and return both the parsed date and its source. `DateTimeOriginal` should be checked first, followed by `DateTimeDigitized`.

Here is the revised function and loop. Keep your existing `$ExcludeNames` and `$UseModifiedTime` lists:

```powershell
function Get-ExifDate($File) {
    $raw = & exiftool -s3 `
        -DateTimeOriginal `
        -DateTimeDigitized `
        -d "%Y:%m:%d %H:%M:%S" `
        -- $File.FullName 2>$null

    if ($LASTEXITCODE -ne 0) {
        return $null
    }

    $values = @($raw | ForEach-Object { $_.Trim() })

    foreach ($item in $values) {
        if ([string]::IsNullOrWhiteSpace($item)) {
            continue
        }

        try {
            $date = [DateTime]::ParseExact(
                $item,
                "yyyy:MM:dd HH:mm:ss",
                [Globalization.CultureInfo]::InvariantCulture
            )

            # ExifTool returns the requested tags in request order.
            $index = [array]::IndexOf($values, $item)
            if ($index -eq 0) {
                return [PSCustomObject]@{
                    Date   = $date
                    Source = "DateTimeOriginal"
                }
            }
            else {
                return [PSCustomObject]@{
                    Date   = $date
                    Source = "DateTimeDigitized"
                }
            }
        }
        catch {
            continue
        }
    }

    return $null
}

foreach ($file in $files | Sort-Object Name) {
    if ($UseModifiedTime -contains $file.Name) {
        $result = [PSCustomObject]@{
            Date   = $file.LastWriteTime
            Source = "modified time"
        }
    }
    else {
        $result = Get-ExifDate $file
    }

    if ($null -eq $result) {
        Write-Host "SKIP   $($file.Name) (no usable date)"
        continue
    }

    $base = $result.Date.ToString("yyyy-MM-dd_HHmmss")
    $extension = $file.Extension.ToLowerInvariant()
    $candidate = Join-Path $file.DirectoryName ($base + $extension)
    $counter = 2

    while ((Test-Path -LiteralPath $candidate) -and
           ($candidate -ne $file.FullName)) {
        $candidate = Join-Path $file.DirectoryName (
            "{0}_{1}{2}" -f $base, $counter, $extension
        )
        $counter++
    }

    Write-Host "$($file.Name) [$($result.Source)] -> $(Split-Path $candidate -Leaf)"

    if (-not $DryRun) {
        Rename-Item -LiteralPath $file.FullName `
            -NewName (Split-Path $candidate -Leaf)
    }
}
```

One caveat: parsing output by position can become ambiguous if ExifTool omits empty fields. A more robust approach is to query each tag separately, in priority order:

```powershell
function Get-ExifDate($File) {
    foreach ($tag in @("DateTimeOriginal", "DateTimeDigitized")) {
        $raw = & exiftool -s3 "-$tag" `
            -d "%Y:%m:%d %H:%M:%S" `
            -- $File.FullName 2>$null

        if ($LASTEXITCODE -ne 0 -or [string]::IsNullOrWhiteSpace($raw)) {
            continue
        }

        try {
            return [PSCustomObject]@{
                Date   = [DateTime]::ParseExact(
                    $raw.Trim(),
                    "yyyy:MM:dd HH:mm:ss",
                    [Globalization.CultureInfo]::InvariantCulture
                )
                Source = $tag
            }
        }
        catch {
            continue
        }
    }

    return $null
}
```

Use the second function in the earlier loop. It preserves the priority order and clearly reports either `DateTimeOriginal`, `DateTimeDigitized`, or `modified time`.

function Get-AvailableName($Stem, $Extension) {
    if (-not $NextCounter.ContainsKey($Stem)) {
        $NextCounter[$Stem] = 1

    do {
        $number = $NextCounter[$Stem]

        if ($number -eq 1) {

        $key = $name.ToLowerInvariant()

    $ReservedNames[$key] = $true
    return $name
}

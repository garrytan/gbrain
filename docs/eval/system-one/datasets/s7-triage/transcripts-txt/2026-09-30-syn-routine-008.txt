My home Wi‑Fi keeps dropping in one room, but it works normally everywhere else. I’m using a fairly ordinary dual-band router. Can you walk me through basic troubleshooting?

[assistant]
Sure. Since the problem is limited to one room, start by checking whether it affects one device or several.

1. In the problem room, test the same device on both the 2.4 GHz and 5 GHz network names, if your router lists them separately.
2. Try a second device in that room.
3. Note whether the connection fully disconnects, becomes very slow, or only shows “no internet.”
4. Temporarily move the device about 1–2 meters closer to the doorway and see whether stability improves.
5. Check whether anything recently changed in that room, such as furniture, a large appliance, or a metal shelf.

Before changing settings, run a simple test from the affected device. On Windows, open Command Prompt and use:

```text
ipconfig
ping 192.168.1.1 -n 30
ping 1.1.1.1 -n 30
```

Replace `192.168.1.1` with your router’s gateway if different. The first ping tests the local wireless link; the second tests the internet connection.

I noticed one odd thing: after I walk from the hallway into the room, the laptop sometimes stays connected to `HomeNet-2G` even though I selected the 5 GHz network earlier. The two names are separate now. Could Windows be switching by itself?

[assistant][assistant]
Yes. Windows can automatically connect to a saved network when its connection settings permit it. It normally will not switch between two distinct SSIDs solely because you walked around, unless the 2.4 GHz profile is configured to connect automatically and the 5 GHz signal becomes weak or briefly disappears. The adapter or driver may also reassociate during a short drop.

Check which profile is active:

```text
netsh wlan show interfaces
```

To inspect saved profiles:

```text
netsh wlan show profiles
```

In Windows Wi‑Fi settings, open the saved network list and check the connection options for `HomeNet-2G` and `HomeNet-5G`. For a simple test, turn off “Connect automatically when in range” for `HomeNet-2G`, leaving it enabled for `HomeNet-5G`. Then manually select the 5 GHz network.

You can also use:

```text
netsh wlan set profileparameter name="HomeNet-2G" connectionmode=manual
netsh wlan set profileparameter name="HomeNet-5G" connectionmode=auto
```

Use the exact profile names shown by `netsh wlan show profiles`. This does not delete either profile or change the router. Afterward, walk between the hallway and room and check the active SSID with `netsh wlan show interfaces`.

I forgot the admin password for my home router. I’m trying to look up the safest way to reset it without accidentally breaking the internet settings. What information should I gather first?

[assistant]
Start by identifying the router’s make and model from the label on the underside or back. Also note whether your internet connection uses a separate modem or an all-in-one gateway. Before resetting, gather:

- The router model and hardware revision
- The current Wi-Fi network name and Wi-Fi password, if you still have them
- Your internet provider’s support number or setup instructions
- Any custom settings you may need to recreate, such as port forwarding, parental controls, guest Wi-Fi, or VPN settings
- A paper clip or similar tool for the recessed reset button
- A phone or computer that can connect by Ethernet, if possible

Do not press the reset button yet. First check the manufacturer’s support page for the exact reset procedure and the default address used to open the setup page.

I see a sticker with a serial number, a MAC address, and something that looks like “Model: RT-AC57U.” There’s one box from the internet provider and a separate black router. How can I confirm the model and find the official instructions?

[assistant]
“RT-AC57U” is the model identifier; “AC1200” describes the wireless class. Since there is a separate provider box and router, the provider box is probably the modem or network terminal, while the black device is the router.

To find the official instructions:

1. Open a browser and search for the manufacturer’s support site, not a download site or forum.
2. Search the support site for `RT-AC57U`.
3. Check the label or support page for a hardware revision, such as V1, V2, or V3. Instructions can differ by revision.
4. Open the user manual and the FAQ or knowledge-base article for “forgot administrator password” or “factory reset.”
5. Compare the product photo and label layout with your device.
6. Avoid entering the serial number or MAC address into an unofficial page.

The manual should tell you how long to hold the reset button, what the status lights do, and which address to use afterward. Keep the provider box powered on, but do not change its settings during the router reset.

I found a support page and a manual for RT-AC57U V2. The manual says to hold the reset button for about five seconds, but another page says ten seconds. Which timing should I use? Also, should I unplug the provider box first?

[assistant]
Use the instructions for the exact hardware revision shown on your label. If the V2 manual says approximately five seconds and the manufacturer’s current support article says ten seconds, follow the current article, provided it explicitly lists RT-AC57U V2. A longer hold may simply ensure the reset is recognized, but do not hold the button indefinitely.

A cautious sequence is:

1. Leave the provider box powered on.
2. Turn on the router and wait until its normal power and connection lights settle.
3. Use a paper clip to press the recessed reset button.
4. Hold it for the duration specified by the V2 support article.
5. Release it when the power or status light changes as described.
6. Wait several minutes for the router to restart. Do not unplug it during this process.

If the article is ambiguous, use the manual’s procedure or contact the manufacturer’s support channel before proceeding. A factory reset normally clears the router’s settings, not the provider box’s settings.

[user]
I checked again: the current support article specifically says RT-AC57U V2 and says to hold Reset for five seconds until the power LED flashes. It also says the default setup address is router.asus.com. What should I expect after the reset?

[assistant]
After the reset, expect the router to return to its out-of-box configuration:

- The administrator username and password will return to the setup defaults or prompt you to create a new administrator password, depending on the firmware.
- The Wi-Fi network name and Wi-Fi password will return to the values printed on the router label, or the setup wizard will ask you to create them.
- Custom settings such as guest networks, port forwarding, DNS changes, access schedules, and parental controls will be removed.
- The router may briefly lose internet access while it restarts.
- Devices that were using the old Wi-Fi name or password may disconnect.

Keep the provider box powered on. Connect a computer to one of the router’s LAN ports with an Ethernet cable if you can. Then open `http://router.asus.com` or the local address listed in the manual. If that name does not work, try the default local address documented for the V2 model. Use only the router’s official setup screen; do not install browser extensions or “password recovery” utilities.

[user]
I don’t have an Ethernet cable nearby, but I can use my phone over Wi-Fi. Is that okay? Also, I’m worried that the reset might change anything with the internet provider box.

[assistant]
Using the phone over Wi-Fi is usually fine, although Ethernet is more reliable during setup. After the reset, connect the phone to the router’s default Wi-Fi network. Its name and initial key may be printed on the router label or shown by the setup wizard.

The reset should not alter the provider box. It only clears settings stored in the router. The main exception is a setup where the router itself stores special provider credentials or connection settings. If the provider uses PPPoE, a static WAN address, VLAN tagging, or another nonautomatic configuration, you may need those details again. Check the provider’s paperwork or support page before resetting if you see such terms.

After connecting:

1. Turn off mobile data temporarily so the phone stays on the router.
2. Open a browser and visit `http://router.asus.com`.
3. Complete the setup wizard.
4. Create a new administrator password and record it in a password manager.
5. Set a Wi-Fi name and strong Wi-Fi password.
6. Confirm that the WAN or internet status shows connected.
7. Reconnect your devices using the new Wi-Fi details.

The provider box has a label saying “DHCP,” and the router’s internet type was set to Automatic IP before I forgot the password. Does that mean I can just use the normal setup wizard? What should I record before pressing Reset?

[assistant]
“DHCP” and “Automatic IP” usually mean the router receives its internet address automatically from the provider box, so the normal setup wizard is likely appropriate. It is not an absolute guarantee, because other settings could still be present, but you probably do not need a username or password from the provider.

Before pressing Reset, record or photograph only the information you need, while avoiding unnecessary exposure of the serial number or MAC address:

- Current Wi-Fi network name
- Current Wi-Fi password, if visible on a connected device or existing label
- Any device names or settings you want to recreate
- The router model and hardware revision
- The provider box’s cable connections, especially which cable goes to the router’s WAN/Internet port
- Any custom settings you remember, such as a guest network or port forwarding

Do not photograph passwords if the image will sync broadly or remain in an unsecured gallery. If the old Wi-Fi credentials are still printed on the router, you can use them after the reset; otherwise, the setup wizard may generate or request new ones.

When reconnecting cables, the provider box should connect to the router’s port labeled WAN, Internet, or with a globe symbol. Computers and other wired devices go into the numbered LAN ports.

I wrote down the cable arrangement and the old Wi-Fi details. I also found a small paper clip. Can you give me a precise reset and setup checklist, including what to do if router.asus.com does not open?

[assistant]
Use this checklist:

1. Keep the provider box and router connected and powered on.
2. Wait until the router has finished its normal startup.
3. Confirm the provider-box cable is in the router’s WAN/Internet port.
4. On your phone, temporarily disable mobile data and any VPN.
5. Locate the recessed Reset button.
6. Press and hold it for five seconds, matching the RT-AC57U V2 support article.
7. Release it when the power LED flashes.
8. Wait several minutes. Do not press buttons or unplug either device during the restart.
9. Open Wi-Fi settings and join the router’s default network using the label or setup information.
10. Open a browser and enter `http://router.asus.com`, including `http://`.
11. Create a new administrator password when prompted.
12. Choose Automatic IP or DHCP for the internet connection if the wizard asks.
13. Set a Wi-Fi name and password, then save the settings.
14. Reconnect the phone and test an ordinary webpage.

If `router.asus.com` does not open:

- Confirm the phone is connected to the router’s Wi-Fi, not mobile data or another network.
- Try the local router address printed in the manual, commonly `192.168.1.1` for this type of device.
- Type the address directly into the browser address bar rather than a search box.
- Try another browser or a private window.
- Restart only the phone’s Wi-Fi connection first.
- If the setup network is not visible, wait a few more minutes and check the router’s lights.
- If it still fails, use an Ethernet cable when available or consult the exact V2 manual.

6. Close other browser tabs and try a private window.
7. Disconnect and reconnect to the default Wi-Fi network.
8. Wait another two or three minutes if the router is still completing startup.

If the page opens, complete the wizard and select Automatic IP or DHCP. If neither address opens, check whether the phone received an IP address in its Wi-Fi network details. An address beginning with `192.168.1.` would be consistent with the common default network. Do not change the provider box settings.

The wizard finished and the phone reconnected with the new Wi-Fi name. The status page says WAN IP obtained, but I want to check whether anything important is still missing. What basic checks should I perform?

[assistant]
Perform these routine checks:

- Open two or three ordinary websites to confirm internet access.
- In the router status page, verify that the WAN or internet state says connected and that an address is shown.
- Confirm the phone’s Wi-Fi details show the new network name and an IP address from the router.
- Check that the router’s date and time are correct; automatic time settings are normally sufficient.
- Review the wireless security setting and confirm it uses WPA2-Personal or WPA3-Personal, not an open network.
- Confirm the administrator password was saved in your password manager.
- Check that the router’s firmware page identifies the expected RT-AC57U V2 hardware.
- Reconnect other household devices one at a time using the new Wi-Fi password.
- If you used custom features before, review the relevant pages for guest Wi-Fi, port forwarding, DNS, and access schedules. Leave them at defaults if you do not need them.

Avoid changing advanced settings merely because they are available. If internet access works and the security settings are appropriate, the basic reset and setup are complete.

[assistant]
You can leave the provider box as it is. The reset changed the router’s settings, not the provider box, and the router is receiving a WAN address successfully.

- Devices saved with the old name will not connect to the new network until you update their Wi-Fi settings.

- Remove or forget the old saved network on the phone if it remains listed, especially if the phone might automatically try to join it elsewhere.

Finally, keep the new administrator and Wi-Fi credentials in your password manager, retain the model and revision information with the router’s manual, and leave the cables connected as they are. No additional reset is needed.

There is an old entry with the printer name, and it shows one document in the queue. I also tried Add device, but it didn’t find anything new. Should I remove the old entry first?

[assistant]
Yes, but clear the queue before removing the entry so the old job does not remain in the print subsystem. Open the old printer entry, select **Open print queue**, and use **Printer > Cancel All Documents**. Wait about 10 seconds and see whether the document disappears.

If it remains, close the queue window and restart the Print Spooler service:

1. Press **Windows key + R**.
2. Enter `services.msc` and press Enter.
3. Find **Print Spooler**.
4. Right-click it and choose **Restart**.
5. Reopen the printer queue and try **Cancel All Documents** again.

Tell me whether the document disappears after the service restart.

[user]
I restarted Print Spooler, but the document still shows as “Deleting.” The queue window has been open for a few minutes, and the printer display still says it’s ready.

[assistant]
A job stuck at “Deleting” usually needs the spool files removed while the spooler is stopped. This affects queued print jobs, not your documents.

1. Close the printer queue window.
2. Open **Windows Terminal (Admin)** or **Command Prompt (Admin)**.
3. Run these commands one at a time:

```bat
net stop spooler
del /Q /F "%systemroot%\System32\spool\PRINTERS\*.*"
net start spooler
```

You should see messages similar to:

```text
The Print Spooler service is stopping.
The Print Spooler service was stopped successfully.

The Print Spooler service is starting.
The Print Spooler service was started successfully.
```

If `del` reports that no files were found, that is fine. Reopen the queue afterward and check whether it is empty.

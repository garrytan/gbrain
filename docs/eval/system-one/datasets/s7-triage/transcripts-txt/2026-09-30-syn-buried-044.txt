I forgot the administrator password for my home router. How do I look up the correct reset procedure without making things worse?

[assistant]
Start by identifying the exact router brand and model, including any hardware revision printed on the label. The reset procedure varies, and a factory reset usually erases the Wi‑Fi name, Wi‑Fi password, port forwards, parental controls, and ISP settings.

Look for a label on the underside or back, or check the router’s packaging or purchase email. Do not use a random “default password” list until you know the model. Also, distinguish the router administrator password from the Wi‑Fi password: they are often different.

Once you have the model, use the manufacturer’s official support site and search for phrases such as:
- “factory reset”
- “forgot admin password”
- “restore default settings”
- the exact model number plus “manual”

Because you still have Wi‑Fi access, first try the local management page:
- Connect to the router’s Wi‑Fi.
- Open `http://tplinkwifi.net` or `http://192.168.0.1`.
- If one does not load, try the other.
- Use the administrator credentials you set during initial setup; these may not be the same as the Wi‑Fi password.

You can confirm the gateway address instead of guessing. On Windows, run `ipconfig`; on macOS or Linux, run `ip route` or inspect the network details. The “Default Gateway” or “default via” address is normally the router’s local address. If the TP-Link Tether app is already signed in, it may let you change settings without typing the local admin password, but that depends on how the account and router were configured.

Right, back to the router. I do not see anything saved in the browser password manager, and I cannot find a recovery option in the Tether app. What exactly should I do before pressing the reset button?

[assistant]
Treat the reset as a last resort because it returns the AX55 to its factory state. Before pressing anything:

1. Confirm that the label says Archer AX55 and hardware version V1.0.
2. Photograph or write down the router label, including the default Wi‑Fi details and serial information. Do not post the full label publicly.
3. Contact your ISP and ask whether the connection uses DHCP, PPPoE, static IP, or another method. If it uses PPPoE, obtain the username and password before resetting.
4. Record your present Wi‑Fi network name and password so you can recreate them. If devices use a hidden network, note that too.
5. List any devices that need fixed addresses, such as cameras, printers, or servers.
6. Record port-forwarding rules, custom DNS servers, VPN settings, IPv6 settings, guest-network settings, and access-control rules if you can view them through the app or another signed-in device.
7. Disconnect any Ethernet devices that could be disrupted, and plan to reconnect them after setup.
8. Download the official AX55 V1 user guide and keep a phone or computer available for setup.

Do not reset while the router is installing firmware or during a power interruption. A reset does not normally require firmware recovery; it only erases configuration.

Can I make a backup of the configuration even though I cannot sign in to the admin page? Also, should I unplug the fiber box first?

[assistant]
A configuration backup normally requires administrator access, so if neither the web interface nor Tether lets you authenticate, you usually cannot create one. Do not use third-party tools that claim to extract or bypass the password; they can expose your network credentials or damage the router.

You generally do not need to unplug the fiber box, which may be an ONT or modem, before resetting the router. A safer sequence is:

1. Leave the ONT/modem powered on.
2. Unplug the router’s power adapter.
3. Wait about 30 seconds.
4. Reconnect the router and let it finish starting.
5. Locate the recessed Reset button.
6. With the router powered on, press and hold Reset with a paperclip for the duration specified in the official AX55 V1 guide—commonly around 10 seconds—until the status LEDs indicate a reset.
7. Release it and wait several minutes. Do not remove power during this process.

Use the guide’s exact LED behavior and timing rather than relying on a generic video. Afterward, connect to the default network shown on the label, open `http://tplinkwifi.net` or the gateway address, and create a new administrator password. Then select the correct internet connection type and restore settings manually. If the ISP uses PPPoE, enter those credentials; if it uses DHCP, the router may connect automatically.

What should I check after the reset, and how can I avoid locking myself out again?

[assistant]
After the reset, work through this checklist:

- Connect one computer by Ethernet if practical; it reduces setup interruptions.
- Join the default Wi‑Fi shown on the router label.
- Open `http://tplinkwifi.net` or `http://192.168.0.1`.
- Create a new, unique administrator password. Do not reuse the Wi‑Fi password, email password, or ISP password.
- Set the correct time zone and allow the router to check for current firmware through its normal administration page. Verify that any update is specifically for Archer AX55 V1.
- Configure the internet connection. Check the status page for an assigned WAN address and an “internet connected” state.
- Set a new Wi‑Fi name and a long Wi‑Fi password, then reconnect your devices.
- Recreate guest Wi‑Fi, DHCP reservations, port forwards, custom DNS, IPv6, VPN, and parental-control settings only as needed.
- Confirm that the router’s remote-management feature is disabled unless you deliberately need it.
- Test several sites, DNS resolution, wired connectivity, and Wi‑Fi from different rooms.
- Save a configuration backup after setup, if the firmware provides that option, and store it in an encrypted password manager or secure drive.

For future access, keep the administrator username and password in a reputable password manager, retain the model and hardware version, and document ISP settings separately. If the reset does not behave as described, stop repeating it and consult TP-Link support or your ISP rather than trying unofficial recovery firmware.

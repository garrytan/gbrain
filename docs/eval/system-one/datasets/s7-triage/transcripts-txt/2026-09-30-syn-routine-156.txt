Yes. This uses Python’s standard `zoneinfo` module and checks a range of New York start times:

```python
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

zones = {
    "New York": ZoneInfo("America/New_York"),
    "London": ZoneInfo("Europe/London"),
    "Sydney": ZoneInfo("Australia/Sydney"),
}

start = datetime(2026, 4, 8, 16, 0, tzinfo=zones["New York"])

for minutes in range(0, 61, 15):
    t = start + timedelta(minutes=minutes)
    print(t.strftime("%a %Y-%m-%d %I:%M %p %Z %z"))
    for label in ("London", "Sydney"):
        converted = t.astimezone(zones[label])
        print("  ", label, converted.strftime("%a %Y-%m-%d %I:%M %p %Z %z"))
```

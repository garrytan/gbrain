My inbox is overflowing with newsletters. I want to clean it up without accidentally hiding normal mail. Can you help me make a cautious plan?

[assistant]
A cautious approach is to separate cleanup into three stages: inventory, a review-only filter, and then an automatic rule.

1. Start with a small sample, such as the last 30 days.
2. Identify repeated newsletter patterns, including sender address, subject wording, and list headers.
3. Create a temporary label or folder named `Newsletter-Review`.
4. Build a filter that applies the label but does not archive or delete anything.
5. Review the results for a few days.
6. Only then decide whether to archive, mark as read, or keep future messages in that label.

Avoid filtering on broad words like “update,” “news,” or “offer” alone, because ordinary account and service messages can contain them.

  - `List-Id:`

I found a recurring newsletter from one address. It has “unsubscribe” in every message, and normal mail from that address does not appear to exist. How do I make a review-only filter?

[assistant]
In Gmail:

1. Run a search using the exact sender address, for example:
   ```text
   from:sender@example.invalid
   ```
2. Click the search-options icon at the right side of the search box.
3. Confirm the **From** field contains only the exact address.
4. Click **Create filter**.
5. Select **Apply the label**, then choose **New label**.
6. Name it something clear, such as `Newsletter-Review`.
7. Leave these unchecked:
   - Skip the Inbox
   - Mark as read
   - Star it
   - Delete it
   - Forward it
8. Decide whether to select **Also apply filter to matching conversations**. If you want to review older examples too, select it; otherwise leave it unchecked.
9. Click **Create filter**.

This will label matching messages while leaving them in the Inbox and unread state. Check that the filter summary shows the exact sender before saving.

Some newsletters use different sender addresses but the same List-ID header. Can Gmail filters match that header directly?

[assistant]
Gmail’s standard filter form does not provide a reliable field for matching arbitrary headers such as `List-ID`. You can search for some header-related text, but header searches may be inconsistent and can include false matches. For a cautious setup, use the stable sender addresses you have verified.

A practical workflow is:

1. Open a message and choose “Show original.”
2. Record the exact `List-ID` and sender address.
3. Search by the sender address:
   ```text
   from:sender@example.invalid
   ```
4. Review the results.
5. Add each verified address to a grouped search only if all messages are the same newsletter:
   ```text
   {from:sender1@example.invalid from:sender2@example.invalid}
   ```
6. Apply the same `Newsletter-Review` label and archive action.

If the sender address changes frequently, keep the rule label-only or use Gmail’s unsubscribe controls rather than attempting a broad header-based rule. Avoid matching only a domain, display name, or generic subject phrase.

I now have two filters. How do I inspect or edit them later, and how can I avoid accidentally creating duplicate rules?

[assistant]
In Gmail, open the settings gear, choose **See all settings**, then open **Filters and Blocked Addresses**. Each filter appears with its search criteria and actions.

For each filter, you can:

- Click **edit** to change the criteria or actions.
- Click **delete** to remove it.
- Use **show search options** while editing to review the exact query.
- Check whether both filters target the same sender or address group.
- Compare their actions, especially archive, label, delete, and mark-as-read settings.

To avoid duplicates:

1. Keep a small text note such as:
   ```text
   Newsletter-Review rules
   1. Exact sender: sender@example.invalid
      Actions: archive + Newsletter-Review
   2. Exact senders: sender1@example.invalid OR sender2@example.invalid
      Actions: archive + Newsletter-Review
   ```
2. Before creating a new filter, search the existing list for the address.
3. Prefer editing an existing grouped filter rather than creating another filter with overlapping criteria.
4. Periodically test each query in the Gmail search box and compare the result count.
5. Avoid adding a second rule solely because a message was not labeled; first check whether it was in Spam, Trash, or outside the date range you tested.

Gmail may apply multiple matching filters, but duplicate labels usually have little visible effect; overlapping archive, delete, or forwarding actions are more important to avoid.

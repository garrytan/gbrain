So the test passes from the project root. Could the relative path still fail in CI if CI starts pytest from another directory?

[assistant]
Yes. The current test depends on the process working directory because it passes a relative path directly to `Path`. If CI invokes pytest from the repository root, it will work as it does locally. If CI changes to another directory first, the path may fail.

A robust test can construct the fixture path relative to the test file:

```python
from pathlib import Path

from app.catalog import load_catalog


FIXTURES = Path(__file__).parents[1] / "fixtures"


def test_load_catalog():
    path = FIXTURES / "catalog" / "basic_catalog.json"
    catalog = load_catalog(path)
    assert catalog["items"][0]["sku"] == "A-100"
```

Here, `Path(__file__).parents[1]` is the `tests` directory, so the path resolves to:

```text
tests/fixtures/catalog/basic_catalog.json
```

The loader already accepts a `Path` object because `Path(path)` accepts another `Path`.

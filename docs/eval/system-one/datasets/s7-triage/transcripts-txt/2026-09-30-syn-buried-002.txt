That added the printer, but there are three old documents stuck in the queue. Windows says “Error - Printing,” and Cancel does nothing. How do I clear them safely?

[assistant]
First try the normal method, then restart the spooler if the jobs remain. Open Settings > Bluetooth & devices > Printers & scanners, select the Brother printer, choose Open print queue, select each document, and click Cancel. If they remain after about a minute, close the queue window and use an elevated Command Prompt.

Run:

```text
net stop spooler
del /q /f "%systemroot%\System32\spool\PRINTERS\*"
net start spooler
```

The first command should report that the Print Spooler service stopped, and the last should report that it started successfully. This removes pending spool files but does not uninstall the printer or its driver.

[user]
The test page printed correctly. I also noticed the printer’s IP address could change later. Is there a way to prevent that from breaking the setup?

[assistant]
Yes. The cleanest option is a DHCP reservation in your router. Sign in to the router at `http://192.168.1.1`, open the LAN, DHCP, or Connected Devices section, find the Brother printer by its MAC address, and reserve `192.168.1.84` for it. The wording varies by router.

Alternatively, configure a static IPv4 address on the printer, but make sure it is outside the router’s automatic DHCP pool and uses the correct subnet mask, gateway, and DNS values. A reservation is usually safer because the router manages the address and avoids duplicate-address mistakes. After reserving it, power-cycle the printer and confirm its network report still shows the reserved address.

Once the reservation is in place, should I remove and re-add the printer, or can I leave the current Windows setup alone?

[assistant]
You can leave the current setup alone if the reservation keeps the printer at `192.168.1.84`. Because the printer was added using a standard TCP/IP port, Windows will continue using that address.

After making the reservation:

1. Power the printer off and on.
2. Print a network configuration report.
3. Confirm the IPv4 address is `192.168.1.84`.
4. In Printer properties > Ports, confirm the selected port still points to that address.
5. Print a test page.

Only re-add the printer if the address changes or the port shows a different address. If needed, edit the existing standard TCP/IP port rather than creating a duplicate printer.

[assistant]
If the printer later shows offline even though the address is reserved, open Printer properties > Ports > Configure Port and check the protocol. RAW with port `9100` is typical for this model. You can also temporarily uncheck “SNMP Status Enabled,” since some printers appear offline when SNMP queries are blocked even though printing works.

Keep the printer driver installed, and avoid deleting the working printer entry while troubleshooting. The existing IP-based setup is preferable to automatic discovery because it is less dependent on Windows finding the printer through network broadcasts.

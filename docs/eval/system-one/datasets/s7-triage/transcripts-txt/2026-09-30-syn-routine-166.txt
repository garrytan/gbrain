[user]
What exactly gets erased when I do that?

[assistant]
A factory reset normally removes the router’s locally stored configuration, including:

- The web-admin password and any custom administrator username
- Custom Wi-Fi network names and wireless passwords
- Guest-network settings
- Port-forwarding and port-triggering rules
- DHCP reservations and local device names
- DNS, firewall, parental-control, and access-control settings
- VPN, static-route, and QoS settings
- Any customized firmware or management preferences stored in the configuration

It usually does not change the installed firmware version, and it does not erase files on computers, phones, or external storage unless the device has a separate storage feature with its own reset option. Your internet service may require details such as a connection username, password, VLAN value, or static IP settings, so check those before resetting if your provider uses them.

I’m ready. The manual says to hold reset for 10 seconds. What’s the safest sequence?

[assistant]
Use this sequence:

1. Leave the router connected to power and wait until it appears to be operating normally.
2. If possible, connect your computer to a numbered LAN port with an Ethernet cable.

If the manual says the reset must be performed while the device is powered on, follow that instruction. If it specifies a different light pattern or timing, use the manual rather than a generic procedure.

The setup page opened and asks me to create an administrator password. What makes a good one?

[assistant]
Create a new password that is unique to the router and not reused for email, shopping, banking, or other accounts. A practical approach is a long passphrase made from several unrelated words, with a few numbers or symbols if the form requires them. For example, use a private phrase patterned like:

```text
word-word-word-number-symbol
```

Do not use the router model, address, street name, phone number, birthday, or a password printed on the device. Store it in a password manager if you use one, and keep a temporary written copy in a secure place until you confirm the password manager entry works. The administrator password and Wi-Fi password can be different; using different values limits the effect of sharing the Wi-Fi password.

[assistant]
After saving the administrator password, the setup wizard may ask about the wireless network. Choose a Wi-Fi name that does not identify your address, apartment, or household members. You can reuse the previous name if you want existing devices to reconnect automatically, but only if you are comfortable doing so.

For the wireless password, choose a separate long password or passphrase. Select WPA3-Personal if every important device supports it; otherwise choose WPA2/WPA3 transition mode or WPA2-Personal, according to the available options. Avoid outdated choices such as WEP or an open, password-free network.

When you finish, let the router apply the settings and wait for the Wi-Fi network to restart. Reconnect one device first and verify that it can open a normal website before reconnecting everything else.

[assistant/assistant]
Start with the simplest checks:

Do not weaken security to WEP or leave the network open. If transition mode works but WPA3-only does not, keep the strongest mode that all of your necessary devices support and check for a firmware update for the older device later.

Sure. Start with the filesystem summary, then inspect the largest top-level directories. These commands only read information:

```sh
df -h /
sudo du -xhd1 / 2>/dev/null | sort -h
```

`df` shows free space on the filesystem, while `du` estimates usage by directory. The `-x` option keeps `du` on the same filesystem, and `-d1` limits the first report to one directory level.

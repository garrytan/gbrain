Is there a quick way to verify that Python can import it and that it is linked to Cairo correctly?

[assistant]
Yes. Run a small import and version check inside the activated virtual environment:

```bash
python - <<'PY'
import cairo

print("pycairo:", cairo.version)
print("Cairo:", cairo.cairo_version_string())

surface = cairo.ImageSurface(cairo.FORMAT_ARGB32, 16, 16)
context = cairo.Context(surface)
context.set_source_rgb(1, 1, 1)
context.paint()
print("surface:", surface.get_width(), "x", surface.get_height())
PY
```

Expected output will contain version strings and:

```text
surface: 16 x 16
```

To see which shared libraries the extension uses, locate the installed module and pass it to `ldd`:

```bash
python - <<'PY'
import pathlib
import cairo
print(pathlib.Path(cairo.__file__).resolve())
PY
```

Then run:

```bash
ldd /path/printed/by/the/previous/command
```

Look for a `libcairo.so` entry resolving to a system path, rather than `not found`.

For future setup on this Ubuntu system, the relevant commands are:

```bash
sudo apt update
sudo apt install build-essential python3-dev pkg-config libcairo2-dev zlib1g-dev

python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install pycairo
```

The distinction is that `libcairo2-dev` supplied Cairo headers and pkg-config data, while `zlib1g-dev` supplied the linker file needed during compilation. The already-installed runtime libraries were not sufficient for building the extension.

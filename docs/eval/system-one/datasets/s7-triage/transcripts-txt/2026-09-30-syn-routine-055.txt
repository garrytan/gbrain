For the rainy-day version, aim to wash the small items you’ll want fresh for the next day, rather than trying to wash everything.

Do not put these in the wash unless necessary
- Waterproof jacket or rain shell
- Shoes
- The main trousers, unless the care label allows it and they are dirty
- Bulky sweater or mid-layer if it is still clean

Suggested timing:
- Start the wash as soon as you arrive back on the second evening, ideally before dinner or other evening activities.
- Use the shortest suitable cycle with the normal temperature listed on the care labels.
- Run an extra spin if the machine allows it.
- Remove everything promptly when the cycle ends.
- Shake each item out, then hang it with space between items.
- Place socks and underwear where air can reach both sides.
- If there is a fan, use it nearby without covering the machine or heater.
- Turn heavier items once before bed.
- Pack anything that is still slightly damp in the waterproof bag only as a last resort, and keep it separate from dry clothing.

If you need to leave early, prioritize underwear and socks. A quick hand wash in the sink can be useful for those items, followed by pressing them in a clean towel to remove water. Never seal damp clothing with fully dry clothing if you can avoid it.

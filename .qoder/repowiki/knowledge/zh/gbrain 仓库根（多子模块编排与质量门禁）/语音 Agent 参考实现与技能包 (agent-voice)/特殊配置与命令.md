通过 `gbrain integrations install agent-voice` 将 `install/manifest.json` 映射的文件复制到宿主仓库 `services/voice-agent/`；本地开发在 `recipes/agent-voice/` 内执行 `npm start` 启动服务，`npm test` 跑单元测试，`npm run test:e2e` / `test:full-flow` 跑端到端，`npm run gen:baselines` 生成 eval 基线。需要设置 `OPENAI_API_KEY`、可选 `DEFAULT_PERSONA=mars`、`BRAIN_ROOT`、`TIMEZONE` 等环境变量。

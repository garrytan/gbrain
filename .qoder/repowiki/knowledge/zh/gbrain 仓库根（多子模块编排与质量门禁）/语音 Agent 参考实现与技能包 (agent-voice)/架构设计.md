本模块是 gbrain 的「recipes」之一，通过 `install/manifest.json` 被 `gbrain integrations install agent-voice` 拷贝到宿主仓库的 `services/voice-agent/` 下，作为独立 Node 应用运行。

- 入口与 HTTP 层：`code/server.mjs` 使用原生 `node:http` 自建路由，暴露 `/session`(WebRTC SDP 交换)、`/tool`(工具调用转发)、`/voice`(Twilio TwiML，可选) 等端点；静态文件由 `public/call.html` 提供浏览器侧 WebRTC 客户端。
- 会话编排：`pipeline.mjs` 串联 `prompt.mjs`(按 persona 组装 system prompt)、`tools.mjs`(工具分发)、`lib/sessions.mjs`(会话状态)、`lib/upstream-classifier.mjs`(上游意图分类)。
- 人格系统：`code/lib/personas/mars.mjs` / `venus.mjs` 导出结构化 persona 常量（含 voice 名、emoji、长提示词），由 `personas.mjs` 聚合并通过 `buildSystemPrompt` 注入到 OpenAI Realtime session。
- 安全边界：`tools.mjs` 维护三层清单——`READ_ONLY_OPS`(默认只读)、`OPTIONAL_OPS`(可通过 `tools-allowlist.local.json` 扩展)、`DENYLIST`(永久拒绝)，`dispatchTool` 永不抛异常，统一返回 `{data}` 或 `{error}` 信封，满足 D14-A 不变式。
- 外部适配：`lib/twilio-bridge.mjs` 提供 Twilio Media Stream ↔ OpenAI Realtime 桥接桩；`lib/audio-convert.mjs` 处理音频格式转换；`context-builder.example.mjs` 给出算子自定义上下文注入契约。
- 测试分层：`tests/unit/` 覆盖 persona 形状、工具白名单、上游分类器；`tests/e2e/` 用 Puppeteer 驱动浏览器发起真实 WebRTC 往返；`tests/evals/` 基于 `routing-eval.jsonl` 对 Mars/Venus 路由做回归评估。
- 依赖方向：server → tools/prompt/pipeline → lib/* → gbrain-client(调用宿主 gbrain MCP)，skills 仅声明路由触发词，不反向依赖代码。

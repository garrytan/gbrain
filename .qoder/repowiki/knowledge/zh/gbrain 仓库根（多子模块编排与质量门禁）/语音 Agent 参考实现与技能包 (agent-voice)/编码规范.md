- 所有对外暴露的 API 函数采用「成功返回 {data}，失败返回 {error} 信封」的统一结构，永不抛出未捕获异常，确保语音通话不会因错误挂起。
- 权限控制采用三段式清单：`READ_ONLY_OPS` + `OPTIONAL_OPS`(可 local.json 扩展) + `DENYLIST`(不可绕过)，并在 `getEffectiveAllowlist` 中缓存结果，测试通过 `{forceReload:true}` 重置。
- Persona 以导出常量对象形式定义（含 name/voice/emoji/prompt），由 `personas.mjs` 聚合注册，而非字符串拼接，便于单元测试校验形状。
- Skill 描述遵循 YAML frontmatter 约定（name/version/description/triggers/mutating/writes_pages），并附带同目录 `routing-eval.jsonl` 用于回归评估。
- 安装产物通过 `install/manifest.json` 声明 src→target 映射与 `resolver_rows_to_append`，由 `gbrain integrations install` 自动写入宿主仓库，禁止手动编辑目标文件。

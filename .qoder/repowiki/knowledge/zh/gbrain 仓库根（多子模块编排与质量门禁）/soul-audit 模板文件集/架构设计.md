本模块是纯数据目录，不包含任何代码，仅存放由 `soul-audit` CLI 在 Phase 2~6 中读取并渲染到仓库根目录的 `.template` 文件：
- `SOUL.md.template`：agent 身份、Vibe、Mission、Operating Principles（brain-first / signal detection / source attribution / back-linking）与沟通风格骨架。
- `USER.md.template`：用户画像占位（姓名来自 git config、时区/地点/角色/项目/联系人/偏好等通过审计交互填充）。
- `ACCESS_POLICY.md.template`：访问分级表（Full/Work/Family/None）及多用户上下文下的响应规则，供运行时策略检查引用。
- `HEARTBEAT.md.template`：按消息/每日/每 15 分钟/每周划分的定时任务清单，含 quiet hours 与 stagger 调度约定。
每个模板顶部均带有 `<!-- Generated by soul-audit. Re-run ... -->` 注释，明确其“被工具生成、可再运行覆盖”的生命周期语义；模板之间无相互依赖，仅被上层 `soul-audit` 流程消费。

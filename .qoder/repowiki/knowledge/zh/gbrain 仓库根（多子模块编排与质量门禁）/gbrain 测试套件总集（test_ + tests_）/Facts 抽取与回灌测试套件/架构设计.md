本模块是纯测试代码，按被测子系统划分文件：
- `test/facts-engine.test.ts`：以 `PGLiteEngine`（in-memory）为持久层，对 `insertFact / expireFact / listFactsByEntity / findCandidateDuplicates / consolidateFact` 等核心 API 做契约级断言。
- `test/facts-extract*.ts`：验证 `extractFactsFromTurn` 与 `parseExtractorJson` 的输入清洗、空/梦生成短路、以及 LLM JSON 字段透传（notability 等）。
- `test/facts-backstop*.ts`：通过 `__setChatTransportForTests` 注入 ChatResult stub，驱动 `runFactsBackstop` 的 eligibility/kill-switch、inline vs queue 模式分支、notabilityFilter、abort 传播。
- `test/facts-queue*.ts`：直接实例化 `FactsQueue`，验证 FIFO、per-session in-flight=1、cap overflow drop-oldest、shutdown grace window 与 AbortSignal 集成。
- `test/extract/receipt-writer.test.ts`：针对 `receiptSlug / shortRunId / writeReceipt` 的 D-EXTRACT-17/19 路径形状与 frontmatter 双保险断言。
- `test/extract/benchmark.test.ts`：校验 `validateFixturePath` 的路径白名单（相对、无 `..`、无 null byte、拒绝 symlink）与 `parseBenchmarkFixtures` 的 JSONL 严格解析。
- 其余 `facts-*.test.ts` 分别覆盖 decay、fence、visibility、canonicality、multi-tenant、separation-pglite、doctor-shape、migration-dim、recall-render、reconcile-protect-cli、meta-cache、eligibility、classif y、anti-loop、absorb-log、context-injection serial、mcp-allowlist serial、backstop-integration、drain-pending 等特性。
依赖方向单向指向 `src/core/facts/*`、`src/core/pglite-engine.ts`、`src/core/ai/gateway.ts`、`src/commands/extract-benchmark.ts`；所有 I/O 均通过 `PGLiteEngine`（内存 SQLite）或同步文件系统临时目录完成，无需外部数据库。

本模块由两类文件组成：
- test/cycle/*.test.ts：聚焦 cycle 子系统的原子能力（extract-atoms-*、synthesize-concepts-*、nightly-probe-adapters、yield-during-phase-*），通过 PGLiteEngine + resetPgliteState 在内存 PG 中构造最小数据面，直接调用 src/core/cycle/* 导出函数。
- 根级 test/autopilot-*.test.ts 与 test/jobs-*.test.ts：以 registerBuiltinHandlers 捕获真实 handler，注入 MinionWorker 或 fake worker 来驱动 autopilot-cycle、autopilot-fanout、autopilot-supervisor、autopilot-self-upgrade、jobs-watch-mode 等端到端路径。
- 隔离约定：需要进程全局状态（process.chdir、mock.module、TTY 重设）的文件显式命名为 *.serial.test.ts，由脚本 scripts/run-serial-tests.sh 串行执行；其余文件走并行 runner。
- 回归桩模式：大量测试以源码文本匹配（readFileSync(...).toMatch(/.../)）锁定常量（如 LOCK_TTL_MINUTES = 5）、CLI 矩阵与错误消息，防止重构回退。

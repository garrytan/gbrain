- 通过设置 `process.env.GBRAIN_HOME = tmp` 并使用 `mkdtempSync(join(tmpdir(), 'gbrain-*'))` 为每个测试提供隔离的 ~/.gbrain 目录，`afterEach` 中递归删除。
- 对需要持久化写入的子命令（capture、calibration）采用注入 `PGLiteEngine` 实例 + `resetPgliteState` 的方式，避免外部数据库依赖。
- 子命令内部解析器/构建器等非导出函数通过模块的 `__testing` 命名空间暴露，测试直接调用这些函数做纯函数断言。
- 涉及完整 CLI 分发的测试使用 `Bun.spawn(['bun', 'run', CLI, ...args])` 启动真实进程，并通过 `Promise.all([new Response(proc.stdout).text(), new Response(proc.stderr).text(), proc.exited])` 收集输出。
- 对外部二进制路径（如 OPENCLAW_BIN）的测试统一采用 `try/finally` 保存并恢复原始环境变量，确保测试间隔离。

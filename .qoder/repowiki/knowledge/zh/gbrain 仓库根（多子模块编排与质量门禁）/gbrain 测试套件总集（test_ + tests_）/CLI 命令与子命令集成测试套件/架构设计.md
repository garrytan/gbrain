本模块是纯测试层，按被测目标划分为三类文件：
- `test/cli-*.test.ts`：对顶层 `src/cli.ts` 的分发守卫（thin-client 模式拒绝 DB 绑定命令）、参数解析（`parseOpArgs`）、PTY runner 工具函数等做单测或轻量进程级验证；通过 `Bun.spawn(['bun', 'run', CLI, ...args])` 启动真实 CLI 进程并断言 exitCode/stdout/stderr。
- `test/commands/*.test.ts`：按子命令目录镜像组织，每个文件覆盖一个子命令的入口函数（如 `runCapture`、`runCalibration`、`runFriction`），通常借助 `__testing` 命名空间暴露内部解析器/构建器进行纯函数断言，并用临时 `GBRAIN_HOME` 目录 + 注入的 `PGLiteEngine` 模拟磁盘/DB 写回。
- `test/calibration-cli.test.ts`、`test/claw-test-cli.test.ts`：分别针对 calibration 和 claw-test 两个较复杂的子命令，构造 mock `BrainEngine` 与 `OperationContext`，断言 MCP operation 行为与 agent-runner 注册表。
依赖方向单向指向 `src/` 下的对应实现，不引入其他测试模块（仅复用 `test/helpers/reset-pglite.ts` 重置 PGLite 状态）。所有测试基于 `bun:test`，使用 `beforeEach`/`afterEach` 在 `$TMPDIR/gbrain-*` 下创建隔离的 `GBRAIN_HOME`，并在 `afterAll` 中关闭引擎连接。

- 每个已发布迁移版本拥有独立的 `test/migrations-v0_XX_Y.test.ts`，通过 `await import('../src/commands/migrations/v0_XX_Y.ts')` 动态加载 orchestrator，避免启动时全量 require。
- 对需要外部状态的用例使用 `mkdtempSync(join(tmpdir(), 'gbrain-*'))` 创建临时 HOME/脑目录，并在 `afterAll` 中 `rmSync(..., { recursive: true })` 清理。
- 通过 `process.env.HOME = tmpHome` 劫持配置读取路径，配合 `beforeEach`/`afterAll` 恢复原始环境变量，保证用例间隔离。
- 对 `tryRunPendingMigrations` 等异步流程使用 `_hooks` 选项注入假 `hasPending`/`initSchema`，并用 `retryBackoffMs: 0`、`pollIntervalMs: 1~10`、`deadlineMs: 30~100` 等极小值加速测试。
- 断言迁移在 `migrations` 数组中的相对顺序（如 `indexOf('0.21.0') < indexOf('0.22.4')`）以强制 semver 递增约束。
- 错误类用例同时检查 `err.name`、自定义属性（如 `version`/`migrationName`/`hint`/`lastBlockers`）以及 `message` 片段，确保用户可见提示稳定。

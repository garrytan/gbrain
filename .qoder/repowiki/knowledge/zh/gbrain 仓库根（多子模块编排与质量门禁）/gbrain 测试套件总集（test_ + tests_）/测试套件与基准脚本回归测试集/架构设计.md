本模块由两个并列子目录组成，全部是 bun:test 编写的回归测试，不依赖被测源码内部实现：
- `test/bench/`：纯函数单元测试，直接 import `src/core/bench/{qrels-file,correctness-gate,baseline-file}.ts`，覆盖 qrels 文件解析（legacy/federated 双形态）、recall/top1/first_relevant 指标计算、baseline 序列化 round-trip 与阈值常量。
- `test/scripts/`：对 shell 脚本与 TS 工具函数的契约级回归测试。策略分为三类：
  1) 子进程调用真实脚本 + 在 tmpdir 中搭建最小 git 仓库注入 fixture，断言退出码/stderr/stdout 行为（如 `ci-cache-hash.test.ts`、`check-proposal-pii.test.ts`、`check-key-files-current-state.test.ts`）；
  2) 通过脚本的 `--dry-run-list` 模式枚举文件集合，断言排除/包含规则与分片平衡（`run-unit-shard.test.ts`、`serial-files.test.ts`、`test-shard.slow.test.ts`、`sharding.test.ts`）；
  3) 用合成 dispatcher 复现并行分发失败传播语义（`run-verify-parallel.test.ts`），或直接 import 脚本中的纯函数做单元断言（`mine-shard-weights.test.ts` 对 `parseLog/computeWeights/serializeWeights`）。依赖方向单向指向 `scripts/*.sh` 与 `scripts/*.ts`，不反向依赖被测业务代码。

本模块按被测子系统划分为三个并列子目录：
- `test/search/`：覆盖搜索阶段（alias-hop/normalize、autocut、reranker、title-boost/title-match、return-policy、per-call-mode、graph-signals、search-stats 等），多数用例通过 `PGLiteEngine` + `resetPgliteState` 在内存 SQLite 中构造最小数据，直接调用 `src/core/search/*` 下的纯函数或轻量服务；带 `-integration.serial.test.ts` 后缀的用例（如 `autocut-integration`、`embedding-column`、`hybrid-reranker-integration`）因共享 PGLite 状态被标记为串行执行。
- `test/code-intel/`：围绕 `src/core/code-intel/recursive-walk.ts` 的 callers/callees 图遍历、sink 分类、traversal cache 与 edge densification，同样以 `PGLiteEngine.executeRaw` 手工 INSERT 最小符号图作为种子。
- `test/chunkers/`：验证 `src/core/chunkers/code.ts` 对 30+ 扩展名的语言识别与 SQL/TS/Python/Go/Rust/Java 等语言的 chunk 提取，使用同步 API 直接断言返回结构。
依赖方向单向指向 `src/core/*`，不反向依赖业务层；所有持久化均走 PGLite，避免外部数据库耦合。

- 每个 describe 块对应一个被测试函数或一组紧密相关的行为，文件名与被测源码路径一一对应（如 `brain-resolver.test.ts` → `src/core/brain-resolver.ts`）。
- 需要文件系统隔离的用例通过 `mkdtempSync(join(tmpdir(), '<prefix>-'))` 创建临时目录，并在 `afterEach` 中用 `rmSync(..., { recursive: true, force: true })` 清理。
- 涉及数据库的用例在 `beforeAll` 中 `new PGLiteEngine()` + `connect` + `initSchema`，在 `beforeEach` 中对 `pages`、`links`、`content_chunks` 等表执行 `DELETE` 重置状态。
- 回归用例顶部附带 JSDoc 注释说明关联的 bug 编号或变更（如 `Bug 11`、`D12`、`v0.36.x #967 regression`），便于追溯。
- 需要修改环境变量的用例在 `beforeEach` 中删除 `process.env.GBRAIN_BRAIN_ID`，在 `afterEach` 中恢复 `process.env = { ...originalEnv }`，避免测试间泄漏。
- 断言风格统一使用 `expect(...).toBe(...)` / `toThrow(...)` / `toContain(...)`，错误场景通过自定义错误类（如 `BrainWriterError`、`DuplicateMountPathError`、`UnknownBrainError`）进行精确匹配。

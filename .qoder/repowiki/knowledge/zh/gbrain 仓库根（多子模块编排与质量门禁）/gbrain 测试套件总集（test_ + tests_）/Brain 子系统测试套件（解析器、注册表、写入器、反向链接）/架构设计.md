本模块是纯测试目录，按被测源码的 `src/core/*` 与 `src/commands/*` 边界组织为独立文件：
- `brain-resolver.test.ts` / `brain-registry.serial.test.ts`：验证 `resolveBrainId` 优先级（显式 flag > `GBRAIN_BRAIN_ID` 环境变量 > `.gbrain-mount` 逐层上溯 > 最长前缀 mount 匹配 > `HOST_BRAIN_ID`），以及 `loadMounts` 对 `mounts.json` v1 的校验。
- `brain-writer.test.ts` / `brain-writer-partial-scan.test.ts` / `brain-writer-walk-prune.test.ts`：断言 `autoFixFrontmatter` 的修复规则（空字节、缺失闭合分隔符、嵌套引号、slug 不匹配、tags/aliases 单引号规范化）、`writeBrainPage` 的路径白名单与集中备份行为，以及扫描/修剪逻辑。
- `backlinks.test.ts` / `backlink-count-mention-filter.test.ts`：验证 `extractEntityRefs`、`hasBacklink`、`buildBacklinkEntry`、`findBacklinkGaps` 去重，以及 D12 中 `getBacklinkCounts` 通过 `IS DISTINCT FROM 'mentions'` 过滤自动提及边。
- `brain-score-breakdown.test.ts` / `brain-score-recommendations.test.ts`：断言 `BrainHealth` 分解字段之和恒等于 `brain_score`、孤儿页定义修正、`doctor` 输出与类型声明一致性。
- `brain-allowlist.serial.test.ts` / `brain-durability-hook.serial.test.ts` / `brain-repo-durability.serial.test.ts`：持久化与 allowlist 相关串行用例。

所有需要数据库的用例通过 `PGLiteEngine` 在内存中初始化 schema 并 `DELETE FROM ...` 清理；无需外部 `DATABASE_URL`。测试框架统一使用 `bun:test`，命名约定以 `*.test.ts` 为主，需串行执行的用例追加 `.serial.test.ts` 后缀。

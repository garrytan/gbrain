本模块是纯函数级单元测试集合，按被测功能分文件组织：
- `auth-*.test.ts`：测试 `src/commands/auth.ts` 的 CLI 参数解析（如 `parseAuthCreateArgs`）。
- `oauth-*.test.ts`：基于内存数据库 `PGLiteEngine` + `sqlQueryForEngine` 注入的 `GBrainOAuthProvider`，直接调用 provider 方法并断言底层 `oauth_tokens/oauth_codes/oauth_clients` 表状态，覆盖 authorize scope 默认继承、confidential client secret SHA-256 比对、refresh token 轮换等。
- `serve-http-*.test.ts`：直接 import `probeHealth`/`probeLiveness`/`parseCorsAllowlistOAuth`/`resolveCorsOrigin`/`HEALTH_TIMEOUT_MS` 等导出，用最小 mock（`makeMockEngine`、`makeMockSql`）验证超时、DB 错误、timer 泄漏与 CORS 白名单解析；Express 路由层集成由 `test/e2e/serve-http-oauth.test.ts` 覆盖，本目录仅做无框架依赖的纯函数断言。
依赖方向单向指向 `src/core/*` 与 `src/commands/*`，不引入 Express 或真实网络 I/O。

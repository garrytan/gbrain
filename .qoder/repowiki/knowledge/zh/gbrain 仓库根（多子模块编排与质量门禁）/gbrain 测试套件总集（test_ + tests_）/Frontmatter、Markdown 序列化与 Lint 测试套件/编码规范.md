- Lint 测试以常量 `const fence = '---'` 拼接最小可复现 Markdown 片段，断言返回 issue 的 `rule` 字面量与 `fixable` 布尔值。
- 对纯函数的测试通过 `buildPage(overrides)` 工厂构造 `Page` 对象，再调用目标函数并断言输出字符串或路径，避免跨用例共享可变状态。
- 涉及 GBRAIN_HOME 的行为通过 `{ GBRAIN_HOME: join(tmp, 'home') }` 注入环境变量，断言 `.gbrain/backups/frontmatter` 下生成 `.bak` 备份文件而非就地 `.bak`。

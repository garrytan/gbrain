本模块是纯测试层，按被测功能域拆分为三组文件：
- `test/frontmatter-*.test.ts`：通过 `child_process.spawnSync(process.execPath, ['run', 'src/cli.ts', 'frontmatter', ...])` 启动 gbrain CLI 进程，使用临时目录 (`mkdtempSync`) 隔离输入输出，断言退出码、stdout/stderr 及 `.gbrain/backups/frontmatter` 集中备份行为，覆盖 `validate`、`generate`、`--json`、`--fix --dry-run`、`--include-catch-all` 等子命令。
- `test/lint-*.test.ts`：直接导入 `src/commands/lint.ts` 中的 `lintContent` 等函数，构造含 `---` fence 的 Markdown 字符串，断言返回的 issue 数组中 `rule` 字段（如 `frontmatter-missing-close`、`frontmatter-nested-quotes`、`no-frontmatter`）与 `fixable` 标记，并验证新旧规则互斥（`no-frontmatter` 存在时不重复报告 `frontmatter-missing-open`）。
- `test/markdown-*.test.ts`：聚焦 `src/core/markdown.ts` 的两个纯函数 `serializePageToMarkdown` 与 `resolvePageFilePath`，通过 `buildPage` 辅助构造 `Page` 行，断言 frontmatter 合并优先级（page < overrides < tags）、v0.38 来源戳记字段（`ingested_via`/`dream_generated`）、默认回退（type=note、空 title）、多 source filing 布局（`.sources/<source_id>/`）等契约。
依赖方向单向指向 `src/` 下的实现；测试之间无共享状态，每个 describe 块内用 `beforeEach`/`afterEach` 管理临时目录。

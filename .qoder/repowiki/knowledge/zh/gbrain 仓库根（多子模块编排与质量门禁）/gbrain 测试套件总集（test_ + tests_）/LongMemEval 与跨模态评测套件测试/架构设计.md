本模块是纯测试层（leaf），按被测子系统划分为三组文件：
- `longmemeval-*.test.ts`：围绕 `src/eval/longmemeval/` 下的抽取器、意图分类器与轨迹路由，使用 PGLite 内存数据库 + 自定义 `ThinkLLMClient` stub 实现完全隔离的 hermetic 测试；通过 `beforeAll/afterAll` 管理引擎生命周期，`beforeEach` 清理 `facts` 表并调用 `resetExtractorState` 重置缓存。
- `cross-modal-*.test.ts`：验证 `src/core/search/query-intent.ts`、`mode.ts`（含 `knobsHash`、`MODE_BUNDLES`、`SEARCH_MODE_CONFIG_KEYS`）、`cross-modal-eval/receipt-name.ts`、`receipt-write.ts`、`aggregate.ts` 等横切能力，侧重正则匹配、哈希版本号、CLI 收据命名与多模型结果聚合规则。
- `notability-eval.test.ts`：针对 `src/commands/notability-eval.ts` 的 JSONL 挖掘/读写工具与评估 harness，使用 `__setChatTransportForTests` 替换 LLM 传输，配合 `test/fixtures/notability-eval-public.jsonl` 做 precision@HIGH/recall/F1 契约断言。

依赖方向单向指向 `src/` 源码，不引入外部网络或真实 API key；所有异步 I/O 均落在临时目录（`tmpdir()`）或内存 DB，保证并行安全。

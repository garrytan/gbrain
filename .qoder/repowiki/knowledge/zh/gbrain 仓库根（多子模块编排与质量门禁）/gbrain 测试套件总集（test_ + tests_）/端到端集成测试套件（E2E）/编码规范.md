- 每个测试文件顶部声明 `const skip = !hasDatabase(); const describeE2E = skip ? describe.skip : describe;`，并用 `describeE2E` 包裹全部用例，使无数据库环境可安全跳过。
- HTTP 相关测试统一在 `beforeAll` 中 `execSync('bun run src/cli.ts auth register-client ...')` 注册 OAuth 客户端、`spawn('bun', ['run','src/cli.ts','serve','--http',...])` 拉起服务、轮询 `/health` 等待就绪，并在 `afterAll` 中 SIGTERM→SIGKILL 终止进程并 `revoke-client` 回收。
- 需要数据库初始化的测试遵循 `beforeAll: setupDB() + importFixtures()`、`afterAll: teardownDB()` 的固定生命周期模式，必要时在 `beforeEach` 中 TRUNCATE 特定表隔离数据。
- 跨进程通信一律通过 `child_process.execSync/spawn` 调用 `bun run src/cli.ts <cmd>`，且显式传入 `{ env: { ...process.env } }` 以继承 helpers.ts 通过 process.env 注入的环境变量。
- 基准测试将被测系统与对照系统封装为同签名函数（如 `openclawDispatch` vs `minionsHandler`），共用同一模型名与提示词常量，再通过 `statsFromResults` 汇总 p50/p95/p99 等分位数。

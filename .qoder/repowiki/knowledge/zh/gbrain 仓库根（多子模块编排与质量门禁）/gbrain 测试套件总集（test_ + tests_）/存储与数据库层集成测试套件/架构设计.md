本模块是 bun:test 驱动的测试集，按被测子系统分文件组织：
- `postgres-engine.test.ts` / `pglite-engine.test.ts` / `pglite-*.test.ts`：对 `src/core/postgres-engine.ts` 做源码级断言（正则扫描禁止裸 `SET statement_timeout`、要求 `sql.begin()` + `SET LOCAL`），对 `PGLiteEngine` 覆盖全部 BrainEngine 方法（Pages/Chunks/Search/Links/Tags/Timeline/RawData/Versions/Config/IngestLog/Stats/Transactions/Cascade）。
- `db-lock-*.test.ts`：围绕 `src/core/db-lock.ts` 的 tryWithDbElection / tryAcquireDbLock，用 PGLite 验证每 tick 选举形状、并发冲突、异常释放、多 lockId 隔离。
- `storage-*.test.ts`：纯内存或临时目录驱动——`storage-config.test.ts` 通过 `mkdtempSync` 写 `gbrain.yml` 校验 YAML 解析与降级键；`storage-backfill.test.ts` 手写 `executeRaw` 与 `StorageBackend` stub 验证状态机幂等与崩溃恢复；`storage-export.test.ts`、`storage-sync.test.ts`、`storage-status.test.ts`、`storage-pglite.test.ts` 分别覆盖导出、增量同步、健康状态与 PGLite 路径。
- `*.serial.test.ts`（如 `pglite-engine-disconnect.serial.test.ts`、`pglite-reconnect.serial.test.ts`）：因 PGLite WASM 冷启动耗时或进程全局副作用（`process.chdir`、`process.env`、gateway 单例），被显式标记为串行运行以避免 shard 竞争。
依赖方向单向指向 `src/core/*` 与 `src/commands/migrations/*`，不反向依赖任何业务逻辑。

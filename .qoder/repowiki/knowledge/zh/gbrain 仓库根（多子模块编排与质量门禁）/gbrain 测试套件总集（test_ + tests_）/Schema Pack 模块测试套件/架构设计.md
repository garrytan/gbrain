本模块是 `src/core/schema-pack` 的配套测试层，全部为无 I/O 的纯函数/内存对象断言，通过构造最小化 `SchemaPackManifest` fixture（如 `minimalManifest` / `makeManifest`）并直接调用导出 API 来钉住内部契约。

- 按功能域拆分为独立文件：`schema-pack-loader.test.ts` 覆盖清单解析、sha8/identity、7 级 pack 解析器、别名图 BFS 闭包与 per-source CTE；`schema-pack-registry.test.ts` 专注 `resolvePack` 的 extends 深度软警告/硬上限与缓存；`schema-pack-trust-boundary.test.ts` 验证 T8/D13 信任门控对 MCP 调用的拒绝策略；`scaffold-extractable.test.ts` 仅测 prompt/template/fixture 生成辅助函数，磁盘写入路径由 e2e 用例承担。
- 依赖方向单向：test → `../src/core/schema-pack/*`，不反向引用任何运行时逻辑；通过 `_resetPackCacheForTests()` 暴露的测试钩子在 `beforeEach` 中重置全局状态，保证用例隔离。
- 所有用例使用 Bun 内置 `bun:test`，并通过 `withEnv` helper 在异步作用域内切换环境变量（如 `GBRAIN_SCHEMA_AUDIT_VERBOSE`），避免污染进程环境。

- 每个被测源文件都有同名或语义对应的 `*.test.ts` 文件，位于 `test/` 根或 `test/skillopt/` 子目录下，形成 1:1 映射。
- 需要文件系统隔离的用例在 `beforeAll/beforeEach` 中创建 `mkdtempSync` 临时目录，并在 `afterAll/afterEach` 中以 `{ recursive: true, force: true }` 清理。
- 涉及环境变量（如 `GBRAIN_AUDIT_DIR`）的用例统一包裹在 `withEnv({ ... }, async () => {...})` 中执行，避免污染全局环境。
- 并发/共享 DB 的对抗性用例采用 `.serial.test.ts` 命名约定，并通过 `resetPgliteState(engine)` 在每个测试前清空 PGLite 状态。
- 对外部系统（LLM、toolLoop、registry）的调用一律通过函数参数注入（如 `toolLoopFn`、`writeCapture`）或返回固定消息的 stub，保证用例零网络、零 LLM 调用。

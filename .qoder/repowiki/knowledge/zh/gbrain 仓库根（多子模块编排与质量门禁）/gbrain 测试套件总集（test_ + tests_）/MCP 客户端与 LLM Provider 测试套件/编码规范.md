- 对外部网络/IO 行为通过进程内 fixture（Node http server 或 StubEngine）模拟，避免真实 DB/网关依赖。
- 对易漂移的序列化输出采用 JSON.stringify 字节级相等断言，确保 MCP tool schema 与定价表不被静默改写。

- 对错误路径统一断言抛出带 `reason` 字段的专用错误类型（如 `RemoteMcpError`），并用 `toBeInstanceOf` 精确匹配分支。

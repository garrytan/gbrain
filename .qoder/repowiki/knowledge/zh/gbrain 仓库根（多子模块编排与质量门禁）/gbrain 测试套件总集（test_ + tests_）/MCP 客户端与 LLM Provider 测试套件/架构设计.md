本模块是 `test/` 下的一个叶子测试包，按被测子系统横向切分为若干独立文件：
- MCP 客户端：`mcp-client.test.ts` 通过 Node `http.createServer` 在进程内启动一个最小化的 JSON-RPC + OAuth discovery 模拟服务器（`.well-known/oauth-authorization-server`、`/token`、`/mcp`），验证 `callRemoteTool` 的 token 缓存、401→重试、`RemoteMcpError` 分类；`mcp-tool-defs.test.ts` 将 `buildToolDefs` 的输出与手写 inline 映射做 JSON 字节级对比，并递归校验所有 `inputSchema` 数组都带 `items.type`。
- 模型配置与别名：`model-config.serial.test.ts` 用自定义 `StubEngine` 实现 `BrainEngine` duck-type，断言 `resolveModel` 的 CLI > configKey > deprecatedKey > tier > env > fallback 六层优先级以及 alias 循环保护；`model-id.test.ts` 校验 provider-prefixed / slash-form 规范化。
- 定价表：`model-pricing.test.ts` 以 `CANONICAL_PRICING` 为唯一事实源，断言 `ANTHROPIC_PRICING`、`MODEL_PRICING` 等派生视图与其一致，并通过读取源码正则匹配禁止跨模块 import 环；`anthropic-pricing.test.ts` 同理。
- Anthropic 协议契约：`anthropic-model-ids.test.ts` 断言 recipe 中只出现无日期后缀的 canonical ID，并对 4.6+ 与 4.5 之前的别名策略分别断言。
- 其他：`openai-compat-multimodal.test.ts` 覆盖 OpenAI 兼容层的 multimodal 路径；`llm-intent-escalation.test.ts`、`llm-intent-hybrid-integration.serial.test.ts` 覆盖意图路由；`providers.test.ts` 仅对 `formatRecipeTable` / `envReady` 做纯格式化断言，不碰 gateway。
依赖方向单向指向 `src/core/*`、`src/mcp/*`、`src/commands/providers.ts`，测试之间互不引用，全部基于 `bun:test`。

本模块是位于 `test/` 下的纯测试文件集合，按功能域拆分为独立用例文件：
- `publish.test.ts`：对 `src/commands/publish.ts` 的纯函数（`makeShareable`、`extractTitle`、`encryptContent`、`generatePassword`、`generateHtml`）进行无状态断言。
- `admin-agents-spend.test.ts`：通过 `PGLiteEngine` + `resetPgliteState` 初始化内存数据库，直接调用 `queryAgentClientSpend` 验证 `/admin/api/agents/spend` 的 SQL 聚合行为（软删除过滤、UTC 日对齐、pending reservation 去重、minion_jobs JSONB 计数等）。
- `budget-meter.test.ts` / `budget-tracker.test.ts`：前者针对 `BudgetMeter` 的预算门控与 JSONL 审计日志；后者针对 `reserveBudget`/`refundBudget`/`haltBudgetSubtree`/`inheritBudgetOwner` 的 CAS 原子性、owner 继承链与 `minion_budget_log` 审计事件。
- `quarantine-cli.test.ts`：通过 `withEnv({ GBRAIN_HOME, GBRAIN_AUDIT_DIR })` 注入临时目录，以 `runQuarantine(engine, [...])` 驱动 quarantine list/clear/scan 子命令并捕获 stdout JSON。
- `admin-embed-spawn.serial.test.ts`：E2E 串行测试，从 tmpdir 启动 `bun run src/cli.ts serve --http`，轮询 `/health` 就绪后向 `/admin/*` 发起真实 HTTP 请求，验证嵌入式 manifest 分支而非 cwd-relative 分支。

依赖方向单向指向 `src/` 中的实现与共享 helper（`helpers/reset-pglite.ts`、`helpers/with-env.ts`），不引入外部数据库或 API Key，全部基于 PGLite 与 Bun 子进程。

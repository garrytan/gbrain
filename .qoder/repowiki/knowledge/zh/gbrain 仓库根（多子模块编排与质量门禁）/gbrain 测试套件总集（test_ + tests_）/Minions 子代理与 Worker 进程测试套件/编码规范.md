- 每个测试文件在 `beforeAll` 内创建并连接 PGLite，`afterAll` 断开，`beforeEach` 调用 `resetPgliteState(engine)` 或手动 `DELETE FROM` 清理相关表，保证用例隔离。
- 对外部依赖（Anthropic SDK、文件系统、时间）一律通过 Fake 对象或注入参数（`_now`、`isStopping`、`makeAnthropic`）替换，避免真实 I/O 与网络调用。
- 对 `ChildWorkerSupervisor` 的行为通过生成可执行 shell 脚本写入 `tmpdir()` 并以不同 exit code 驱动，再断言事件流而非断言内部状态。
- 断言采用结构化类型守卫（如 `e.kind === 'worker_exited'` 后的 `Extract<...>` 窄化）配合 `toMatchObject` 校验事件字段，而非浅比较整条事件。

本模块由两类测试组成，均基于 `bun:test`：
- `test/minions/`：聚焦 `src/core/minions/budget-meter.ts` 的 reserve/settle/sweep 三阶段计费原子性，使用 PGLite 内存库 + `resetPgliteState` 在每个 `beforeEach` 清空 `mcp_spend_reservations` / `mcp_spend_log` / `oauth_clients` 等表。
- `test/subagent-*.test.ts` 与 `test/child-worker-supervisor.test.ts`：前者通过 `FakeMessagesClient` 回放 Anthropic Messages API 响应，配合 `MinionQueue` 在 PGLite 中构造真实 `minion_jobs` 行，验证两阶段持久化（`subagent_messages` + `subagent_tool_executions`）、租约（`subagent_rate_leases`）与崩溃恢复；后者直接实例化 `ChildWorkerSupervisor`，用 `tmpdir()` 下生成的 shell 脚本作为“worker”，断言事件流中的 `worker_spawned` / `worker_exited` / `backoff` / `health_warn` 形状与 crashCount 语义（D1/D2 不变量、RSS watchdog code=12、软/硬预算降级模式、issue #1801 的 wedge restart）。
依赖方向单向指向 `src/core/minions/*`，不引入外部网络或真实数据库。

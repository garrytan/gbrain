- 每个测试文件顶部以 JSDoc 注释声明所覆盖的版本特性编号（如 v0.39、v0.41 E6）与被测契约要点，便于 PR 审查时快速定位变更影响面。
- 数据库相关测试统一通过 `beforeAll` 创建 PGLiteEngine + `initSchema()`，`afterAll` 断开连接，`beforeEach` 调用 `resetPgliteState(engine)` 清理状态。
- 对不可变聚合逻辑（如 `computeDoctorReport`、`detectBlockShape`、`expandBullet` 等）采用纯函数参数化断言，直接传入合成输入并断言返回值结构。
- 需要文件系统隔离的集成测试使用 `mkdtempSync(join(tmpdir(), 'gbrain-*'))` 创建临时目录，并在 `afterEach` 中递归 `rmSync` 清理，避免跨用例污染。
- CLI 行为通过独立的 `.serial.test.ts` 文件并以 `child_process.execSync` 启动真实 `gbrain` 子进程验证，与 in-process seam 测试分离。

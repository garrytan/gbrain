本模块由三个彼此独立、仅共享 `BrainEngine` 类型边界的子目录组成：

- `code-intel/`：实现 W3 阶段的代码遍历能力。`recursive-walk.ts` 负责递归扫描源码；`traversal-cache.ts` 提供以 `(symbol_qualified, depth, source_id, cluster_generation)` 为键的 write-through 缓存层，通过 `cluster_generation`（由 `recompute_code_clusters` 递增）和可选的 REPEATABLE READ xmin_max 快照隔离保证一致性，对外暴露 `getCachedOrCompute` 供上层 W3 操作复用；`sinks/` 按语言分发 sink 分类，`index.ts` 维护一个进程级正则编译缓存，将 callee 匹配到 `db_call | http_call | file_io | process_exec` 四类 SinkKind。
- `brainstorm/`：四阶段流水线编排器。`orchestrator.ts` 是入口，定义 `BrainstormProfile`（内置 `BRAINSTORM_PROFILE` 与 `LSD_PROFILE`），依次执行 Phase1 hybridSearch 近邻检索 → Phase2 domain-bank 远端采样 → Phase3 并行 cross-generate（`mapWithConcurrency` 限并发 4）→ Phase4 judge；通过 `checkpoint.ts` 在 `~/.gbrain/brainstorm/<run_id>.json` 持久化完整 idea 体以实现 `--resume` 断点续跑，并带 7 天 mtime GC；`judges.ts` 承载评分逻辑与两套 JudgeConfig；`error-classify.ts` 把 SQLSTATE 57014 统一包装成 `StructuredAgentError('brainstorm_timeout')`；`domain-bank.ts` 负责远端页集合获取与注入模式过滤。
- `claw-test/`：端到端 Agent 测试框架。`agent-runner.ts` 定义 `AgentRunner` 接口（`detect` / `invoke` / 可选 `postInstallHook`）与全局注册表，当前唯一实现位于 `runners/openclaw.ts`；`scenarios.ts` 从 `test/fixtures/claw-test-scenarios/<name>/scenario.json` 加载场景配置（支持 `fresh-install` / `upgrade` 两种 kind）；`transcript-capture.ts` 与 `progress-tail.ts` 负责子进程 I/O 捕获与进度输出；`seed-pglite.ts` 为测试预置 PGLite 种子库。

依赖方向单向向外：三者均只依赖 `../engine.ts` 提供的 `BrainEngine` 抽象，不互相引用，便于各自演进。

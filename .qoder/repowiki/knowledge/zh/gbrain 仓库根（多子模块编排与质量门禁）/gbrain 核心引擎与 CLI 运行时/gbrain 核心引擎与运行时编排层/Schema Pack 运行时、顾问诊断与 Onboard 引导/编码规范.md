- 对外 API 统一从 `index.ts` 桶导出，内部跨文件引用走直接路径以保持依赖图可读。
- 所有外部副作用入口（advisor 单个 collector、onboard nudge/banner、doctor checks）采用 try/catch 包裹的 fail-open 策略，异常被记录到 stderr 但绝不向上抛出破坏调用方主流程。
- 对不可信输入（正则、extends 链深度、path traversal）在解析期用 zod 校验并在运行期加预算/上限保护（`redos-guard.ts`、`EXTENDS_DEPTH_HARD_CAP`、`ALIAS_CLOSURE_MAX_DEPTH`）。
- 诊断类函数返回结构化结果（`AdvisorFinding` / `OnboardCheckResult`）而非直接打印，渲染逻辑与数据收集解耦。
- 需要并发执行的数据库检查使用 `Promise.allSettled` + `AbortController` 配合固定毫秒预算（3s onboarding budget），超时视为部分结果而非错误。

- 对外 API 集中在 `index.ts` 中 re-export，内部实现保持私有，调用方只依赖该聚合入口。
- 可插拔组件通过判别联合接口注入（如 `Verifier` 的三种 verifier 形状、`BackgroundWorkDrainer` 的 drain/abort 钩子），而非继承或回调散列。
- 对不可恢复的基础设施故障（PgBouncer 断开、锁丢失）使用命名常量集合（`INFRASTRUCTURE_ABORT_REASONS`）标记，由上层 catch 分支统一跳过 failJob 交由 stall detector 回收。
- 测试注入点通过显式的 `__*ForTest` 导出（如 `__registerDrainerForTest`、`__listDrainerNamesForTest`）替换全局状态，避免破坏生产模块的单例语义。
- 配置项优先从环境变量读取默认值（`GBRAIN_SUPERVISOR_PID_FILE`、`GBRAIN_PROGRESSIVE_BATCH_STAGES`、`GBRAIN_ALLOW_SHELL_JOBS`），并在构造函数中以 `Required<T>` 合并后使用。

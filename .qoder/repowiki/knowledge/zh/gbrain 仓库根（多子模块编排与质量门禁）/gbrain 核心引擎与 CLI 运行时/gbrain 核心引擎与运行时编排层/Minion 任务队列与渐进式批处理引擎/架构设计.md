模块由三个协作子域组成，依赖方向单向：
- `minions/`：Postgres-native 作业系统。`types.ts` 定义 `MinionJob`/`MinionJobInput`/`MinionHandler` 等核心契约；`queue.ts` 实现入队、claim、重试、死信、静默时段与去重；`worker.ts` 以 Promise pool 并发执行 handler，内置锁续期（`lock-renewal-tick.ts`）、RSS 看门狗、健康检查与 `unhealthy` 事件；`supervisor.ts` 通过 `child-worker-supervisor.ts` 以独立进程管理 `gbrain jobs work`，负责 PID 文件独占、指数退避重启、wedge 检测与优雅关闭；`handlers/` 按 job name 注册具体处理器（shell/embed/subagent/ingest-capture 等），`tools/` 暴露 brain-allowlist 等共享工具。
- `progressive-batch/`：独立的批处理原语，`orchestrator.ts` 驱动 `trial → ramp_100 → ramp_500 → full` 四阶段流水线，`types.ts` 用判别联合 `OutputCountVerifier | IdempotentMutationVerifier | NoopVerifier` 表达三类验证器，`audit.ts`/`stage-report.ts` 输出 JSONL 审计与结构化报告，`retrofit-wrap.ts` 为旧有批量站点提供适配层。
- `background-work.ts`：全局后台工作注册表，集中登记 fire-and-forget sink（facts queue、last-retrieved、search cache、eval capture），在 CLI 退出时按 `order` 排序依次 drain 并可选 abort，避免 PGLite `db.close()` 竞态导致忙循环。
入口 `index.ts` 仅 re-export `MinionQueue`/`MinionWorker`/`calculateBackoff`/类型，作为对外稳定 API 边界。

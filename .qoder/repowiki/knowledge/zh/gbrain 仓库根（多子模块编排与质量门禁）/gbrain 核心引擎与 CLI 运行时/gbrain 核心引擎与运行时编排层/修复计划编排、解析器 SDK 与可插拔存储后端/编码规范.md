- 公共 API 统一通过 `index.ts` barrel 导出，禁止调用方直接 import 内部文件（如 resolvers/index.ts 注释明确要求从 'gbrain/resolvers' 导入）。
- 所有外部可插拔组件（resolver、storage backend）通过 id/backend 字符串标识并在 registry/factory 中按 id 查找，避免硬编码依赖。
- 异步操作返回带 `confidence`(0-1)、`source`、`fetchedAt` 的结构化结果对象，确定性后端返回 1.0，LLM/启发式返回 <1.0。
- 错误类型采用具名 `code` 字段的强类型枚举（`ResolverErrorCode`、`BudgetExhausted` 等），而非任意字符串异常。
- 可选回调通过 Hooks 接口注入（`RemediationHooks`、`ResolverLogger`），核心库不调用 console，由调用方决定输出格式。

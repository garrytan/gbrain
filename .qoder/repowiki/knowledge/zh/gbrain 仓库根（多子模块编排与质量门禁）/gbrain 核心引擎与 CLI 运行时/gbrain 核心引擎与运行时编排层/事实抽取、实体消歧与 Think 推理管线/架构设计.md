模块由三个并列子域组成，通过 `BrainEngine` 接口与底层存储/搜索解耦：
- `src/core/facts/`：事实抽取流水线。`extract.ts` 调用 gateway.chat(Sonnet) 从对话轮次提取结构化 NewFact；`queue.ts` 提供进程级单例 FactsQueue（cap=100、per-session inflight=1、AbortSignal 驱动优雅关闭），并通过 `registerBackgroundWorkDrainer` 注册为后台工作 sink；其余文件按职责切分：`absorb-log.ts`、`backstop.ts`、`decay.ts`、`eligibility.ts`、`extract-from-fence.ts`、`fence-write.ts`、`forget.ts`、`meta-hook.ts`、`phantom-audit.ts`、`stub-guard-audit.ts` 等。
- `src/core/think/`：gbrain think 管线入口 `index.ts` 串联 `intent.ts`（意图分类）→ `gather.ts`（四路并行检索 + RRF 融合）→ `prompt.ts`（system/user prompt 组装）→ LLM 调用 → `cite-render.ts`（引用解析）→ `persistSynthesis`（落库）。LLM 客户端经 `ThinkLLMClient` 抽象注入，默认走 `gateway.chat()` 适配层以复用 MCP/配置/重试能力，并支持 `client`/`stubResponse` 测试注入与无 API key 时的优雅降级。
- `src/core/entities/resolve.ts`：纯函数式实体消歧器，按 exact-slug → pg_trgm 模糊匹配 → 前缀扩展（people/*, companies/*）→ slugify 回退四级链解析自由文本实体名，并提供 `resolveEntitySlugWithSource`（带 resolution_source 标签供 trajectory 路由）和 `resolvePhantomCanonical`（幽灵页重定向）两个变体。
- `src/core/by-mention.ts`：独立的自动链接 gazetteer，基于 `LINKABLE_ENTITY_TYPES` 硬编码类型构建 token-Map，对正文做 maximal-munch 扫描并施加 self-link / cross-source / first-mention-only 三重守卫，输出 `Mention[]` 供下游写入 link_source='mentions'。
依赖方向：本模块仅向上依赖 `../engine.ts`、`../ai/gateway.ts`、`../search/hybrid.ts`、`../model-config.ts`、`../background-work.ts`，不反向被 facts/think 互相循环引用。

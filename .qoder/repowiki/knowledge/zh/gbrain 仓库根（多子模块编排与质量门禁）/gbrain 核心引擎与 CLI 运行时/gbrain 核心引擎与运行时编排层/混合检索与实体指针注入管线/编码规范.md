- 后融合各 boost 阶段统一采用 mutate-in-place + floor-ratio 门限 + 结果上打 attribution 字段（如 `backlink_boost`/`salience_boost`/`recency_boost`/`title_match_boost`/`alias_resolved_boost`）的模式，供 --explain 溯源。
- 对外 API 一律通过 `BrainEngine` 接口访问数据库，对缺失表/旧版脑的异常采用 fail-open（try/catch 返回空集或原输入），保证向后兼容。
- 可观测性通过可选回调（`onMeta`/`onRelationalMeta`/`onGraphMeta`/`onScoreDistribution`）注入，默认 undefined 时零开销，热路径永不等待。
- 异步副作用（缓存写入、telemetry flush、volunteer 事件日志）注册到 `registerBackgroundWorkDrainer` 或 fire-and-forget，确保进程退出前有序 drain 且不阻塞主流程。

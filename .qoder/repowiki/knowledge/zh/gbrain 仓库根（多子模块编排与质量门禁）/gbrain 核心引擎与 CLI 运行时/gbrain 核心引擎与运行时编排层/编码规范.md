- 所有跨源读写的 API 统一接受 `{ sourceId?: string; sourceIds?: string[] }` 选项，且 `sourceIds` 数组优先于标量 `sourceId`，用于 MCP 联邦读取授权。
- 批量写入方法（addLinksBatch/addTimelineEntriesBatch/addTakesBatch/upsertChunks）共享 `BatchOpts` 契约：内部自动 `withRetry(BULK_RETRY_OPTS)`，禁止调用方再包一层重试，并通过 `auditSite` 字段输出 JSONL 审计。
- 数据库操作一律走 `BrainEngine` 抽象，禁止在子域中直接 import postgres-js/pglite 驱动。
- AI 调用必须经 `ai/gateway.ts` 的 embedding/chat/expansion/reranker 入口，不得直连具体 provider。

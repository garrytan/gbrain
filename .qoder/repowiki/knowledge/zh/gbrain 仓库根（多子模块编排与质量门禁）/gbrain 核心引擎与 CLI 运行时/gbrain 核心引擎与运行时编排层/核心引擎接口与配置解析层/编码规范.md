- 对外 API 使用 interface 描述输入输出形状（PageInput、ChunkInput、SearchOpts、DomainBankSampleOpts 等），并在 JSDoc 注释中记录版本演进与向后兼容约定。
- 搜索/排序/过滤等可枚举参数采用 string literal union + 对应的白名单映射表（如 PAGE_SORT_SQL、ENRICH_ORDER_SQL、CR_MODES + isCRMode guard），避免 SQL 拼接注入。
- 配置字段遵循「env > 文件 > DB 平面 > 默认值」的优先级链，并通过 KNOWN_CONFIG_KEYS / KNOWN_CONFIG_KEY_PREFIXES 白名单驱动 `gbrain config set` 的提示与校验。
- 多源脑（multi-source）API 统一暴露 `sourceId?: string` 标量与 `sourceIds?: string[]` 数组两种作用域，约定当两者同时存在时数组优先（federated read）。

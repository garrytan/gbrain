本模块是 core 层的对外契约面，由四个文件构成清晰的职责分层：
- `types.ts`：所有跨引擎共享的数据模型（Page/PageInput/Chunk/SearchResult/Take/Fact 等）与常量（ALL_PAGE_TYPES、CR_MODES、PAGE_SORT_SQL、ENRICH_ORDER_SQL），作为 PostgresEngine 与 PGLiteEngine 的共同约束。
- `engine.ts`：声明 `BrainEngine` 接口及其全部方法签名（connect/disconnect/reconnect/initSchema/transaction、Page CRUD、searchKeyword/searchVector/upsertChunks、Takes/Facts/Dream 等高级能力）、批量写入选项 `BatchOpts`、`ReservedConnection` 专用连接抽象，以及 `clampSearchLimit`、`MAX_SEARCH_LIMIT` 等内部工具；该文件不实现任何 SQL，仅暴露 API 边界。
- `config.ts`：提供 `loadConfig()`（同步，~/.gbrain/config.json + env 覆盖）、`loadConfigWithEngine()`（异步，在 DB 连通后叠加 DB 平面键）、`saveConfig()`、`isThinClient()` 等函数，并内置 #427 Bun .env DATABASE_URL 劫持防护、legacy embedding provider→embedding_model 迁移、KNOWN_CONFIG_KEYS 白名单校验等策略。
- `index.ts`：聚合导出入口，仅重导出 `BrainEngine` 类型、`PostgresEngine` 构造函数、`types.ts` 全量类型以及 markdown 辅助函数，隐藏 engine 实现细节。
依赖方向单向：`engine.ts` 和 `config.ts` 都只依赖 `types.ts`，`index.ts` 反向聚合三者；engine 实现位于同目录下的 `postgres-engine.ts` / `pglite-engine.ts`，不在本模块作用域内。

模块由三条相对独立的子域组成，通过稳定的类型契约解耦：

- `src/core/ingestion/`：对外暴露 `gbrain/ingestion` 版本化公共 API（`index.ts` 仅导出 types + `computeContentHash`/`validateIngestionEvent`），内部以 `types.ts` 定义 `IngestionSource`/`IngestionEvent`/`IngestionSourceContext` 契约；`daemon.ts` 实现 `IngestionDaemon`，负责 per-source 生命周期监督（崩溃计数+指数退避）、24h 内容哈希去重（`dedup.ts`）、每源令牌桶限速、以及注入式 `IngestionDispatcher` 投递到 Minion 队列；`sources/` 下的 file-watcher/inbox-folder/gstack-learnings/markdown-greenfield 均为同构的 `IngestionSource` 实现，通过 `createXxxSource(opts)` 工厂构造并由 daemon 注册；`skillpack-load.ts` 按 `gbrain-ingestion-source-v1` 版本从插件清单加载第三方 source。
- `src/core/chunkers/`：多策略分块库，`code.ts` 基于 web-tree-sitter WASM（Bun `import ... with { type: 'file' }` 内嵌 36 个语法）做 AST 级符号切分并附带 call-site edge 提取；`semantic.ts` 用句子嵌入+余弦相似度+Savitzky-Golay 找主题边界；`recursive.ts` 是兜底递归切分；`chinese-semantic.ts`、`llm.ts`、`edge-extractor.ts`、`qualified-names.ts`、`symbol-resolver.ts` 为语言/边/限定名辅助。所有 chunker 都通过 `CHUNKER_VERSION` 配合 sync 命令触发全量 re-chunk。
- `src/core/diarize/payload-fitter.ts`：通用 payload 压缩器，支持 `batch`（确定性 token 预算分块）与 `summarize`（embed→k-means 聚类→Haiku 摘要）两种策略，带质量门控 `degraded` 标志。
- `src/core/transcription.ts`：独立音频转写服务，默认 Groq Whisper（OpenAI 兼容 API），自动回退 OpenAI，>25MB 文件经 ffmpeg 分段后拼接结果。

依赖方向：sources → types → daemon → dispatcher（MinionQueue）；chunkers 被上层 import-file 调用，不反向依赖 ingestion；transcription 被 audio/video 处理器消费；diarize 被 brainstorm/judges 使用。

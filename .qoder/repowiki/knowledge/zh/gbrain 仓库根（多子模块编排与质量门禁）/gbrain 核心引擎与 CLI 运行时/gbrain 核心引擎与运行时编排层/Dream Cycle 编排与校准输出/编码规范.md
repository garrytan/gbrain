- 每个 phase 对外暴露 `runPhaseXxx(engine, opts) → Promise<PhaseResult>` 或继承 `BaseCyclePhase` 实现 `process()`，统一返回 `{phase, status, duration_ms, summary, details}` 信封，异常经 `mapErrorCode/mapErrorClass` 转为 `PhaseError`。
- 所有 LLM 提交前必须调用 `checkBudget(estimate)`，当 `allowed=false` 时跳过该次提交但继续累积已产出，使阶段以 `status:'ok'` + `details.budget_exhausted:true` 优雅降级而非报错。
- 读取源隔离数据一律通过 base 提供的 `scope()` 返回的 `ScopedReadOpts`（含 `sourceId/sourceIds`），禁止子类直接访问 `ctx.engine` 绕过 scope。
- 长循环内部在每批处理顶部检查 `isAborted(opts.signal)` 并支持可选的 `yieldDuringPhase` keepalive 回调，避免长时间运行触发 worker 驱逐。
- 配置项通过 `engine.getConfig('dream.*')` 读取并以 `resolveModel(...)` 统一解析模型 ID，同时保留废弃 key 的兼容分支。
- 可观测性通过追加 JSONL 行记录到 `~/.gbrain/audit/` 下的 ISO 周文件名，每条带 `schema_version` 字段且变更需向后兼容。

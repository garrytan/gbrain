模块按职责分为三个子目录：
- `src/core/cycle/`：Dream Cycle 的流水线阶段集合，每个文件对应一个 Phase（如 `synthesize.ts`、`patterns.ts`、`consolidate.ts`、`extract-facts.ts`、`auto-think.ts`、`drift.ts` 等），统一通过 `BaseCyclePhase` 抽象类提供 source-scope 强制、BudgetMeter 预算门控、错误信封与进度上报；旧阶段（`synthesize`、`patterns`）仍保持独立函数式入口 `runPhaseXxx(engine, opts)` 返回 `PhaseResult`，新阶段继承 `BaseCyclePhase` 并通过 `process()` 钩子实现。
- `src/core/cycle/phases/`：纯数据/无 LLM 的辅助阶段（当前仅 `consolidate.ts`，将 facts 聚簇合并为 takes），直接操作 `BrainEngine` 执行 SQL 并写回 DB。
- `src/core/calibration/`：校准层产物——`templates.ts` 定义 voice-gate 失败时的手写模板槽位与渲染函数，`voice-gate.ts`、`take-forecast.ts`、`recall-footer.ts`、`svg-renderer.ts`、`undo-wave.ts`、`cross-brain.ts`、`think-ab.ts`、`gstack-coupling.ts`、`domain-aggregators.ts`、`nudge.ts` 共同构成校准报告、A/B 思考对比、跨脑聚合与 UI 渲染。
- `src/core/enrichment/` 与 `src/core/enrich/thin.ts`：对已有页面做轻量补全（预算、完整性评分），被上层 cycle 在合成后调用。
依赖方向单向向外：cycle 阶段 → `../engine.ts` / `../operations.ts` / `../minions/*` / `../ai/gateway.ts`；calibration 不反向依赖 cycle，只消费 engine 读出的聚合结果。`budget-meter.ts` 是共享基础设施，被 auto-think/drift 等阶段复用，审计写入 `~/.gbrain/audit/dream-budget-YYYY-Www.jsonl`。

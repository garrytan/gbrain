本模块是 skillopt 的纯支撑子集，不依赖上层编排器，被 orchestrator 与其他 skillopt 文件共同消费。
- `types.ts` 作为单一事实来源：集中声明 EditOp/ScoredRollout/Trajectory/GateInput/RunReceipt/SkillOptOpts 等核心接口，并暴露 D12 验证门常量（VALIDATION_EPSILON=0.05, VALIDATION_RUNS_PER_TASK=3, ROLLOUT_SUCCESS_THRESHOLD=0.5）与 D17 基线（D_SEL_MIN_SIZE=5），所有其他文件通过 import type 引用，禁止在此处引入运行时副作用。
- `apply-edits.ts` 实现无副作用的 SKILL.md 正文切片编辑引擎：`applyEdit`/`applyEditBatch` 仅对 frontmatter 之后的 body 操作（D5），返回 tagged `EditResult`（D9），内置 heading/行锚解析、唯一性校验、```fence 内拒绝、git working-tree 预检与 .tmp+rename 原子写；`rejected-buffer.ts` 复用该 `atomicWrite` 持久化 LRU 容量=100 的拒绝编辑缓存，键为 `{skill_sha8, edits}` 的 SHA-256 前缀 8 位，保证状态感知去重。
- `reflect.ts` 封装两次 reflect 调用（失败/成功，D7）与 one-shot rewrite ablation（cat31 config C），通过 `describeJudge`/`describeJudges` 把 Judge 渲染成自然语言评分标准注入 prompt，使用 `cacheSystem=true`（D11）节省系统提示 token，并通过 `RejectedEntry[]` 反偏置重复提案；`parseEditsResponse` 容忍 fenced JSON 与尾随逗号，内部 `validateEdits` 做白名单字段校验。
- `audit.ts` 基于上游 `../audit/audit-writer.ts` 的单例 `AuditWriter<SkilloptEvent>`，按 ISO 周轮转写入 `~/.gbrain/audit/skillopt-YYYY-Www.jsonl`，任务文本经 `sha8` 脱敏，skill_name 明文保留以便 doctor 诊断；导出 `_resetAuditWriterForTests` 供测试覆盖 GBRAIN_AUDIT_DIR。
- `help.ts` 仅导出 `SKILLOPT_HELP_TEXT` 常量，由 CLI 入口直接拼接。
依赖方向：`reflect.ts` → `types.ts` + `rejected-buffer.ts`；`rejected-buffer.ts` → `apply-edits.ts`；`audit.ts` → 外部 audit-writer + `types.ts`；其余文件互不耦合，全部被上层 orchestrator 消费。

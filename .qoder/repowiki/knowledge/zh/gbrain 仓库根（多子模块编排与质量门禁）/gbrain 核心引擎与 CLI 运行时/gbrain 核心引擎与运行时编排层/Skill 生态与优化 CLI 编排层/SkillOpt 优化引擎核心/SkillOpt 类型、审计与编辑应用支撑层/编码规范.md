- 对外 API 一律返回带 outcome 字段的 tagged union（如 `EditResult`、`GateResult`），拒绝路径用 reason/detail 描述而非抛异常（D9）。
- 所有跨运行持久化的可序列化对象都显式声明 schema 版本号（如 rejected buffer 的 `{schema: 1, entries}`），加载时做最小结构校验并在损坏时静默回退到空数据。
- 敏感输入（benchmark task text、skill snapshot）在审计与缓存中统一通过 `sha8()` 取 SHA-256 前 8 位十六进制脱敏，skill_name 保持明文。
- 文件写入采用 `.tmp + fsync + rename` 的原子写模式（`atomicWrite`），避免并发或崩溃导致的部分写入。
- 面向 LLM 的 prompt 以模板字符串常量形式集中定义（FAILURE_REFLECT_SYSTEM / SUCCESS_REFLECT_SYSTEM / ONE_SHOT_REWRITE_SYSTEM），并通过 `describeJudge`/`describeJudges` 将结构化 Judge 渲染为自然语言准则注入 user message。
- 面向测试的可变全局状态（如 `_writer` 单例）通过导出 `_resetAuditWriterForTests` 暴露重置钩子，使测试能注入自定义 GBRAIN_AUDIT_DIR。

本模块按 skillpack 生命周期切分子文件，各子能力通过共享的 manifest-v1.ts（清单 schema）、registry-schema.ts（注册表 schema）与 registry-client.ts（远程源/缓存/tarball 原语）进行协作：
- 初始化阶段由 scaffold_init 生成本地/脑内/第三方包骨架；
- 开发阶段由 audit_quality 驱动 doctor/harvest/check，并依赖 rubric.ts 评分规则；
- 发布阶段由 publish_install 调用 registry-client 的 tarball 打包与 registry-client 的上传接口；
- 消费阶段由 install.ts 落盘受管块，state_trust 写入已安装来源与 nag-state 计数，post-install-advisory 输出 agent 可读提示；
- reference_apply 提供只读 diff 与 clean-hunk 自动合并，供 `gbrain skillpack reference` 使用；
- misc_ops 串联背书、迁移、采集等跨阶段辅助流程。
所有对外入口最终由 CLI 层统一调度，子模块之间不直接互相 import，而是通过上述共享 schema/client 契约通信。

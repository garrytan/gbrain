模块由三个纯函数式子文件组成，依赖方向单向：`diff-text.ts` → `apply-hunks.ts` → `reference.ts`。
- `diff-text.ts`：零依赖的 unified-diff 生产者，基于经典 O(N·M) LCS 动态规划计算行级操作序列，再按上下文窗口合并为 hunk 范围并输出标准 `--- a/` / `+++ b/` 格式；负责处理末尾无换行标记 (`\ No newline at end of file`)。
- `apply-hunks.ts`：unified-diff 消费者，提供 `parseUnifiedDiff` 解析器与 `applyHunks` 应用器；对每个 hunk 提取 pre-change 块在目标文本中做唯一匹配，仅当恰好出现一次时替换为 post-change 块，缺失或歧义则报告冲突，纯 JS 实现不依赖系统 `patch(1)`。
- `reference.ts`：对外 API 层，暴露 `runReference` / `runReferenceAll`（只读扫描所有 scaffold entry 并产出 per-file status + unified diff）和 `runReferenceApply`（`--apply-clean-hunks` 路径，逐文件调用 `unifiedDiff` → `parseUnifiedDiff` → `applyHunks`，支持 `dryRun`）。通过 `bundle.ts` 枚举 scaffold entries，区分 sharedDep/pairedSource，并对二进制文件（含 NUL 字节）跳过文本合并。两个导出接口均附带带语义的 framing 提示行，明确“参考文件”定位与两路合并限制。

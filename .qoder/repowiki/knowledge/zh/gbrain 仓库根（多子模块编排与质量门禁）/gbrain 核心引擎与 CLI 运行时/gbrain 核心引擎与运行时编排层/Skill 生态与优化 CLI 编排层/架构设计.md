本目录是 `src/core/skillpack`、`src/core/skillify`、`src/core/skillopt` 三个核心子系统的 CLI 门面：
- `src/cli.ts` 将 `gbrain skillpack`、`gbrain skillify`、`gbrain skillopt` 注册为 CLI_ONLY 命令，通过 `await import('./commands/...')` 懒加载对应 dispatcher。
- `src/commands/skillpack.ts` → 调用 `core/skillpack/{bundle,scaffold,reference,migrate-fence,scrub-legacy,harvest,remote-source,registry-client,...}` 实现打包/发布/安装/引用生命周期；
- `src/commands/skillify.ts` → 调用 `core/skillify/generator.ts` 的 `planScaffold/applyScaffold` 生成 5 个骨架文件，并把 `check` 委托给 `commands/skillify-check.ts`；
- `src/commands/skillopt.ts` → 解析 flags 后走 `core/skillopt/bootstrap-benchmark.ts`（bootstrap-from-routing / bootstrap-from-skill）、`batch.ts`（--all / fleet）、或 `orchestrator.ts` 的 `runSkillOpt` 主循环。
三者互不依赖，仅共享 `autoDetectSkillsDir*`（repo-root）、`resolveModel`（model-config）等跨域工具；CLI 层负责参数校验、JSON 信封输出、退出码约定以及 --help 文本分发。

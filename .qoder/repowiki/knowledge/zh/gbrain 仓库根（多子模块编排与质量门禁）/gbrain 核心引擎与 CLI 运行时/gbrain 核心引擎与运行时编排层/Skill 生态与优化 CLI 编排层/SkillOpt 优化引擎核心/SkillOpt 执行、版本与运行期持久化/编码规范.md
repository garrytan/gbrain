- 所有 JSON 持久化文件首字段声明 `schema` 版本号，读取时校验 schema 再反序列化，失败回退到空状态并写 stderr 提示。
- 对外暴露的路径构造函数（`skilloptDir`/`versionsDir`/`historyPath`/`bestPath`/`versionPath`/`checkpointPath`）集中定义，避免路径拼接散落各处。
- 文件写入一律通过 `atomicWrite` 完成，保证 crash 后不会留下半截文件。
- 错误处理采用 try/catch 包裹 fs 操作并在 catch 分支向 `process.stderr` 输出 `[skillopt] ...` 前缀的可诊断消息，同时返回安全默认值。
- 可插拔能力通过可选参数注入测试桩（如 `toolLoopFn`/`chatFn`），默认走真实实现，便于单元测试替换。

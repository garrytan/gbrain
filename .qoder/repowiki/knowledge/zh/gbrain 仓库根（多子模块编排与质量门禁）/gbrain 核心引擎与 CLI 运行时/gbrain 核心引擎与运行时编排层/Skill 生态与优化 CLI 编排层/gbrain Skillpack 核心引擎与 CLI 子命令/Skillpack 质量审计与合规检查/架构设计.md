模块以单一数据源 `rubric.ts` 为中心：一个按 id 排序的 DIMENSIONS 数组同时承载 CORE（5 项必过）与 BADGE（5 项可选）两类维度定义，每个维度是纯函数 `(input: RubricInput) => Promise<{passed,detail,fix_hint}>`；`walkRubric()` 顺序执行并汇总成 `RubricScore`，`describeRubric()` 导出纯元数据供解剖文档生成。

- `doctor.ts` 作为 CLI 入口编排器：加载 manifest → 调用 `walkRubric` → 按需触发 `applyAutoFixes`（基于维度名 switch 生成路由 eval / CHANGELOG / bootstrap / license 等脚手架），并以 `DoctorResult` 结构体输出人类可读文本或稳定 JSON。
- `harvest-lint.ts` 独立于 rubric，负责从 `~/.gbrain/harvest-private-patterns.txt` + 内置默认正则集合中加载模式，逐行匹配 harvested 文件，命中则抛出带 `hits[]` 的 `PrivacyLintError`，由上层 harvest 回滚副本。
- `brain-pack-lint.ts` 读取各 skill 的 SKILL.md frontmatter `tools:`，与调用方传入的 `knownOps: Set<string>` 对比，返回 `BrainPackLintResult.unknownTools` 暴露版本漂移。

依赖方向单向向外：本模块仅依赖 `manifest-v1.ts`、`markdown.ts`、`audit.ts`，不反向被它们引用；所有 I/O 通过显式参数注入（如 `knownOps`、`patternsPath`），保持可测试性。

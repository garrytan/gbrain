- 每个子模块定义一组字面量联合的错误码类型（如 `RegistryClientErrorCode`、`RemoteSourceErrorCode`、`TarballErrorCode`）配合同名 `*Error extends Error` 类，并在构造函数中固定 `this.name`，便于上层按 code 分支处理。
- 所有 I/O 写入采用“先写 .tmp 文件/目录，成功后 `renameSync` 原子替换”的模式，失败时 try/catch 内清理临时产物，保证缓存槽不会被部分写入污染。
- 对外接口统一通过 options 对象注入测试桩（如 `fetchImpl`、`cacheDir`、`noNetwork`、`cacheRoot`、`noCache`），默认走真实网络/文件系统，使单元测试无需外部依赖。
- 缓存路径基于输入稳定哈希派生：registry 用 URL 的 sha256 前 16 位，git 用 host+owner+repo+commit-sha，tarball 用文件 sha256，确保同一来源幂等命中。

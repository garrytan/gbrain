- 评分器统一返回 0..1 浮点分数，解析或调用失败时采用悲观回退（score=0）并把错误信息挂到 `judge_error` 字段，避免向上抛异常中断优化循环。
- 对外 API 通过可选 `opts` 参数暴露测试 seam（如 `chatFn`、`now`），使无 I/O 路径可被单元测试完全替换。
- LR 调度函数均为纯函数，签名 `(base, t, totalSteps) => number`，且内部对 `t` 做 clamp 并对结果取 `Math.ceil` 后钳制到 `[MIN_LR, base]`。
- 写捕获 handler 遵循相同模板：校验必填参数 → 构造 `CapturedWrite {op,key,input,ordinal}` → 追加到 `writes` 数组并更新 `virtualPages` Map → 返回带 `virtual: true` 的响应体。

- 每个质量维度在 DIMENSIONS 数组中以对象字面量声明，包含稳定的 id/name/category/description/auto_fixable 字段以及一个异步 check(input) 函数，统一返回 {passed, detail, fix_hint}。
- 失败路径一律附带 fix_hint 字符串，给出可直接粘贴到终端的修复命令或最小操作步骤，便于 CLI 渲染和 --fix 自动修复。
- 对外错误使用自定义 Error 子类（PrivacyLintError、PrivacyLintConfigError）并在 hits 属性上携带结构化定位信息，而非仅抛通用 Error。
- 对全局 RegExp 的重复使用前显式重置 lastIndex = 0，避免跨行/跨文件匹配状态泄漏。
- 对缺失文件或解析失败的 SKILL.md 采用 fail-open 策略（continue/skip），让质量 lint 只报告问题而不阻塞半写好的 pack。

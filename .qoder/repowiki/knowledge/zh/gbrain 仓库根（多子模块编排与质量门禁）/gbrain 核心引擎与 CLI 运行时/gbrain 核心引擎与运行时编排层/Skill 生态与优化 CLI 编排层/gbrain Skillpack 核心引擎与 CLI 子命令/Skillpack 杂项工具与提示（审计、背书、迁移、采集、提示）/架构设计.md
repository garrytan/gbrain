本模块是一组无共享状态的工具函数集合，每个文件对应一个独立的 CLI 子命令或运行时钩子，彼此不互相依赖，统一通过 `src/core/skillpack.ts` 的 CLI 分发入口调用。

- 审计层 (`audit.ts`)：实现 ISO 周四锚定的周轮转 JSONL 写入，路径由 `GBRAIN_AUDIT_DIR` 覆盖，默认落至 `~/.gbrain/audit/skillpack-YYYY-Www.jsonl`；`readRecentSkillpackEvents` 被 `gbrain doctor` 消费。
- 背书工作流 (`endorse.ts`)：纯数据操作 + git 封装，校验 `registry.json` / `endorsements.json` 的 schema，原子写 `.tmp` + rename，提交固定格式 commit message，可选 push origin/main。
- 脑内打包发现 (`brain-resident-locate.ts`)：按 `sourceScopeOpts(ctx)` 多源枚举 `brain_resident: true` 的 pack，计算 per-source 的 active schema_pack 并做 mismatch 提示，`getResidentSkillDetail` 对 SKILL.md 做 realpath  confinement + 大小限制，返回给 MCP 工具。
- 提示输出 (`post-install-advisory.ts`, `brain-pack-advisory.ts`, `bootstrap-display.ts`)：三者遵循同一契约——构建纯文本 advisory 并通过 `process.stderr.write` 打印，绝不自动执行任何步骤；`build*` 返回 `string | null`，null 表示无需打扰。
- 迁移与清理 (`migrate-fence.ts`, `scrub-legacy.ts`)：前者解析 `<!-- gbrain:skillpack:begin/end -->` fence，receipt-first 再回退到行解析 (F-CDX-8)，可加性复制缺失 skill；后者在确认 frontmatter triggers 存在后安全删除遗留表格行。
- 采集 (`harvest.ts`)：将宿主仓库 `skills/<slug>/` 镜像进 gbrain 树，复用 `copyArtifacts` 的 symlink 拒绝与 realpath confinement，随后运行隐私 lint，命中则 rollback 已写文件，最后更新 `openclaw.plugin.json#skills`。

依赖方向单向向外：仅引用同目录下的 `manifest-v1.ts`、`bundle.ts`、`state.ts`、`copy.ts`、`harvest-lint.ts` 及上层 `../markdown.ts`、`../operations.ts`、`../sources-load.ts`，不反向依赖 CLI 层。

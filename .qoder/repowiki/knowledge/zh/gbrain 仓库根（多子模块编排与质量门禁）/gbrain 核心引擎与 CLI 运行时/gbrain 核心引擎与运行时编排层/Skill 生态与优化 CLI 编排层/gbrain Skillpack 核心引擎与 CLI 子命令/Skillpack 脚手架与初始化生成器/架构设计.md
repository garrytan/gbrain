本模块按「来源」拆成四个并列入口，共享同一套写盘契约与产物格式：
- `init-scaffold.ts`：`gbrain skillpack init <name>` 的“大教堂式”模板生成器，输出完整 `skillpack.json` + `skills/<slug>/SKILL.md` + `routing-eval.jsonl` + `runbooks/bootstrap.md` + `CHANGELOG.md` + `README.md` + `LICENSE` + `.gitignore`，可选 `--minimal` 去掉 test/e2e/evals；通过 `applyWritePlan` 统一执行“拒绝覆盖已有文件”的幂等写入。
- `init-brain-pack.ts`：`gbrain skillpack init-brain-pack` 的轻量变体，产出带 `brain_resident: true`、`schema_pack` 和精确 `gbrain_min_version`（默认绑定当前 `VERSION`）的清单，依赖 `init-scaffold.ts` 中的 `applyWritePlan` 复用写盘逻辑。
- `scaffold.ts`：`gbrain skillpack scaffold <name>` 的本地 bundle 安装器，调用 `bundle.ts#enumerateScaffoldEntries` 枚举技能及其 frontmatter `sources:` 声明的配对源文件，再通过 `copy.ts#copyArtifacts` 镜像复制到目标工作区，支持 partial-state（仅补缺失的 paired source）。
- `scaffold-third-party.ts`：第三方 pack 的编排层，串联 `loadSkillpackManifest → semverGte 版本检查 → askTrust 信任提示 → bundleManifestFromSkillpack 转换 → enumerateScaffoldEntries → copyArtifacts → buildBootstrapDisplay → state.ts upsertEntry/saveState`，返回包含 `status`/`manifest`/`trustDecision`/`copy`/`bootstrap`/`state` 的结构化结果供 CLI 与发布门控消费。

依赖方向单向向外：本模块只读 `manifest-v1.ts`、`bundle.ts`、`copy.ts`、`bootstrap-display.ts`、`state.ts`、`trust-prompt.ts`、`remote-source.ts`，不反向被它们引用；所有写盘操作都经由 `applyWritePlan` / `copyArtifacts` 两个受控原语完成，保证“不覆盖已有文件”的统一合同。

- 持久化采用 `.tmp` 文件先写再 `renameSync` 的原子更新模式，失败时清理 tmp 并抛出带 `code` 字段的自定义 Error 子类。
- 每个状态文件以 `SKILLPACK_*_SCHEMA_VERSION` 常量标记 schema，加载时校验该字段，未知版本在 state 中抛错而在 nag 中 fail-open 返回空状态。
- 数据操作函数（`upsertEntry`/`removeEntry`/`upsertNag`/`recordNagDisplay`）返回新对象而非原地修改，使调用方可进行引用比较。
- 对外暴露的 `load*`/`save*` 统一接受 `{ statePath?: string }` 选项，默认通过 `gbrainPath(...)` 计算 `~/.gbrain/` 下的文件名，便于 e2e 注入临时路径。

本模块是 SkillOpt 运行管线中的“准入 + 决策”层，按职责拆分为四个独立文件：
- `preflight.ts`：D3 成本预估算，基于模型定价表与固定 token 估算（ROLLUT/REFLECT/JUDGE）计算总 USD，返回 `{proceed, estimate}`；未知 provider 回退到 Sonnet 保守价，不抛错。
- `validate-gate.ts`：D12/D4 验证门，对 selSet 并行执行 N=3 次 rollout+judge，取 per-task median 后求均值，以 `bestScore + VALIDATION_EPSILON` 严格大于判定接受；暴露 `scoreSkillOnTasks` 作为统一的“打分原语”，并通过 `rolloutFn`/`scoreFn` 注入点支持测试替换。
- `bundled-skill-gate.ts`：D16 打包技能保护，通过 `autoDetectSkillsDirReadOnly` 判断是否位于安装路径下，组合 `--no-mutate` / `--allow-mutate-bundled` 标志决定就地修改或仅写 `proposed.md`，并强制要求非空 held-out 集才能对打包技能做 in-place 变更。
- `cycle-phase.ts`：dream-cycle 阶段包装器，读取 `cycle.skillopt.*` feature flag 与配置，扫描带 `skillopt-benchmark.jsonl` 且 `last_run_at` 过期的技能，逐个以 epochs=1、较小 batch 调用 `runSkillOpt`，维护 per-skill 与 brain-wide 双预算上限，并将结果持久化到 config 表。
依赖方向单向向下：phase → orchestrator → gate → rollout/score；本模块不持有状态，所有 I/O（fs、engine.getConfig、pricing table）均通过参数或纯函数边界进入，便于单元测试。

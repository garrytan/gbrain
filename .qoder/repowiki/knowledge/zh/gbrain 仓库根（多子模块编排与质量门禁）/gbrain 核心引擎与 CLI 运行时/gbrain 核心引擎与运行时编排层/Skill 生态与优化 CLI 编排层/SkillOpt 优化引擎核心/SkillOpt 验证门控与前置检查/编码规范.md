- 对外 API 统一采用 opts 对象模式，并通过可选的 `rolloutFn`/`scoreFn` 等注入点暴露测试 seam，避免在业务逻辑中直接耦合具体实现。
- 错误处理区分 MUST-ABORT（如预算耗尽、无定价）与可降级错误：前者向上抛出让调用方中止，后者按 score=0 悲观回退，保证评估不被静默污染。
- 安全策略（打包技能、held-out 门槛）以纯函数形式暴露（`shouldMutateSkillFile`、`assertBundledMutationHeldOut`），由上层入口集中调用，确保 CLI、batch、fleet、MCP 等多条路径共享同一份核心策略。
- 配置项通过 `engine.getConfig(key)` 读取并提供默认值，失败时 fallback 到常量（如 `DEFAULT_PER_SKILL_CAP_USD`、`DEFAULT_STALE_DAYS`），使功能默认关闭、按需开启。

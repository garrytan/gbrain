- 对外暴露一对 `buildXxx(input) -> string | null` 纯函数 + `printXxx(...)` 包装器，后者仅在返回值非 null 时写入 stderr，使测试可断言形状而调用方控制输出流。
- 所有 I/O 失败采用 fail-open 策略：try/catch 吞错并降级（如 `readSkillDescription` 返回 `(no description)`），绝不让单个 malformed 包中断整个枚举流程。
- 文件写入一律先写 `.tmp` 再用 `renameSync` 原子替换，保证 endorsements.json 等关键清单不被截断。
- 外部输入（slug、SKILL.md 路径）必须经 `realpath` + relative containment 校验后再访问，防止 symlink 逃逸与 `..` 穿越。
- CLI 选项统一以 `{ dryRun?: boolean }` 布尔开关暴露，dry-run 分支只做验证不写盘，便于预览与测试。
- 错误类型继承自 `Error` 并携带具名 `code` 字段（如 `EndorseError.code`、`HarvestError.code`），由调用方根据 code 区分处理分支。

- 每个子命令空间由一个 `src/commands/<ns>.ts` 作为入口，内部再 `await import('../core/<ns>/...')` 懒加载实现，避免冷启动开销。
- CLI 入口统一遵循 `--json` 模式输出稳定 JSON 信封（含 ok/outcome/receipt 等字段），非 json 模式打印人类可读摘要。
- 子命令采用 `subcommand + switch` 的两级分派：顶层 `runXxx(args)` 解析 sub，再按子命令分别处理 flag 与业务逻辑。
- 错误路径通过 `process.exit(2)` 表示用法/参数错误，业务失败返回具体 ExitCode 映射（如 skillopt 的 accepted=0/no_improvement=1/errored=2）。

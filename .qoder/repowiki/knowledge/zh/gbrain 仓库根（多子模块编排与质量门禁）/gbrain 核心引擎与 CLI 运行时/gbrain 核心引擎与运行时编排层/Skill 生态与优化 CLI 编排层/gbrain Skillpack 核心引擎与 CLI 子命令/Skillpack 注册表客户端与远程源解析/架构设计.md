本模块由三个职责正交的文件组成，共同构成 skillpack 从“名称→包根目录”的拉取链路：
- `registry-client.ts`：封装对 `gbrain-skillpack-registry` 的 HTTP 获取与磁盘缓存。通过 `loadRegistry()` 实现“网络优先 + ETag 304 快速轮询 + 软 TTL(1h)/硬过期(7d) 降级到本地缓存”的策略；`findPack` / `searchPacks` 在已加载的 `LoadedRegistry` 上按 tier 排序并应用 endorsements 覆盖。
- `remote-source.ts`：接收任意 spec（kebab 名、owner/repo、https URL、本地路径、.tgz），经 `classifySpec` 分类后分派到 `resolveGitSource` / `resolveTarballSource` / `resolveLocalSource`，统一产出 `ResolvedSource`。git 分支使用 `git ls-remote` 先解析 HEAD SHA，再用 `cloneRepo`（来自 `../git-remote.ts`）浅克隆到 `~/.gbrain/skillpack-cache/git/<host>/<owner>/<repo>/<sha>/`；tarball 以文件 sha256 为键缓存到 `tarball/<sha>/`。所有写操作均通过 `.tmp-*` 临时目录 + `renameSync` 原子落盘，避免并发或失败污染缓存槽。
- `tarball.ts`：纯 Bun 下调用系统 GNU tar 实现确定性打包（`--sort=name --mtime=@0 --owner=0 --group=0 --pax-option=delete=atime,delete=ctime`）与安全解压——先 `tar --list --verbose` 做 allowlist（仅 `-` 和 `d`）、路径穿越检查、单文件大小/总大小/文件数/压缩比上限校验，再执行实际 extract。
依赖方向：`remote-source.ts` → `tarball.ts` + `../git-remote.ts`；`registry-client.ts` 独立于两者，仅依赖 `../config.ts` 与 `./registry-schema.ts`。三者对外只暴露带 `ErrorCode` 字段的自定义 Error 类，错误码作为精确的分类标签供上层处理。

- 对外抛错一律通过 `errorFor({ class, code, message, hint })` 构造结构化错误，而非裸 throw，便于上层统一格式化与提示。
- LLM 调用点暴露可选的 `chatFn?: typeof gatewayChat` 参数，默认回落到 `gatewayChat`，使单元测试可注入 mock。
- Bootstrap 产物以 `BOOTSTRAP_PENDING_REVIEW` 哨兵行结尾，`loadBenchmark` 在未显式 `--bootstrap-reviewed` 时拒绝使用，形成强制人工审查门禁。
- 所有涉及磁盘写入的路径都先 `fs.mkdirSync(..., { recursive: true })` 再写，确保中间目录存在。
- Benchmark 任务 ID 必须全局唯一且稳定：`splitBench` 按 task_id 排序后再切分，`computeBenchmarkSha8` 对排序后的 canonical JSON 计算 SHA-256 前缀 8 位。

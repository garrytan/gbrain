- CLI 入口在模块顶层安装信号处理器（SIGCHLD、SIGTERM/SIGHUP/SIGPIPE/uncaughtException），确保锁获取阶段也被覆盖。
- 对外暴露的入口采用「裸对象 + 默认导出」而非 SDK 包装函数，避免在非 Node 环境引入运行时依赖。
- 构建产物（admin 前端）使用 `with { type: 'file' }` 以 ESM 形式内联为字符串常量，保证 `bun build --compile` 后仍可被 require/import。
- DDL 脚本使用 `CREATE TABLE IF NOT EXISTS` + `ON CONFLICT DO NOTHING` 组合，使同一份 SQL 既可用于 fresh-install 也可幂等回放。

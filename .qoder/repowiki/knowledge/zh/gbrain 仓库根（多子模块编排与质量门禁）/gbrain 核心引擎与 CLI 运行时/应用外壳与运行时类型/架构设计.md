本模块是 gbrain 二进制/可执行入口与运行时边界的聚合点，按职责拆分为四个独立文件：
- `src/cli.ts`：Bun shebang 入口（`#!/usr/bin/env bun`），负责全局信号处理安装、自升级心跳、参数解析、thin-client 路由（通过 MCP 转发到远端 brain）、本地引擎连接、读操作 180s 超时保护、结果格式化与统一退出码通道（`finishCliTeardown`）。命令分派采用「共享 Operation + CLI_ONLY 白名单」双轨：共享 op 来自 `core/operations.ts`，CLI-only 子命令（init/reindex/auth 等）直接 switch 调用。
- `src/openclaw-context-engine.ts`：OpenClaw 插件注册器，导出一个裸对象 `{ id, name, description, register }`，由 host 通过 `openclaw.extensions` 发现；在 `register` 中调用 `createGBrainContextEngine` 注入确定性时空上下文，并可选消费宿主提供的 `resolveEntities` / `brainQuery` 回调以绕过自身 DB 连接。
- `src/admin-embedded.ts`：构建期自动生成的静态资源映射，将 `admin/dist/*` 打包为 ESM `with { type: 'file' }` 导入，供 Express handler 在编译后的二进制中直接 serve SPA。
- `src/schema.sql`：Postgres + pgvector 单文件 DDL，集中定义 sources/pages/content_chunks/code_edges_*/links/tags/raw_data/timeline_entries/page_versions/ingest_log/config/access_tokens/oauth_*/*minion_jobs*/*op_checkpoints* 等表及 HNSW/GIN/tsvector 索引、plpgsql 触发器（generation clock、search_vector、chunk FTS）和默认种子数据，既是 fresh-install 也是迁移回放的基础。
- `src/version.ts`：从 `package.json` 读取版本号，被 CLI 与 banner 路径消费。
- `src/types/image-decoders.d.ts`：为 Bun 的 image decode 能力提供声明式类型补充。
依赖方向单向向外：本模块仅 import `core/*`、`commands/*`、`core/mcp-client.ts`、`core/self-upgrade.ts` 等核心实现，不反向被 core 依赖，属于最外层 shell。

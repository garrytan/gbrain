src/ 是 gbrain 的单一可执行产物根目录，按职责划分为五个子域并通过共享契约耦合：
- core_engine 提供 BrainEngine 接口与 Postgres/PGLite 双后端、AI 网关、摄取/抽取/检索/事实/评估等子域实现；
- cli_commands 下的每个文件对应一个 `gbrain <cmd>` 子命令，统一通过 EngineFactory 启动 Engine 实例并调用其 API；
- mcp_server 复用 core_engine 的同一套操作（tools.json 映射到 engine.operations），以 stdio 与 HTTP 两种传输暴露给 Claude Desktop 或外部 MCP 客户端；
- standalone_evals 与 core/eval-* 并行存在，前者作为发布门禁的独立 harness，后者嵌入引擎内部供 eval 子命令驱动；
- app_shell_and_types 提供入口 cli.ts、OpenClaw 桥接、schema.sql 与内嵌前端资源，是所有子域的启动边界。
跨子域的统一约束包括：所有持久化访问经 db.ts/connection-manager.ts 抽象，所有 AI 调用经 ai/gateway.ts 路由至 recipes，所有版本迁移由 commands/migrations 集中编排并在 init/upgrade 时串行应用。

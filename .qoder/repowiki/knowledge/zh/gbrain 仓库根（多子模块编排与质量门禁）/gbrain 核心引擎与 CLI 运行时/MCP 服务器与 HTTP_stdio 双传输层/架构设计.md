模块以 `dispatch.ts` 为唯一调度中心：`server.ts`（stdio 传输，通过 `@modelcontextprotocol/sdk/server/index.js` 的 `Server` + `StdioServerTransport`）和 `http-transport.ts`（Bun.serve 自实现的 JSON-RPC over HTTP `/mcp`）各自注册 `tools/list` 与 `tools/call` 处理器，但都委托给 `dispatchToolCall`，从而保证两条路径的参数校验、错误序列化、`OperationContext` 构造完全一致。

- `tool-defs.ts` 是 ParamDef→JSON Schema 映射的单点，被 stdio 与 HTTP 两端共同消费，避免 schema 漂移。
- `rate-limit.ts` 提供基于令牌桶 + 有界 LRU Map 的内存限流器，HTTP 路径在认证前按 IP、认证后按 token id 分别应用两层限速；默认值由 `GBRAIN_HTTP_RATE_LIMIT_*` 环境变量驱动。
- `server.ts` 额外承担 PGLite 场景下的「Retrieval Reflex」职责：当 engine=pglite 时启动本地 unix socket IPC 服务器，将实体解析请求转发到 `resolveEntitiesToPointers`，避免 PGLite 单连接模型下打开第二个数据库连接。
- 进程生命周期：stdin EOF / transport close / SIGTERM/SIGINT/SIGHUP 均触发统一 shutdown，清理 IPC socket、调用 `engine.disconnect()` 并退出，防止与 ingest 任务争用 PGLite 写锁。
- 依赖方向：本模块仅向上依赖 `core/engine.ts`、`core/operations.ts`、`core/config.ts`、`core/sql-query.ts`、`core/context/*` 等核心包，不反向被 core 依赖，属于纯接入层。

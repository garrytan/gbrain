- 所有外部输入（HTTP body、MCP params）在进入业务 handler 之前必须经 `validateParams` 按 Operation 的 ParamDef 白名单校验，未知字段不被接受。
- 错误响应统一序列化为 `{ content: [{ type: 'text', text: JSON.stringify({ error, message }, null, 2) }], isError: true }` 的 ToolResult 形状，禁止直接抛裸 Error 字符串。
- 可选增强（如 `_meta.brain_hot_memory`、CORS、日志写入）一律包裹 try/catch 并以 best-effort 降级，确保主流程不因辅助钩子失败而翻转成错误。
- 可配置阈值通过 `envInt(name, fallback)` 从 `GBRAIN_*` 环境变量读取，保持 HTTP 与 rate-limit 模块间一致的 env 解析模式。

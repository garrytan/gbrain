需在 gbrain 仓库根目录执行，设置对应 provider 的 API Key（默认 Anthropic → `ANTHROPIC_API_KEY`）。典型命令：
- `bun run evals/functional-area-resolver/harness-runner.ts --limit 1 --yes`（冒烟测试）
- `node evals/functional-area-resolver/harness.mjs --model opus --parallel 3 --yes`
- `node evals/skillopt-judge/runner.mjs --judge-model anthropic:claude-sonnet-4-6 --output evals/skillopt-judge/receipts/$(date +%Y%m%d).json`
- `node evals/skillopt-reflect/runner.mjs --optimizer-model anthropic:claude-opus-4-7 --output evals/skillopt-reflect/receipts/$(date +%Y%m%d).json`

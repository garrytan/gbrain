- 每个评估子目录采用「fixtures.jsonl + runner.mjs」结构：固定输入 JSONL 描述用例，单文件 Node CLI 负责读取 fixtures、调用 src/core 实现、写入 JSON/JSONL receipt 并以 exit code 表达 pass/fail。
- CLI 参数使用极简的 `flag(name, def)` 或 `parseArgs(argv)` 手动解析，不支持任意布尔开关，仅暴露必要选项（--model/--output/--fixtures 等）。
- receipt 首行携带可审计元数据（schema_version/timestamp/judge_model/optimizer_model/fixtures_count 等），并通过 hash(prompt_template)/hash(fixtures)/harness_sha 绑定运行上下文，便于复现与检测陈旧数字。
- 评分同时报告严格与宽松两档（STRICT vs LENIENT / MAE vs threshold），宽松评分基于领域语义（dispatcher area 同集合、edit shape 匹配）而非字符串相等。
- 统计汇总使用 t-distribution 置信区间（n=3 seeds, df=2, t-critical≈4.303），在 README 表格中以 `mean ± halfWidthCI` 形式呈现。

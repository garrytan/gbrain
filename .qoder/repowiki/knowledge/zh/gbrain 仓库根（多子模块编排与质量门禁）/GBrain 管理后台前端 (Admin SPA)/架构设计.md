- 入口 `src/main.tsx` 通过 `ReactDOM.createRoot` 挂载 `<App />`；构建产物输出到 `dist/`，Vite base 路径为 `/admin/`（见 `vite.config.ts`），由后端反向代理统一前缀。
- 路由采用纯 hash 模式：`App.tsx` 监听 `hashchange`，在 `'login' | 'dashboard' | 'agents' | 'log' | 'calibration' | 'jobs'` 之间切换，未鉴权时强制跳转到 `#login`。
- 页面按职责拆分为 `src/pages/` 下的独立组件（Login / Dashboard / Agents / RequestLog / Calibration / JobsWatch），无路由库依赖，导航由 App 侧边栏驱动。
- HTTP 层集中在 `src/api.ts`，封装 `apiFetch`（JSON）与 `apiFetchText`（text/plain，用于校准 SVG 图表），统一处理 `credentials: 'same-origin'`、401 跳转 login 以及错误体解析；所有后端端点以 `/admin/api/*` 形式暴露。
- 认证模型为 v0.26.3 D11+D12：浏览器不缓存 token，仅依赖 HttpOnly cookie，401 即重定向登录，无自动重试。
- 权限 scope 常量位于 `src/lib/scope-constants.ts`，是 `src/core/scope.ts` 的手动镜像，受仓库脚本 `scripts/check-admin-scope-drift.sh` 校验一致性，避免跨包引用破坏 SPA 编译边界。
- 样式全部内联 CSS（`index.css` + 组件内联 style），遵循 `DESIGN.md` 的工业风暗色规范，无 UI 框架。

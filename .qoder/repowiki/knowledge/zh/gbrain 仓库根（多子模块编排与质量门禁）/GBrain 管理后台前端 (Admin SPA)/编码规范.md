- 页面组件以 `*Page` 后缀命名并放在 `src/pages/` 下，由 `App.tsx` 通过 hash 路由条件渲染，不使用 react-router。
- HTTP 调用统一走 `src/api.ts` 导出的 `api.*` 方法，禁止在页面中直接写 fetch，401 一律重定向到 `#login`。
- scope 常量在 `src/lib/scope-constants.ts` 中以手写镜像形式维护，并通过外部脚本与后端 `src/core/scope.ts` 保持同步，不得直接跨包 import。
- CSS 使用 BEM 风格 class（如 `sidebar`、`nav-item`、`main`）配合 CSS 变量（`--border`、`--text-secondary` 等），颜色语义化且仅用于 badge 等数据标识。

- 所有 TS 源码使用 `@/` 路径别名指向 src/，禁止相对路径穿越到 sibling 子模块
- 跨子模块的公共 API 通过 package.json exports 子路径显式暴露，而非直接引用内部路径
- 测试用例统一走 bun:test，并在 beforeAll 中通过 helpers/fixtures 初始化 PGLite 或真实 Postgres 连接
- CLI 命令与工具协议均以 src/cli.ts 为单一入口，子命令按 src/commands/*.ts 拆分并由 engine-factory 装配
- 敏感信息检查与 WASM 嵌入校验通过 scripts/check-*.sh 在提交前强制运行，不得绕过

### 主脑
- 定义：指 `~/.gbrain` 目录下的唯一 Host Brain 数据库（brain.pglite + config），是系统中唯一的真正大脑实例，所有 source 分区都写入这个统一的数据库。项目中的其他 .gbrain 文件只是指路牌或同步规则，不是独立的大脑。
- 别名：host brain、大脑本体

### Source（内容源）
- 定义：同一个大脑里的命名分区，对应一个本地项目目录。通过 `gbrain sources add` 注册，在项目目录下放置 `.gbrain-source` 指路牌告诉 CLI 默认操作的 source id。同一大脑内的不同 source 默认开启跨源搜索。
- 别名：source、内容源

### Mount（团队脑挂载）
- 定义：挂载别人的脑（如团队共享脑），配置文件位于 `~/.gbrain/mounts.json`。目前该功能尚未启用，属于未来规划。
- 别名：mount、团队脑挂载

### 指路牌
- 定义：项目目录下的 `.gbrain-source` 文件，内容为 source id（如 `zeus`），告诉 gbrain CLI "在这个目录下默认操作 source=X"。如果文件缺失或目录为空，会导致自动路由断裂。
- 别名：source 指路牌、.gbrain-source

### Doctor
- 定义：gbrain 内置的健康检查工具，输出总体健康分、脑质量分、Skill 评分、Ops 评分，以及 FAIL/WARN 级别的诊断项。包含 sync_freshness、cycle_freshness、timeline_coverage、extract_atoms 积压、facts 吸收失败等多项检查。
- 别名：gbrain doctor、体检

### whoknows eval
- 定义：gbrain 的专家路由评测集，包含 10 条查询的 fixture 文件，用于评估 whoknows/find_experts 功能的检索命中率。需要 qrels 配置才能做 A/B 对比，eval capture 为 opt-in 模式。
- 别名：whoknows、专家路由评测

### 脑质量分
- 定义：gbrain 对知识库质量的综合评分（满分 100），包含 embed（35）、links（25）、timeline（15）、orphans（15）、dead-links（10）五个维度。timeline 覆盖率目标 90%，低于此值会显著拉低总分。
- 别名：brain quality score、脑分

### Dream Cycle
- 定义：gbrain 的夜间自动增强周期，包括 extract atoms、facts absorption、contradiction detection、enrichment 等 phase。需要完成完整 cycle 才能提升脑质量分，特别是 timeline 覆盖率。
- 别名：dream、梦循环、增强周期

### Schema Pack（模式包）
- 定义：定义脑的数据结构（page types、typed edges、extraction rules）的打包格式。默认 `gbrain-base-v2` 包含 15 种类型（person、company、media、tweet 等），支持 agent 作者自定义 pack 并通过 `migration_from:` 字段实现向后兼容升级。
- 别名：schema pack、模式包、pack

### Skill（技能）
- 定义：gbrain 的可插拔工作流模块，以 Markdown 文件形式存在，通过 skills/RESOLVER.md 进行路由。仓库内置 43 个 curated skills，涵盖信号捕获、ingest、enrichment、querying、brain ops 等功能。
- 别名：skill、技能包

### Minions（子代理队列）
- 定义：BullMQ 形状、Postgres 原生的作业队列，支持 durable subagents（崩溃恢复的 LLM 工具循环）、shell jobs with audit、child jobs with cascading timeouts、rate leases for outbound providers、attachments via S3/Supabase storage。
- 别名：minion、子代理、作业队列

### Brain Repo（脑仓库）
- 定义：以 markdown 文件形式存储的知识库，作为系统的 system of record。GBrain 将 repo 同步到 Postgres 进行检索，git 中的删除变为 DB 中的软删除。支持发布公开子集、分享团队 mounts、运行 thin-client 设置。
- 别名：brain repo、知识仓库

### Hybrid Search（混合搜索）
- 定义：Vector（HNSW on pgvector）+ BM25 keyword + reciprocal-rank fusion + source-tier boost + intent-aware query rewriting 的组合检索策略。三种命名搜索模式（conservative、balanced、tokenmax）将成本/质量旋钮打包为单个配置键。
- 别名：hybrid search、混合检索

### Synthesis Layer（合成层）
- 定义：gbrain 区别于普通搜索的核心能力：不仅返回相关页面，还生成合成的、有引用的答案，并明确指出脑不知道什么（gap analysis）。这是让搜索结果变成实际答案的关键差异化特性。
- 别名：synthesis、答案合成

### Self-wiring Knowledge Graph（自连线知识图谱）
- 定义：每次页面写入时自动提取实体引用并创建 typed edges（attended、works_at、invested_in、founded、advises 等），无需 LLM 调用。支持多跳遍历（`gbrain graph-query`），相比纯向量检索带来 +31.4 P@5 的提升。
- 别名：knowledge graph、知识图谱、自连线

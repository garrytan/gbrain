## 故障排除指南
- 常见问题
  - 权限不足：确认运行用户对目标目录与服务端口的访问权限。
  - 网络不可达：检查代理、防火墙与 DNS 解析。
  - 配置错误：核对环境变量与配置文件键名、值域与格式。
  - 版本不兼容：对照升级指南与依赖矩阵。
- 诊断步骤
  - 提升日志级别，收集完整上下文。
  - 使用最小复现用例，逐步缩小范围。
  - 对比正常与异常环境的差异（配置、依赖、网络）。
- 恢复策略
  - 回滚到上一个稳定版本。
  - 清理缓存与临时文件后重试。
  - 重建索引或重新导入必要数据。

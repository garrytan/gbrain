# 2026-07-07 NSIS 安装弹窗问题记录

## 现象

安装新版本 PMBrain 时，即使已从系统托盘手动退出，安装程序仍然弹出 "无法关闭 PMBrain.exe" 提示，需要用户点击"忽略"继续。

## 根因

electron-builder 自带的 NSIS 安装模板中（`installSection.nsh`），通过 `CHECK_APP_RUNNING` 宏用 `FindProcDLL` 检测并关闭 PMBrain.exe。`FindProcDLL` 对 Electron 应用的进程树处理不够干净：
- 只能发 `WM_CLOSE` 尝试关闭主窗口，对侧边栏（sidecar/node 子进程）不生效
- 如果有文件句柄残留（如 node 子进程未完全释放），可能误判为"无法关闭"

## 解决方案（未实施）

创建 `desktop/build/installer.nsh`：在 `preInit` 钩子中用 `taskkill /f /t` 强制结束 PMBrain 整个进程树：

```nsh
!macro preInit
  nsProcess::_FindProcess "PMBrain.exe"
  Pop $R0
  ${If} $R0 == 0
    nsProcess::_KillProcess "PMBrain.exe"
    Pop $R0
    Sleep 500
  ${EndIf}
!macroend
```

然后在 `desktop/electron-builder.yml` 中增加：
```yml
nsis:
  include: build/installer.nsh
```

`nsProcess` 是 electron-builder 自带的 NSIS 插件（`app-builder-lib/templates/nsis/include/nsProcess.nsh`），无需额外安装。通过 `preInit` 钩子，在安装程序 `Function .onInit` 最早期就被调用，先强制结束进程，后续 `CHECK_APP_RUNNING` 不会再弹框。

# 2026-07-07 AI 对话完整上下文记录

## 对话期间执行的工作

### 1. embedding 维度 UI 联动修复（方案 A）

**问题**：桌面端配置页切换向量化模型时，维度输入框不会同步更新。用户从 ZeroEntropy（1280 维）改到智谱 embedding-3（1024 维）后，维度字段仍保持 1280，导致保存后 config 写入错误维度，知识库导入失败。

**修改**：在 `desktop/src/renderer/src.ts` 中：
- 新增 `MODEL_DEFAULT_DIMENSIONS` 常量（覆盖 7 厂商 10 模型）
- 新增 `updateEmbeddingDimensionsDefault()` — 切换厂商/模型名时自动更新维度输入框
- 增加事件监听：`#embedding-provider` change + `#embedding-model-name` input

### 2. 打包过程（1.0.42 → 1.0.43）

- 首次 `build:win` 正确生成 1.0.42 安装包
- 误用 `--config.extraMetadata.version=1.0.76` 额外打包产生版本混乱
- 清理错误文件，递增桌面版版本到 1.0.43 后重新打包
- `latest.yml` 已更新指向 1.0.43

### 3. 补充修正

最终设计调整为：桌面端保留 embedding 维度 UI 自动联动，但后端不再自动猜测或修正维度。用户最终填写多少就保存多少；缺失或无效维度直接提示填写。Docker/Postgres 已有库的 `content_chunks.embedding` 列维度若与当前配置不一致，启动时只报明确的维度不匹配错误，不再自动 ALTER、清空旧向量或重建索引。

### 4. NSIS 安装弹窗（未解决）

安装新版时即使已退出 PMBrain，仍弹出"无法关闭进程"提示。原因是 electron-builder 自带 `CHECK_APP_RUNNING` 宏对 Electron 子进程处理不干净。解决方案：在 `electron-builder.yml` 中引入自定义 NSIS 脚本，用 `preInit` 钩子提前 `taskkill /f /t`。

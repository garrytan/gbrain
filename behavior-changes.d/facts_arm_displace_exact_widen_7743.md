search and query now answer a plain question about a person with the saved facts that name the thing asked: a fact that holds every query term can take the place of the lowest page rows, and search returns fact rows as query does. A degraded or thin result of a short query also runs the exact-text scan for its terms and adds up to three pages it finds, marked widened: exact. Set search.facts_arm_displace, search.search_facts_arm or search.exact_widen to false to turn each off.

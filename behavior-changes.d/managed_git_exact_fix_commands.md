retry-effects, doctor parked_effects and settle-effects previews list each parked Git target's last_error as phase, step and reason code only, and a retry, park or re-arm stores it that way, so git's own error line from an older build no longer prints or persists. A fix command word with a line break, a control character or a marker token prints in $'...' quoting with byte escapes, so the command names the exact path on one line (bash, zsh, ksh, busybox sh); dash reads it as one literal word and runs nothing from it.

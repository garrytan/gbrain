New command: gbrain value prints one card of real counts about your brain: conversations archived, pages by kind, links, facts kept, lookups served, pages brought up on their own and later retrieved, nightly items and the brain score. Every row is a measured number, off with the command that turns it on, or unavailable with the reason; it never shows 0 for a number it could not read. gbrain value --json prints the same card as a versioned JSON document. It runs only on the computer that holds the brain: it is not an MCP tool, and a thin client refuses it.

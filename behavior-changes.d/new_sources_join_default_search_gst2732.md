A source added with no `--federated` or `--no-federated` choice is now federated (in default search, and readable by connections with no source grant) when the brain serves one person: `access.serves` reads one, `brain.audience` classifies personal and the client is not thin. Otherwise it stays unset as before, and `sources add` and `sync --source <id>` print the `source_not_in_default_search` notice with `gbrain sources federate <id>` as the fix (asking the user first on a shared brain). Existing sources are not changed. Adds from a remote MCP caller keep the old default.

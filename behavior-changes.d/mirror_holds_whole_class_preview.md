gbrain repair file-drift --held --side unknown|database|both --prefer file --whole-class previews every held file-drift page of one side as one class: one manifest under the gbrain config directory and one hash, with the lines each page would lose, the pages kept held (kept_newer_page, and kept_protected_parts on a read-only mirror) and the data-loss card. On a read-only mirror the held window previews now list a page whose file is newer prefer_file instead of no_drift, and the held comparison names the whole-class preview instead of gbrain sources mirror-writable. A held deleted page whose file differs names neither preview: a tombstone_edited page names the keep-the-deletion preview (--held --side deleted --state tombstone_edited --prefer database) first and gbrain sources mirror-writable second, and a purged_differs page names only mirror-writable. The preview writes nothing else; --whole-class --apply refuses for now.

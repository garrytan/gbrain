An atom a re-extraction retires now keeps the trust tier and write origin its extraction gave it, and an atom a later extraction produces again comes back at that tier. The retirement used to store the atom as unknown with no origin, so a revived atom stayed unknown. The same holds for every page a derived writer retires (chronicle events, synthesis outputs, gbrain repair stale-atoms). Atoms retired before this release keep the tier they were stored with.

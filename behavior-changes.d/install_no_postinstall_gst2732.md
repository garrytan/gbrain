gbrain ships no postinstall script, so a global `bun install -g` of the stable release no longer ends with Bun's "Blocked 1 postinstall" line and a clone's `bun install` no longer prints "postinstall skipped". Nothing it did is lost: every command already refuses on a Bun below the floor, `gbrain setup` applies a new brain's setup migrations, `gbrain upgrade` runs migrations in post-upgrade, and the first command on a brain applies pending schema migrations. New: when upgrade migrations are still pending (after reinstalling over an older brain with `bun install -g`), every command except apply-migrations, upgrade, post-upgrade, doctor, init, setup and serve prints a `migrations_pending` notice naming them, with `gbrain apply-migrations --yes` as the fix.

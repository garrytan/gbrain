gbrain access serves several --labelled-only on a brain that has the company source and no owner now stops with a BLOCKED company/ line and writes nothing, where it used to label the members. The labelled-only run adds a folder rule company/ in source company so labelled-only members still read the company pages, and that rule's readers start with the brain owner. Run it again with --owner <member id> (the member is added when missing and named the owner), or name the owner first with gbrain access owner set <member> and run it unchanged.

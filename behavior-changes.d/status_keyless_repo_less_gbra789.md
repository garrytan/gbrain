gbrain status run on the brain's own machine no longer makes a healthy keyless brain look broken (a thin client reading a remote brain still shows the old lines). A source with no local folder and no connector (Slack, meetings, iMessage, contacts), which keeps its pages in the database, that has never synced now reads "[OK] <source> repo-less (pages live in the database; nothing to sync)" instead of "[UNKNOWN] <source> never", and a brain with embeddings off on purpose shows embed=off instead of embed=0%. A default source whose checkout gbrain import recorded keeps the old line. On a brain with no source checkouts, a full gbrain dream cycle (not one run with --source) that ran to its end (ok, clean or partial, never aborted) now records itself (config dream.last_full_cycle), so "Last full cycle" shows it instead of "never run"; status --json carries it under cycle.last_full with name dream, plus repo_less_sources and embeddings_off.

Access tokens and OAuth clients have a new private-facts grant, `none` for every existing and new token and client, so remote fact reads stay world-only until the brain host opts a connection in: `gbrain auth rescope --token <name> --private-facts granted-sources` (or `--client <id>`) means this key will read every private fact in the sources its grant lists, including facts saved private on purpose, without rewriting any fact. A source opens only when the grant lists it by id: a token with no source grant, a source federated before or after the grant was written and a request's `source_ids` never add one. A fact held on, provenanced from or about a private, `readable_by`, folder-ruled, quarantined or member page stays hidden, and so does a fact with no page to check (no holding page, or a transcript lane such as the conversation archive). `context_pack`, `delta`, writes and audience or attested reads stay world-only. `--private-facts none` turns it off on the next request. No MCP operation or admin HTTP route can set it. `gbrain auth list` and `gbrain auth clients` show it.

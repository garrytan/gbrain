Code sync re-chunks TypeScript, TSX, JavaScript, Python, Ruby and Elixir files once (a per-language chunker revision): top-level code with no named definition (anonymous default exports, top-level `if`/`for`/`try`, Python's `__main__` block) becomes `<file>::__module__` chunks with call edges, and Elixir modules and functions become named definitions that `code-def` and `code-callers` find. The sync cost gate prices only those files.

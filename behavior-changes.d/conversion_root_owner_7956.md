`gbrain sources canonical <id> --to git` refuses a registered root it cannot read (gone, unmounted, a file, no permission or a symlink loop) with `source_root_unreadable` (reason and fix) instead of a raw filesystem or Git error, and an archived or re-registered source refuses `owner_unavailable` before the Git checkout check instead of `git_checkout_required`. An apply whose source was returned to mixed (`--to mixed`) while it ran reports `incomplete` with a message that the source is mixed, never `converted` (#7956).

A harness can now declare the group chat an answer goes into (the X-Gbrain-Room header, request-level _meta.room, or a room tool argument once whoami shows features.room). The caller's read is unchanged; every page and fact in the answer is marked room_access with whether the people in that chat could have read it, and the room_above_level notice tells the agent to keep those items out of the reply. A call with no room is unaffected. With mcp.strict_params set to reject, every tool schema now also declares the optional room argument. See docs/guides/rooms.md.

On Claude Code 2.1.314 or newer, the claude-cli provider now runs its child with `--setting-sources ""`, so your own `~/.claude/CLAUDE.md`, memory and `settings.json` no longer steer gbrain's background claude-cli calls. The subscription login is kept, but `settings.json`'s `env`, `apiKeyHelper` and permission rules no longer reach the child either. `GBRAIN_CLAUDE_CLI_USER_SETTINGS=1` (shell or ~/.gbrain/.env) loads them again. Older CLIs are unchanged.

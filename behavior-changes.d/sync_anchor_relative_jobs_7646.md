A queued `sync` job for a source whose stored path is not absolute on this host completes as a skip (`reason: sync_anchor_relative`, with the ask-the-user fix) instead of failing and using up its attempts. `gbrain sync --all --json` gives such a source's entry `code`, `why` and `fix` beside `error`. With a stored `.`, `gbrain sync --repo ./` is refused like `--repo .`. A relative `sync.repo_path` behind a `default` source with no path no longer lets an explicit `--repo` advance default's last synced commit. `gbrain dream --json` puts a failed phase's ask-the-user fix in its `cycle_failed` envelope.

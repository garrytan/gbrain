gbrain's hook launcher (<config dir>/hook-launcher/gbrain-hook), which every MCP server entry and hook gbrain setup writes starts gbrain through, now records the Bun that installed gbrain and puts it first on PATH. Before, a Codex session started without bun on its PATH (the desktop app, a launcher, a terminal opened before the shell profile changed) could not start gbrain serve or its hooks, and showed no tools. gbrain post-upgrade rewrites the launcher in place, and gbrain setup codex does the same; no config.toml, hooks.json or trust entry changes. gbrain doctor reports a launcher that records no Bun, or a Bun that is gone. The compiled gbrain binary needs no Bun and its launcher does not change.

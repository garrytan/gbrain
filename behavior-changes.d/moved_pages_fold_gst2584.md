gbrain repair file-drift --held no longer offers a delete or a recreate for a page whose file moved while its deletion was held: it lists the page as moved_to <slug> with the new gbrain repair moved-pages --source <id> --slug <old-slug> fold command, and --prefer file skips it. A file that names the page type gbrain-base 1.0.0 gave its path, equal to the type copy an older gbrain stored in the page's frontmatter, now keeps the type a later schema pack gave the page on import, and the import records the rename as a legacy_type retype stamp; before, the next edit read the old type back into the page.

Inline holding-page fact appends still keep their newest five saved versions by default, pruning at most 100 older versions per save. Owners can disable this holding-specific pruning step by running gbrain config set versions.holding_prune_enabled false before future saves. This can increase saved-version storage and does not restore versions already removed or clear history-gap markers. Setting the key back to true restores pruning on subsequent fact appends, which can then remove older versions. This switch covers only inline holding pages; large inline-page and segmented-page retention policies are unchanged and can still prune a holding page that qualifies for them.

On a Postgres brain whose database uses a non-C collation, the unbound tokens and OAuth clients that gbrain access serves several --owner lists, the member keys that gbrain sources unfederate names, and the unlabeled people folders that gbrain access serves and doctor report now come in byte order, the same order PGLite gives. Before, the order followed the database locale. Only the order changes; the lists hold the same entries. PGLite brains see no change.

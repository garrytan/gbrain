The dream cycle has a new phase, `bookkeeping_gc`, after `purge`: it now does the retention GC that `purge` used to do (op checkpoints, brainstorm checkpoints, batch-retry audit files, volunteer events, decision receipts, applied captures, retrieval feedback), with the same retentions. `gbrain dream --json` reports those counts under `bookkeeping_gc` instead of `purge`, whose details keep only sources, pages and orphan clones; `--phase purge` no longer runs the GC.

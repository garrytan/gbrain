A holding page (memory/unattributed, or a folder's <folder>/memory/unattributed) now keeps only its newest five saved versions, whatever their size, as large pages already did. `get_versions` and `gbrain revert` see only those five. Every fact row on the page is kept, the page itself still holds every row, and Git keeps every state of the page where the brain has a repository. An older holding page sheds its extra versions in batches of at most 100 on its next saves, so nothing runs on upgrade. Once a version is removed, an `as_of` read of the page reports incomplete history, and `gbrain repair unwithdrawn-facts` lists that page's candidates as ambiguous: restore them with `--include-ambiguous` and the hash of that preview. Nothing to run.

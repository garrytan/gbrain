Search, query, recall and get_page results now say where each page's authority comes from in a new precedence field: record, approved, curated, doc, chat or external. Lean search rows show it only when it is not curated. Pages of type rule, and type facts pages marked claims: allowed, read as approved unless an outside sender wrote them or an agent wrote them over MCP; chat sources (the conversation archive, meetings, Google) read as chat; a guest source reads as external; everything else reads as curated. Set a source's class with gbrain sources set-precedence <id> <class>, or remove it with --clear. The label is information only: it changes no ranking and no trust level. New: gbrain claims check "<draft>" (MCP tool check_claims) checks the numbers in a draft against your allowed-claims facts pages and says for each one whether a dated line supports it, a line says another number, or nothing covers it; a sentence with several numbers is supported only when every number is. New brains get me/facts and company/facts marked claims: allowed; on an existing brain, add claims: allowed to the front matter of a facts page you want checked. The query keyword-count line now names the date, language or symbol filters that the search listing it points to cannot apply.

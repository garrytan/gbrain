New read-only command: gbrain engine swap --to rust --plan (alias --dry-run, add --json for one JSON document) shows whether this brain is ready to move to the opt-in Rust engine. It lists the verdict, each readiness criterion with what was measured or which evidence is missing, the variables and gbrain service definitions on this machine that select the current engine (names only, never values), the free disk space and a plan hash. Speed is reported and never blocks the opt-in move. It writes nothing and never creates a brain: a mounted brain is refused with engine_swap_refused, reason team_brain, and a configured path with no brain in it is refused with no_brain. A brain that uses managed storage is refused with engine_swap_refused, reason managed_storage, because the Rust engine never holds managed storage. While a gbrain sources refresh is unfinished it refuses with engine_swap_refused, reason refresh_unsettled, and names each refresh and the command that finishes it. READY needs current follower evidence and exactly one observed writer host. The move itself (--yes --expect) arrives in a later release; any other flag is refused as invalid_params.

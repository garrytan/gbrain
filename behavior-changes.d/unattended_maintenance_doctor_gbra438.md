`gbrain doctor` has a new check, `unattended_maintenance`, which reads the free-upkeep record `maintenance.last_run`: it warns (and so can lower doctor status from healthy) when no upkeep run is recorded on a brain older than 48 hours, when the last run is older than 48 hours, or when one step failed three runs in a row; the fix is `gbrain maintain --unattended`. Upkeep turned off (`maintenance.auto false`) or owned by an autopilot reads ok. New commands: `gbrain maintain --unattended`, `--status` and `--purge` (preview, then `--yes --expect <hash>`).

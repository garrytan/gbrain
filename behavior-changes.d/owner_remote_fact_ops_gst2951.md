The brain owner's own remote agents (a credential bound to the member gbrain access owner set names, speaking for itself) now read the owner's private facts through find_trajectory, ontology_get, ontology_conflicts and volunteer_chronicle, and get_write_attribution now finds a private fact for the owner's admin credential, as recall, query and think already did. Facts taken from a private page the owner can read come through too. Before, these operations returned only world facts to every remote caller, so a trajectory or ontology built from private facts came back empty for the owner. Every other remote caller reads no private fact it did not read before: another member, a labelled-only member, an unbound token, a call with no credential and the owner's credential speaking for an audience of several still get world facts only, and a private-facts grant still works on find_trajectory only. Page rules still apply to the owner, so a fact taken from a page whose readers leave the owner out stays hidden, withdrawn facts stay out of every read, and ontology from life/diary pages stays redacted for remote callers. Diary observations are now left out before each value resolves, so a newer diary note no longer hides the older value a remote caller may read.

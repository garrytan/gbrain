`gbrain git commit-push --dry-run` now asks git about the planned paths the way the real run stages them, and runs the real run's checks before staging, so it exits 1 with the real run's code and text where that run would refuse (`commit_outside_source_root` for a path outside `gbrain.sourceRoot` unless `--allow-outside-source-root` is passed, `commit_prestaged_paths`, and `commit_paths_invalid` for a path outside a sparse-checkout definition or one that matches nothing) instead of exiting 0 and listing it. It still takes no lock and writes nothing.

`gbrain doctor` no longer grades a skills folder it found by walking up from the current directory unless gbrain installed it (a skills.lock.json, a valid manifest.json or the skillpack block in its resolver file): resolver_health and skill_currency report "not a gbrain skills folder (<path>)" as info, so an agent's own skills folder no longer lowers health_score or fails doctor. Pass --skills-dir (or set GBRAIN_SKILLS_DIR / OPENCLAW_WORKSPACE) to grade it as before. Agent crons should page on the new `gbrain doctor --alert` (exit 17 act, 18 unknown), not on health_score.

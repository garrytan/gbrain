New: a portable profile. remember takes a facet (size.<item>, brand, diet, allergy, style, constraint, schedule, household, other); with no entity it saves the fact on your own profile, which is memory/owner on a single-user brain, the owner's entity for the brain owner and the member's own member page for a member credential. Allergy facts are saved private unless the call names a visibility. Any connected agent reads the profile with context_pack and profile set to true (one block of facets, constraints, relationships from your page's links, unfaceted preferences and a withheld count, packed into budget_tokens), and the CLI reads it with gbrain profile. A remember without facet is unchanged. The claim metric prefix profile. is now reserved: a hand-written claim_metric that starts with it is refused (profile_metric_reserved, with the same call using facet as the fix), an unknown facet is refused with the list (profile_facet_unknown), a member credential cannot save a profile fact onto another page (profile_entity_not_self), and facts extracted from conversations never carry the prefix. find_trajectory, gbrain eval trajectory and the founder scorecard skip profile facts. On a brain with no members, an agent connected without an owner binding cannot read the owner's private profile facts: they stay private, withheld counts them and a profile_private_hidden notice names gbrain access owner set. Existing grants made from a bot profile keep their tool list; the new parameters ride on remember and context_pack, which they already call.

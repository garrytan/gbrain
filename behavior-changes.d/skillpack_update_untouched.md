Installed skills can now take gbrain's current version whole when you never edited them. `gbrain skillpack scaffold` (including `--harness` installs) and every update record the sha256 of each skill file it installed in `~/.gbrain/skillpack-state.json` (schema `gbrain-skillpack-state-v2`; an older gbrain refuses that file instead of dropping its records). Preview what would change with `gbrain skillpack reference --all --update-untouched --dry-run`; a skill with any edited file, a pinned skill (`gbrain skillpack pin <skill>`) or one with no recorded hash is skipped with a reason and a diff. Every update is journaled under `~/.gbrain/skillpack-backups/` and undone with `gbrain skillpack restore <id>`. `gbrain upgrade` writes no skill files; nothing runs on upgrade.

The brain owner's own remote agents (a credential bound to the member gbrain access owner set names, speaking for itself) now get the owner's private facts on the entity card (its recent facts and its active fact count) and the context_pack cards built from it, in the facts search and query attach about the entity a query names and the saved facts matching its words, in extraction_pending's list of facts saved without an entity, and in the similar facts forget names after a withdrawal. Before, these returned only world facts to every remote caller. Every other remote caller reads what it read before: another member, a labelled-only member, an unbound token, a call with no credential and the owner's credential speaking for an audience of several still get world facts only, and a private-facts grant admits a private fact on a world page where it already did. Page rules still apply to the owner, so a fact taken from a page whose readers leave the owner out stays hidden, and withdrawn facts stay out of every read.

New: gbrain setup claude-code and gbrain setup codex now offer, on a brain the same setup run created, to import the coding-agent sessions already on the machine, so a new session can recall them on day one. Nothing is imported until someone says yes. At a terminal setup shows what it found and asks to import the newest session ([Y/n]), then the rest of the last 30 days on a second, explicit yes ([y/N]). Off a terminal or with --json the offer is the setup_history decision in the first-run bundle; its accept command is gbrain setup <harness> --history-decision <id>, used once. --history none skips for one run, --history decline stops the offer, and --history latest or --history <1-30> imports at once. The import writes one redacted page per conversation per day into the private conversations source with no model or provider call, never changes the archive switch, and is never offered on an upgraded, restored, shared, pinned or team brain. Afterwards setup prints what the brain holds, each count marked measured, off or unavailable, and three questions built from the imported sessions.

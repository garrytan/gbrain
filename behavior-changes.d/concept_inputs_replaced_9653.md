A concept publication now replaces the concept's recorded derivation inputs with its current member atoms, so purging a retired former member no longer hides a concept that was re-synthesized without it (#9653). The purge still hides every saved version of the concept written while that atom was an input: get_versions, get_page with known_as_of or as_of, and revert_version no longer return it, and nothing deletes a version; the purge errs toward hiding, so an older version archived before that atom joined is hidden too. Callers that may not read owner-only material also stop seeing versions written from owner-only inputs; the owner's own callers keep every version a purge did not hide. revert_version to such a version brings its recorded inputs back onto the live page, and get_versions withholds replaced_because from a version whose successor is hidden. Doctor concept_stale_inputs counts live concepts an older version left with an input edge to a deleted former member; nothing rewrites them, and each is corrected the next time it is re-synthesized with changed members.

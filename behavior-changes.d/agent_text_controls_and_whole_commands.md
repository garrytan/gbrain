Messages for agents and terminals (why, user_message, AGENT block fields, notices) write a control character other than tab as a visible octal escape such as \033, and a cut never splits a character or an escape. The managed Git identity question names the checkout by its quoted form. A command argument is never cut: a capped line prints a command whole or says to read it from --json. An argument with a NUL byte or a lone surrogate keeps its exact argv in JSON, prints no command, and its next step becomes report, with why naming the argument. The HTTP view masks a private path after a raw control character in structured argv.

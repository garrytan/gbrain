You can now settle the duplicate groups `gbrain dedupe --preview` lists. `gbrain dedupe confirm <group-id>` records that the pages are one person or company and links them as one identity; `gbrain dedupe confirm --clean --expect <hash>` does that for every clean group in the list you read; `gbrain dedupe reject <group-id>` records that they are different people, so the pair is never proposed again, and undoes a confirm. When the default source has a repository each decision is a file in its .gbrain/identity/ folder, committed through gbrain git commit-push, and a database rebuilt from git keeps it; that file names each member's source and slug, so a decision about pages in several sources puts every member's source and slug in the default source's repository, and confirm and reject refuse a group with a page in an owner-only source, or a page outside the default source that not every reader of it may read, there. Otherwise the database keeps it. A confirmed group counts once: rank_entities folds the group's pages onto its main page, and enrichment tiering counts the mentions in every source of the group. Groups linked by hand with entity_identity_link count as before, and get_links and get_backlinks still join identity groups only with entity_identity.union on. entity_identity_link and entity_identity_unlink now refuse to move or remove a page that gbrain dedupe confirm linked (identity_link_owned_by_dedupe); gbrain dedupe reject does it and records why. Nothing is linked without your confirm, and no page is merged, renamed or deleted.

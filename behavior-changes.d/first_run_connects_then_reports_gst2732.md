`gbrain init` no longer asks the user to approve connecting gbrain to their agent. The first-run bundle (`first_run_decisions`) now lists the settings in effect and how to change them, with no "Reply 'defaults'" question: search mode as applied, automatic saving (`writeback`) shown as in effect `off` with `salient` recommended (it was shown as default `salient` while off), skills and upkeep. Connecting the agent moved out of the bundle into its own `harness_wiring` notice (kind info, actor agent, no consent), because it is an install step. The install docs (AGENTS.md step 3, INSTALL_FOR_AGENTS.md Step 3.5) drop the STOP for every harness: connect first, then relay the settings and the cost matrix in the reply that reports the install. Nothing paid turns on from these settings without a key the user supplied.

Two nightly learning phases now run by default. Claim conflicts (dream.claim_conflicts.mode) now defaults to propose: each dream cycle files a pending proposal when two typed facts about the same thing disagree. It needs no key, costs nothing and changes no fact until you decide (gbrain trust review --kind contradiction). Turn it off with gbrain config set dream.claim_conflicts.mode off. Thin-page filling (cycle.enrich_thin) now runs when a chat model key you supplied is configured, and stays off without one. It fills at most 3 thin person and company pages per source per run, at about $0.01 a page, and stops at $0.50 per run (the brain-wide per-run cap was $5.00). It has no daily cap unless you set cycle.enrich_thin.max_daily_cost_usd. Turn it off with gbrain config set cycle.enrich_thin.enabled false. A value you already set for any of these keys is kept. gbrain doctor now reports the newest nightly learning run and how much of the morning note you kept or undid (learning_note).

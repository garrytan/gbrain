An extraction run's receipt page (type `extract_receipt`, under `extracts/`) is now chunked and sealed in the transaction that writes it. Remote/MCP `search` and `query` on the extracted source no longer report `safe_index_pending` or `projection_pending` after every extraction, doctor `safe_index_pending` no longer counts new receipts, and remote readers can now find receipts like other generated pages (demoted in ranking). Receipts an earlier release wrote stay unsealed until `gbrain repair safe-chunks --apply`. A receipt is database-only bookkeeping on every brain, with or without a Git repository: when its slug already holds a content page or a page with a file in Git, the receipt is not written (the extraction logs a warning and carries on) instead of overwriting that page.

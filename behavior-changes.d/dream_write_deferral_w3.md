A dream purge or consolidate write that was accepted but is still pending after its publish wait no longer fails the phase: the phase warns `dream_write_deferred` with the receipt id, and the next pass reads that receipt before it submits anything for the source (committed clears it; a failure is reported with its real code). After 3 passes still pending, doctor `dream_write_deferred` warns with `gbrain write-request -- <id>`. `gbrain config set dream.write_deferral.enabled false` restores the failing phase.

`gbrain sources writer retry-effects <source> --parked-pushes` (and `git-durability --pat-file`) no longer stops the whole run when one parked request's remote writer can no longer see its page (it became private): that request is listed in `refused` with its `request_id`, code `page_not_found`, the page slug and a read-only receipt command, the other parked pushes are retried, and the run ends `partial` (exit 1). The refused request stays parked; nothing retries it under another authority.

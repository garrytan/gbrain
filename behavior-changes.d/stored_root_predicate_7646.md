Stored paths (`sources.local_path`, `sync.repo_path`) are judged absolute by one rule in sync, `config set sync.repo_path`, write-through, `gbrain sources set-path --clear` and doctor. On Windows only a drive path (`C:\...`) or a UNC share counts: a root-relative `\brain` or `/brain`, which names a folder on whatever drive gbrain runs from, is refused by sync (`sync_anchor_relative`) and cleared by `--clear` like `.`. Doctor's `default_source_local_path` now warns when the `default` source's own path is absolute only on another operating system (a Windows drive path read on Linux or macOS), where it reported ok. A page or fact write whose stored root is not absolute on this host records the database-only reason `relative_root` (it was `no_repo_configured` or none).

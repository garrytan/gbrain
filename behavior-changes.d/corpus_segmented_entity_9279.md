Captured session files whose facts name a large entity page (one stored in segments, over about 1 MiB) are now extracted: facts inferred from a mention of that page were refused after the model call, so those files were retried five times and then stopped. The first sweep after this upgrade retries each file stopped that way once, at the cost of one model call per stopped window, with no command needed. From now on a refusal that retrying cannot change stops its window after one paid attempt instead of five, retention keeps the session file instead of deleting it at the un-ingested limit, and gbrain doctor (memory_writeback) counts these files as held. gbrain sweep --retry-failed --apply still retries them by hand.

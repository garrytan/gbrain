The built-in model defaults now name the newest models in each family. With only an Anthropic key and no model set, the utility tier and query expansion use claude-haiku-5-5 (was claude-haiku-4-5), the reasoning and subagent tiers and the default chat model use claude-sonnet-5-5 (was claude-sonnet-4-6), and the deep tier uses claude-opus-5-5 (was claude-opus-4-7); the opus, sonnet and haiku aliases follow. With only an OpenAI key, the tiers now come from the gpt-6 family (utility gpt-6-luna, the other tiers gpt-6.2-sol) instead of the gpt-5.6 family, and the gpt alias follows the deep tier. This includes a brain where account model discovery is off or has not run yet, so if your OpenAI endpoint does not serve gpt-6, set models.tier.<tier> to a gpt-5.6 model. The nightly relationship check (dream.edge_contradictions) runs on the utility tier, and claude-haiku-5-5 is not yet certified for its apply mode, so with no mode set it now proposes closures for you to accept instead of writing them; set models.dream.edge_contradictions to a certified model such as anthropic:claude-sonnet-5-5, or dream.edge_contradictions.mode apply, to keep writing them. claude-sonnet-5-5 is a thinking model, so a subagent turn may now write up to 32,000 output tokens (was 8,192); with dream.synthesize.mode agentic and the default $5 dream.synthesize.budget_usd, a transcript's worst-case estimate can pass the cap and be skipped, so raise the cap or set agent.max_output_tokens if you use agentic mode. Contextual retrieval's page synopses keep claude-haiku-4-5, because that model is part of the key that decides whether existing embeddings can be reused. Anything you set yourself (models.tier.<tier>, models.default, chat_model, expansion_model, GBRAIN_MODEL or a per-command --model) is unchanged. To keep an older model, set it, for example gbrain config set models.tier.reasoning anthropic:claude-sonnet-4-6.

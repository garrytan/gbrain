The built-in model defaults now name the newest models in each family. With only an Anthropic key and no model set, the utility tier and query expansion use claude-haiku-5-5 (was claude-haiku-4-5), the reasoning and subagent tiers and the default chat model use claude-sonnet-5-5 (was claude-sonnet-4-6), and the deep tier uses claude-opus-5-5 (was claude-opus-4-7); the opus, sonnet and haiku aliases follow. With only an OpenAI key, the tiers now come from the gpt-6 family when your account lists it (utility gpt-6-luna, the other tiers gpt-6.2-sol) instead of the gpt-5.6 family, and the gpt alias follows the deep tier. Contextual retrieval's page synopses keep claude-haiku-4-5, because that model is part of the key that decides whether existing embeddings can be reused. Anything you set yourself (models.tier.<tier>, models.default, chat_model, expansion_model, GBRAIN_MODEL or a per-command --model) is unchanged. To keep an older model, set it, for example gbrain config set models.tier.reasoning anthropic:claude-sonnet-4-6.

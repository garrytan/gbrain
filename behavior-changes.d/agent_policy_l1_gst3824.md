New: an agent policy says when your agents may send, spend, delete, sign up, call or publish for you outside the brain. gbrain policy init sets one (the default preset asks before every such action), gbrain policy allow, ask and deny change one rule, and gbrain policy show prints it. Agents ask with the policy_check tool (or gbrain policy check) and get allow, ask, deny or none. It is advice only: your harness's own approvals still apply. A change from an agent session, or with no terminal, waits as a pending revision until you run the printed gbrain policy accept command in your own terminal or approve it in the owner session, and remote callers can never write the policy page. The terminal check stops agent sessions that keep their usual markers; it is not proof against a program running on the brain host that hides them. The capabilities tool tells an agent which gbrain tools its connection can call right now, listed or not. A brain-first line that tells agents to call policy_check first is off by default; gbrain config set brain_first.policy_line on adds it at the next setup or upgrade, and off removes it.

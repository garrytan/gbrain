Conversation facts can now carry a slot: where a person lives, who employs them or their role. `gbrain extract-conversation-facts` asks the model for it and stores it on the fact's ontology columns. The facts block in `query` then works out each value's validity window when it reads: an older value shows "valid FROM to UNTIL", ending where the next value starts, when both came from the same conversation page or the newer fact says the value changed in plain English (moved, joined, left, was promoted and similar); otherwise both values stay open and nothing is labelled. Nothing is closed in storage, so re-extracting pages in any order gives the same windows, a stored end date always wins, and a fact the caller cannot read never ends a window the caller can. Facts without a slot read exactly as before, and the ontology (ontology_get, ontology_propose, conflicts and the ontology-facts repair) ignores conversation facts. Pages extracted before this release keep their facts without slots and are not re-extracted automatically. To add slots to an existing brain, preview the paid run first with `gbrain extract-conversation-facts --force --dry-run`, which now prints the segment count and an estimated token count and dollar cost, then run `gbrain extract-conversation-facts --force`.

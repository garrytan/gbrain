# Upgrade to v0.60.276.0: inexact renames keep identity only when the files confirm it; background writes refuse a source that cannot publish

This release adds one index (schema migration v250, built online on Postgres; no column, no backfill) and two
doctor checks. Nothing rewrites pages on upgrade.

1. **Finish the upgrade.** `gbrain upgrade` runs it. To be sure, on the brain host:
   ```bash
   gbrain apply-migrations --yes --no-autopilot-install
   ```
   If doctor `persistence_request_indexes` reports the request-id index invalid or missing, run its fix
   (`gbrain repair request-indexes`).

2. **Settle renames sync no longer trusted.** A sync that sees Git guess a rename between files that do not share an
   `id`, a unique `slug:` line or a unique title now imports a new page and soft-deletes the old one. List them:
   ```bash
   gbrain sync status --source <id> --json   # identity_downgrades
   gbrain doctor --only rename_identity_downgrades --json
   ```
   Relay each pair to the user. If the user says the two files are the same document, restore the old page with the
   command the report names (`gbrain restore <old-slug> --source-id <id> --force`). The purge leaves the old page
   alone until then; there is no deadline. To keep identity on a future move-and-edit, give the file a stable
   frontmatter `id`, or move, commit and sync before editing.

3. **Background work refused `owner_unavailable`.** On a writer-claimed brain, autopilot, jobs and connector syncs
   now stop before taking a request id when the source's worktree is in recovery or its owner check fails (for
   example a deleted `.gbrain-owner.json`). Read the cause:
   ```bash
   gbrain sources writer status --source <id> --json
   ```
   Repairing a deleted owner marker is a writer self-transfer; ask the user before running it.

4. **Parked purges.** Doctor `purge_parked_pages` names pages the managed purge failed to remove five times. Fix the
   named cause, preview, then ask the user before the retry (it permanently removes pages):
   ```bash
   gbrain pages purge-deleted --retry-parked --dry-run --json
   gbrain pages purge-deleted --retry-parked --yes
   ```

Verify:
```bash
gbrain doctor --only persistence_request_indexes,rename_identity_downgrades,purge_parked_pages --json
```

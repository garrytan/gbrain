# v0.58.1.37 — exclude owner-sent automation from loop extraction by label

Mailbox warm-up and similar owner-sent automation produced an LLM extraction
candidate for every thread — tens per day — because each carried the owner's
own SENT message. A new opt-in config excludes whole label classes before
extraction:

```bash
gbrain config set loops.extraction_exclude_labels "Apollo Mailwarming"
```

Comma-separated Gmail label names or ids. Any thread carrying one returns
`excluded_label` and is never enqueued for extraction — even threads the
owner wrote in. Unset config preserves prior behavior.

# v0.35.0.0 migration notes

This is a historical record, not an installation playbook. The hosted provider
introduced in this release retired on **2026-09-04** and is no longer supported.
Its opt-in commands have been removed. Original identifiers and attribution are
preserved at Git revision `6040075c6cb95be5881cc2e1b76ef7d71f4e5d29`
(retained on 2026-09-23).

## What changed in that release

- The embedding model stayed unchanged unless the user explicitly opted in.
- `KNOBS_HASH_VERSION` moved from 1 to 2 so result-cache keys included the
  reranker settings. The historical one-hour cache turnover was not a re-embed.
- `tokenmax` enabled cross-encoder reranking by default; `conservative` and
  `balanced` did not. Missing credentials or provider errors returned the
  original fusion order and wrote a failure audit rather than breaking search.
- Reranker diagnostics warned immediately for auth failures and at five
  transient failures in seven days. Audit query text was hashed, never raw.

## Current action

Do not replay the old provider opt-in. For a model change, follow the
[explicit-consent migration playbook](v0.46.3.0.md). An upgrade does not
authorize schema changes or paid re-embedding. Current supported providers
are listed in the [provider guide](../../docs/integrations/embedding-providers.md).

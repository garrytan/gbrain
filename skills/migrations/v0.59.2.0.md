# Upgrade to v0.59.2.0: skillopt reports unusable optimizer output and model provenance

This release changes how `gbrain skillopt` reports a run whose optimizer model
never returned usable edits, and records which models every run used. No
database migration, new provider key or paid call is required.

1. **Scripts and schedulers that run `gbrain skillopt`:** a run where no
   optimizer reply was usable now ends `errored` with exit code 2 (it used to
   end `no_improvement` with exit 1). If a wrapper treats exit 1 as "nothing to
   do" and anything else as a failure, it will now correctly flag these runs.
   Do not remap exit 2 back to success. Read the printed `Fix (...)` line and
   `Resume:` command, or the receipt's `remediation` and `resume_command`.

2. **Nightly dream cycle (`cycle.skillopt.enabled true`):** check the most
   recent cycle report for skillopt rows with outcome `skipped_budget`:

   ```bash
   gbrain skillopt <skill> --dry-run
   ```

   A `skipped_budget` row means one optimizer call alone reserves more than
   `cycle.skillopt.per_skill_cap_usd`. This is expected for a Claude 5 thinking
   optimizer at the default $0.50 cap, because thinking optimizers now get a
   32,000-token output cap. Tell the user and offer one of the fixes the row
   lists. Do not change their cost cap without asking:
   - `gbrain config set cycle.skillopt.per_skill_cap_usd <usd>`
   - `gbrain config set skillopt.reflect_max_tokens <n>`
   - a cheaper `models.tier.deep` optimizer

   The skill is retried automatically once one of those settings changes.

3. **Optional, only when the user wants it:** strict model provenance.
   `gbrain skillopt <skill> --models-strict --dry-run` previews whether every
   model the run would call was chosen explicitly. Enable it for every run
   with `gbrain config set skillopt.models_strict true` only if the user asks.

4. **Verify:**

   ```bash
   gbrain --version
   gbrain skillopt --help   # lists --reflect-max-tokens and --models-strict
   gbrain models            # sources attributed; advisory newer-model hints
   ```

   The `gbrain models` newer-model hint is advisory. Do not change model
   defaults or tier keys because of it unless the user asks.

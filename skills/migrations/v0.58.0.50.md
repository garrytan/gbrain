# v0.58.0.50 — gathered-pages evidence budget is configurable

The `synthesize` gathered-pages block had a hard-coded ~12k character budget.
With many gathered pages, per-page excerpts shrank to frontmatter-only while
the response still emitted a plausible-looking citation.
`synthesize.pages_budget_chars` (config) or the `pages_budget_chars` verb
param now sizes the block; the per-page ceiling scales with it, and the
response carries a `PAGES_EXCERPT_TRUNCATED_N` warning whenever excerpts
were cut.

No schema or data migration; nothing re-imports or re-embeds. No action
needed — set `synthesize.pages_budget_chars` (or pass `pages_budget_chars`
on the verb) only if you want a larger evidence block.

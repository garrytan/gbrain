# v0.57.0.18 — `--segment-limit` boundary records terminal outcome

`gbrain extract-conversation-facts --segment-limit N` skipped the
terminal audit row for any page with exactly N segments, because
"fully processed" was `segmentsThisPage < segmentLimit`. Such pages
re-extracted on every subsequent run.

"Fully processed" is now `segmentsThisPage === segments.length` — a page
completes when every segment in scope was processed, whether or not a
limit was set. Pages cut short by the limit still get no terminal row and
resume normally.

No action required.

# Upgrade to v0.57.0.42: preserve memory and review blocked work

Preserve the agent's identity, capture preferences, provider choices and source
grants. This patch adds no schema migration and authorizes no live repair,
ownership change, paid backfill or service installation.

## Upgrade without mixing consumers

1. On a managed deployment, gracefully stop and drain the owner and older
   workers on every host. Retain the original installation and a verified full
   database backup. Git alone is not a full database backup.
2. Use the installation's supported upgrade path, retaining independent
   opt-outs where applicable:

   ```bash
   GBRAIN_NO_AUTOPILOT_INSTALL=1 GBRAIN_NO_REEMBED=1 gbrain upgrade --no-autopilot-install
   ```

   If an existing migration phase failed, inspect that failure before using
   `gbrain apply-migrations --yes --no-autopilot-install`. Do not delete its
   ledger, force a retry blindly, enable capture or add credentials.
3. Restart compatible owners/workers and verify the installed version, scoped
   page readback and writer state:

   ```bash
   gbrain --version
   gbrain sources writer status --json
   gbrain backup check --json
   ```

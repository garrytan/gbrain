# Upgrade to v0.60.74.0: fix wave 9

Bug fixes across cost caps, background jobs, the nightly quality probe, facts, session capture, auth and skills. Three schema migrations; a few outputs and defaults change. Nothing here needs the user's consent, but relay the one-time `behavior_changes` notice when gbrain prints it.

1. **Finish the upgrade.** `gbrain upgrade` runs it. To be sure, on the brain host:
   ```bash
   gbrain apply-migrations --yes --no-autopilot-install
   ```
   v209 adds the empty `page_facts_reconcile` table. v210 clamps stored OAuth client token lifetimes into 60..7,776,000 seconds and shortens already-issued access tokens to 90 days after issue (refresh and machine bearer tokens untouched). v211 pins `search_path` on gbrain's database functions.

2. **Restart long-running processes.** Tell the user to restart every `gbrain serve --http`, autopilot daemon and `gbrain jobs work` worker so the token cap and the new shutdown handling take effect.

3. **Relay the behavior changes.** The one-time notice names six changes the user may notice: shell jobs terminate processes they leave behind (`setsid` or a service manager for daemons), declaring-pack brains start the daily `extract_atoms` auto-drain within `autopilot.auto_drain.max_usd_per_day` (opt out: `gbrain config set autopilot.auto_drain.enabled false`), OAuth access tokens last at most 90 days (a client without a refresh token reconnects), `gbrain sources writer status --json` renames `ingress` to `local_process_ingress`, `gbrain jobs work` exits 0 after a SIGTERM drain and 17 when work was handed back, and unextracted session files are kept up to 90 days. `gbrain doctor --only behavior_changes` shows it again.

4. **Update scripts and skill forks you maintain.**
   - Read `local_process_ingress.state` instead of `ingress`; for ownership read `worktrees` / `bindings`.
   - `gbrain jobs supervisor stop --json` gains `drained`, `checks` and `queue`; reason `timeout_40s` is now `timeout`.
   - Cost caps use one flag, `--max-usd N|off`; a bare `0` is refused (write `off`). Remote `run_skillopt` needs a positive `max_cost_usd`.
   - `--source` on `timeline-add`, `ontology-add` and `takes add|update|supersede` is provenance; choose the destination with `GBRAIN_SOURCE=<id>` or `.gbrain-source`.
   - A fork of the bundled `capture` skill: frontmatter is `writes_pages: true` with `writes_to: [inbox/]`; `schema-author` is `writes_pages: false`. A list-valued `writes_pages` is refused by `put_skill` and the 0.53.0 adoption.
   - A fork of `perplexity-research`: the Sonar chat-completions endpoint is retired; use the Agent API (`POST /v1/agent`).
   - Forks of `ingest`, `eiirp` and `operational-disciplines`: always-on capture runs only after the user's explicit automatic-capture opt-in.
   - A fork of `gbrain-upgrade`: a migration playbook that forbids unattended upgrades outranks `self_upgrade.mode: auto`.
   - Upgrade hints to a pinned tag: `bun remove -g gbrain && bun add -g github:garrytan/gbrain#v<version>`, never an in-place tag swap.

5. **Optional follow-ups to offer the user.**
   - Codex users: `gbrain transcripts recover codex` previews restoring the user side of sessions imported before this release; `--apply` re-imports them (no facts extracted).
   - Nightly quality probe: `gbrain models` shows its routes. On an Anthropic-only brain, set three different judges so the panel can reach a verdict: `gbrain config set models.eval.cross_modal.slot_a <model>` (and `slot_b`, `slot_c`). If the user set `autopilot.nightly_quality_probe.max_usd`, an unpriced model is refused; register its rate with `gbrain pricing set`.
   - Brains without managed persistence: `gbrain dream --phase extract_facts` reconciles every synced `## Facts` section at once instead of 250 pages per cycle.

6. **Verify.**
   ```bash
   gbrain doctor
   gbrain auth clients
   gbrain sources writer status --json
   ```

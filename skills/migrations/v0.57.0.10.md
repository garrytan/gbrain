# v0.57.0.10: Hermes joins the harness registry

No operator action is required: the change is additive metadata. `gbrain mcp
adapters` now lists `hermes` with its `docs/mcp/HERMES.md` guide, stdio-only
mode, and manual connection. Existing Hermes registrations through
`hermes mcp add gbrain` are unaffected — the registry entry is descriptive,
not a new install path.

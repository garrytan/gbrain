# Upgrade to v0.59.0.0: keep LongMemEval comparisons separate

This release changes the **evaluation reader** default to notes-first with a
1024-token output cap. It does not change `gbrain think`, agent memory, the
stored brain, or the experimental excerpt selector. No database migration,
provider enrollment or paid benchmark run is required.

1. Preserve existing LongMemEval receipts and research records. Do not rewrite
   their prompts, grades or historical cutoff labels.
2. For a new LongMemEval run, the default is equivalent to
   `--reader-mode notes --reader-max-tokens 1024`. If comparing with or
   resuming a historical direct receipt, pass `--reader-mode direct`; it keeps
   the original prompt and 512-token budget. Use separate output files for
   direct and notes. Reader configuration mismatches refuse a resume even
   with `--allow-mixed-run-config`.
3. Verify the installed CLI without spending on provider calls:

   ```bash
   gbrain --version
   gbrain eval longmemeval --help
   ```

   Confirm the two reader flags are listed. A cutoff, empty answer or unknown
   finish is an incomplete reader error, not an answer eligible for judging;
   its partial text is retained only as a diagnostic. Do not bypass the
   reader guard or drop failures from a score denominator to recover an old
   headline number.

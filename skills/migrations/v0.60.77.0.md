# Upgrade to v0.60.77.0: zero-model saves, forget review, fact replacement, quote checking

Saves never call an AI model before they land, `forget` reports close rewordings it did not remove, `remember` can replace one named fact, and quotes in `think` answers and dream pages are checked against their sources by default. One schema migration. Nothing here needs the user's consent, but relay the one-time `behavior_changes` notice when gbrain prints it.

1. **Finish the upgrade.** `gbrain upgrade` runs it. To be sure, on the brain host:
   ```bash
   gbrain apply-migrations --yes --no-autopilot-install
   ```
   v212 adds the empty `decide_review_queue` and `decide_review_proposals` tables.

2. **Relay the behavior changes.** The one-time notice names what the user may notice:
   - `think` answers, saved syntheses, concept narratives and pattern pages check their quotes: a quote found in no evidence loses its quotation marks and is marked `[unverified]`. Present `answer`, not `answer_raw`. The check is measured not to over-flag real quotes, but how often it catches a made-up quote is not measured yet, so do not tell the user a kept quote is proven. Opt out: `gbrain config set think.quote_verify false` and `gbrain config set dream.quote_verify false`.
   - `forget` responses carry `similar_active`: close active facts it did not withdraw. Ask the user before forgetting any of them.
   - On a brain with a TypeSafe key, forgetting a fact queues an overnight review that can propose withdrawing rewordings of it. It only proposes. Opt out: `gbrain config set decide.slots.conflict.review_withdraw false`.

   `gbrain doctor --only behavior_changes` shows it again.

3. **Use the new calls.**
   - To correct a fact, pass `replaces: <fact_id>` to `remember` instead of forgetting and re-remembering. Refusals name the reason (`target_superseded` names the fact that replaced it; `replaces_cross_page` means forget the old fact, then remember).
   - Review forget proposals with `gbrain decide proposals list`. Accepting a withdrawal is permanent: confirm with the user, then `gbrain decide proposals accept <r-id> --yes`; otherwise `gbrain decide proposals reject <r-id>`.

4. **Leave the tool list alone.** `mcp.advertised_surface` can list fewer tools while every tool stays callable, but a held-out agent benchmark found shorter lists lowered task success by 8 to 10 points and saved no tokens. Set it only for a client that cannot hold the full catalog.

5. **Verify.**
   ```bash
   gbrain doctor
   gbrain decide status
   ```

# v0.46.35.0

## `gbrain config get` redacts secrets by default (#3943)

Before: `gbrain config get anthropic_api_key` printed the raw value while
`config show` and `config set` redacted. After: `get` redacts like its
siblings. Automation that needs the plain value passes `--raw` (either
argument position):

    gbrain config get anthropic_api_key --raw

Scripts that parsed the raw value from `config get` output MUST add `--raw`.
Everything else is unchanged.

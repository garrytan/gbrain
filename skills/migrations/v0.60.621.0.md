# Upgrade to v0.60.621.0: Hermes transcript import skips automated sessions by default

`gbrain transcripts ingest` on a Hermes `state.db` used to import every row of
the `sessions` table, so scheduled cron runs, delegate sub-agent children,
kanban workers, tool integrations and hook-driven runs became conversation
pages beside your own conversations and, with `--facts`, paid for fact
extraction over text you never said. From this release the importer reads the
session kind Hermes records itself (`sessions.source`, the creation label in
`created_source`, and the `_delegate_from` marker Hermes puts on sub-agent
children) and skips, by default, what Hermes hides from its own session
history: `subagent` (including delegate children spawned under a desktop or
gateway turn, which inherit the parent's source), `kanban` and `tool`.
Scheduled `cron` runs and a hook's custom source still import until you name
them. Nothing is deleted, no schema changes, no model calls.

1. **Decide what to exclude.** Preview first; the summary prints an
   `excluded:` line and `--json` carries `sessionsExcluded` and
   `excludedBySource`:
   ```bash
   gbrain transcripts ingest ~/.hermes/state.db --dry-run
   gbrain transcripts ingest ~/.hermes/state.db --dry-run --exclude-source cron,subagent,kanban,tool
   ```
   To keep importing everything as before:
   ```bash
   gbrain transcripts ingest ~/.hermes/state.db --exclude-source none
   ```

2. **Set a default for scheduled runs** (a JSON array or a comma list; `[]`
   imports everything; the flag wins over the key):
   ```bash
   gbrain config set transcripts.hermes.exclude_sources '["cron","subagent","kanban","tool"]'
   ```
   A list you set explicitly is part of the `--since last` scope for Hermes
   stores and auto-detected paths: changing it starts a fresh scope (like
   `--max-bytes`), so sessions you stop excluding are picked up on the next
   run. Setting the key for the first time therefore also re-scopes the next
   scheduled discovery run (`gbrain transcripts ingest --all --since last`),
   which re-reads every discovered file once (hash-skipped, so no page
   changes, but a large Codex or Claude Code tree takes one long pass). The
   default list is not part of the scope. A value that is not a list refuses
   the run instead of excluding nothing; an explicit list replaces the
   default, so name `subagent`, `kanban` and `tool` again to keep them out.

3. **Expect one re-render on the next full scan.** Every Hermes page a run
   imports now records its kind under `transcript_import` (`session_source`,
   `session_created_source` when it differs, `delegate: true` for sub-agent
   children). The next ingest **without** `--since` rewrites each existing
   page it imports once to add those keys (on a managed brain that is one
   write request per page); a `--since last` schedule skips sessions below
   its watermark before rendering and leaves their pages as they are. Pages
   whose session the current list excludes are not rewritten either. To stamp
   every existing Hermes page once you can run `gbrain transcripts ingest
   ~/.hermes/state.db --exclude-source none` one time, but that run also
   IMPORTS every automated session present in the store at that moment (and
   with `--facts` extracts over them): preview it with `--dry-run` first, and
   delete the pages you did not want afterwards (`gbrain delete <slug>`).
   Re-runs after that are free again. Read `session_created_source` first when it is present: Hermes
   can rewrite `source` later (for example to `local`).

4. **Pages imported before this release are not removed.** Automated sessions
   imported earlier stay until you delete them; the recorded kind (once the
   page has been re-rendered as in step 3) and, for pages whose session row
   still exists, `state.db` are what a later cleanup can classify by.
   `gbrain delete <slug>` soft-deletes a page today.

**Say to your agent:** *"Import my Hermes sessions but leave out the cron jobs and sub-agent runs"* — *"Set the Hermes import to skip cron, sub-agent, kanban and tool sessions by default"* (your agent runs `gbrain config set transcripts.hermes.exclude_sources` with that list).

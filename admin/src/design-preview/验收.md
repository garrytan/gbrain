# 知识工作台与设置页版式验收

本轮是独立前端预览，不替换正式路由，不调用后台接口。数据为参考图对应的演示数据，连接测试、文件导入与 AI 回复不模拟成功。

## 验收步骤

1. 打开 `/admin/design-preview.html`，检查工作台的三栏布局、欢迎区、三个快捷入口和底部输入区。
2. 点击设置，再返回 AI 工作台，检查导航选中状态和页面切换。
3. 输入会话关键词，仅显示匹配会话；输入不存在的关键词，显示空结果；清空恢复列表。
4. 点击新建对话，检查新会话选中且输入框清空；点击快捷入口，将相应问题填入输入框。
5. 输入中文消息后发送，检查用户消息展示，并明确显示未接入 AI；中文输入法选词的 Enter 不触发发送，Shift+Enter 换行。
6. 设置页默认显示四个模型服务卡片和五种模型用途。分类搜索只过滤菜单；点击模型用途后显示独立用途配置视图；更换模型只修改预览状态。
7. 点击连接测试、刷新模型，显示未连接后端的说明，不出现虚构成功状态。
8. 在宽屏及较窄电脑窗口检查内容可滚动、输入框不被裁切、设置卡片和用途行没有横向溢出。

## 实施边界

- 样式与 React 组件隔离在 `admin/src/design-preview/`，复用现有 React、Lucide 和 Vite。
- 保留参考图的设置分类，尚未设计的分类清楚标明待设计，不推断后台配置。
- 标题栏的窗口控制符仅作桌面版式示意，不模拟浏览器最小化或关闭。
- 后续正式接入需复用 Core / Operation / Admin API；会话持久化、工作目录、模型角色映射等公共能力须先确认现有实现，涉及底层新增时单独确认。
- 规划分享链接未取得正文，本轮视觉依据为用户选择的两张截图。

## 启动与构建

在 `admin/` 执行 `bun run dev --host 127.0.0.1 --port 5199 --strictPort`，打开 `http://127.0.0.1:5199/admin/design-preview.html`。

独立构建：`bunx vite build --config vite.design-preview.config.ts`。产物在根目录 `.codex/design-preview-dist/`，不覆盖正式 `admin/dist`，不随正式入口加载。

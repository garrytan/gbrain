01A

数据库

PGLite 适合单机自用；多人共享或局域网并发建议使用 Docker Postgres。

使用建议

PGLite 是嵌入式单写者数据库，同一时间只适合本机一个服务进程访问。若需要多人同时通过 MCP/局域网使用，请选择 Docker Postgres。

数据库切换说明

切换 PGLite / Postgres 只会改变连接目标，不会自动迁移、删除或备份原数据库。PGLite 数据仍保留在原位置；切换前请确认目标数据库和数据范围。

选择保存 PMBrain 数据库的本机位置；现有用户会继续使用原位置。
已有数据库可填写地址；当前使用 PGLite 时可一键创建 Docker 数据库并迁移完整知识库。
迁移预检结果

    先扫描旧库并展示处理方案；确认后才冷备、创建专属 Docker 库。全部校验和新服务检查通过后才切换，原库始终保留。

              PGLite + 共享模式
              
    当前数据库是 PGLite：它不支持多进程/多用户并发写入。局域网多人同时调用时，容易出现排队、超时或体验变差。若要稳定给多人使用，建议在「基础配置」改选 Docker Postgres 后再开共享。
    
            
    
            
    
              
              PMBrain 会锁定这张网卡和这个 IPv4，不会在网络变化时自动切到其他地址。
              
    避免地址变化
    建议在路由器设置“DHCP 地址保留”，把这个 IPv4 固定给本机。若网卡、Wi-Fi 或 VPN 导致地址消失，PMBrain 会立即停止共享并通知你，不会静默切换。首次出现 Windows 防火墙提示时，请只允许“专用网络”。

    DOCKER POSTGRES
    四步启动本机数据库
    
      
      
        
    1. 安装并启动 Docker Desktop
      Windows 10/11 需要先确认 Docker Desktop 正常运行；如提示 WSL2，请按引导安装并重启电脑。
      2. 
        
    2. 在 PowerShell 启动 pgvector Postgres
      docker run -d --name pmbrain-postgres -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=pmbrain -p 5433:5432 -v pmbrain-postgres-data:/var/lib/postgresql/data pgvector/pgvector:pg16
      3. 
        
    3. 启用向量扩展
      docker exec -it pmbrain-postgres psql -U postgres -d pmbrain -c "CREATE EXTENSION IF NOT EXISTS vector;"
      4. 
        
    4. 回到 PMBrain 填写连接地址
      postgresql://postgres:postgres@127.0.0.1:5433/pmbrain
      已有数据库可填写地址并保存配置；已有 PGLite 知识库请使用页面上的一键迁移按钮。
      5. 
      
    
      
    本教程适合手动配置现有数据库。一键迁移会自动创建专属容器和数据库；Docker Desktop 本体需先安装。

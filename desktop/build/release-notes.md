## PMBrain 1.4.69

- 知识库目录被 Windows 标成只读时，打开前会去掉这个只读标记。PGLite 因此可以重新创建启动锁 postmaster.pid。只读标记去不掉时，直接说明是启动锁权限，不再打开数据库。
- 升级校验如果是启动锁权限问题，不再做 WAL 修复。升级冷备没有通过时，重新启动不会再打开知识库服务。
- 知识页面、原始资料和已有向量不会被删除。

## PMBrain 1.4.68

- 只读的失效启动锁会在打开前去掉。知识页面、原始资料和已有向量不会被删除。

- 目录仍无写入权限时，界面说明是启动锁权限问题。知识页面、原始资料和已有向量不会被删除。
